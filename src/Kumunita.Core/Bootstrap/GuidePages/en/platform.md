## Admin: platform

The **Platform** tab is where a global admin keeps the *platform's own* things in order — the pages it ships, the defaults it applies, and the things it lets residents override.

**The platform pages.** The terms, the help guides, the privacy note, and the code of conduct are the platform's own pages. A global admin can edit them, and reset a page back to its shipped text when they want the latest wording.

**The platform defaults.** Set the default language, time zone, and date format for the instance. Every resident can still override any of these on their own account (see [Settings](/pages/system/help/settings)) — the default is only what applies where a resident has not chosen their own.

**The sign-up gate.** Choose whether new residents can sign up on their own, or only when you invite them.

What this tab is not: it does not manage individual accounts (that is [Accounts](accounts)), communities ([Communities](communities)), or the security and audit surface ([Security](security)). See [Admins](/pages/system/help/admins) for the role in full.
