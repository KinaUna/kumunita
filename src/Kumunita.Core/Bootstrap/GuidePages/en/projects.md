## Projects

Projects is where the neighborhood's higher-level shared work lives — the direction (a **goal**), the work toward it (a **project**), and, underneath both, the to-dos that do the actual work (see [To-dos](/pages/system/help/projects/todos)).

**A goal is a direction.** Open **Projects** in the top bar and pick **New goal**. A goal says what the neighborhood is working toward — it has a title, an optional description, and an audience, but no dates and no status: a goal is a *direction*, not a scheduled thing. A goal is the umbrella the rest hangs under.

**A project is a stretch of work toward a goal.** Pick **New project**. A project has a title, an optional description, optional start and due dates, an optional status, and an audience. A project points at the goal it serves — but a project with no goal is a standalone project, and both are fine.

**To-dos are the work inside the stretch.** To-dos are where the actual work gets done — assigned, tracked, moved across boards. See [To-dos](/pages/system/help/projects/todos) for the to-do walk-through, and [Boards](/pages/system/help/projects/boards) for the board view of them.

**What this page is not.** It does not replace [To-dos](/pages/system/help/projects/todos) or [Boards](/pages/system/help/projects/boards) — those are the work-items themselves. This page is the layer *on top*: the direction, and the stretch of work that goes toward it.

By default a goal and a project are visible to everyone in the community. You can narrow who can see one in the audience section, the same way you do for a post. What a goal or project is written in, and who may translate it, follows the same rules as a post — see [Language](/pages/system/help/language) and [Translators](/pages/system/help/translator).
