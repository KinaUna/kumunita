## Calendar

The **Calendar** is the events list arranged by date, so you can see what is coming up in the neighborhood at a glance instead of scrolling a list. It lives in the **Calendar** tab of Events.

**To see it.** Open **Events**, then the **Calendar** tab. The month shows each day, and the events on that day.

**To move through time.** Step to the previous or next month. The events that fall in that month are what you see — the same events as the **Events** list, arranged by their date rather than by recency.

**To join one.** Open an event from the calendar and pick **RSVP**, exactly as on the events list — see [Events](/pages/system/help/events).

The calendar and the list are the same events. If you can see an event in one, you can see it in the other; if it is hidden from you, it is hidden from both.
