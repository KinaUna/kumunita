## Items per page

**Items per page** is how many things a list shows before you scroll to the next page — posts in the feed, to-dos in the list, entries in the directory.

**To set yours.** Open **Settings → Items per page** and pick a number. It is saved on your account.

**What it changes.** The length of every list and feed you read. A larger number shows more at once (fewer page-turns); a smaller one shows less (faster pages). It is a reading preference, not a limit — it never changes *what* you can see, only how much is on a page.

**What it doesn't change.** It does not hide anything and it does not change who can see a thing — the audience still decides that. It is purely a matter of how the list is paginated for you.

If you never set one, the platform's default applies.
