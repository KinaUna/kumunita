## Notizen

Eine Notiz ist ein kurzer Text von dir, der an etwas auf der Plattform hängt — an einen Beitrag, eine Gruppe, eine Veranstaltung, eine Seite, ein Ziel oder Projekt, eine Aufgabe, ein Board, ein Dokument, eine Ankündigung oder ein Inventar-stück. Eine Notiz gehört dir, nur für dich — sie erscheint nicht an der Sache, an die sie hängt, und niemand anderes sieht sie.

**Eine hinzufügen.** Öffne die Sache und klicke auf **Notiz hinzufügen**, schreibe deine Notiz und speichere. Später liest der Knopf **Notiz ansehen**; öffne sie, um sie zu ändern oder zu löschen.

**Deine finden.** Öffne **Notizen** in der oberen Leiste. Deine Notizen sind nach der Art der Sache gruppiert, die sie betreffen. Du kannst sie auch in Ordnern sammeln — einen Ordner anlegen und eine Notiz hineinbewegen — um eine Sammlung zu einem Thema beisammenzuhalten.

Eine Notiz ist eine Erinnerung für dich selbst, kein Kommentar für den Autor oder die Leser der Sache.
