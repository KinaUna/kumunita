## Boards

Ein Board ist eine Wand mit Spuren, die To-dos anordnet, damit du auf einen Blick siehst, wo die Arbeit steht. Es lebt im **Boards**-Tab von Projekten.

**So erstellst du eines.** Öffne den **Boards**-Tab und wähle **Neues Board**. Gib ihm einen Namen und füge dann die Spuren hinzu, die du willst.

**Spuren.** Eine Spur ist eine vertikale Spalte auf dem Board. Eine Spur kann einen Status tragen — ein To-do, das hineinbewegt wird, übernimmt diesen — und ein optionales Limit, wie viele To-dos sie hält. Nutze Spuren, um zu *zeigen*, wo die Arbeit ist, nicht um sie zu sperren: eine Karte zu bewegen ist ein Blick auf den Zustand, kein Schloss darauf.

**Ein To-do bewegen.** Öffne ein To-do und wähle seine Board-Spur, oder bewege es auf dem Board. Das To-do behält alles, was es hatte (Zuständiger, Unteraufgaben, Kommentare) — nur seine Spur und ein spurgetragener Status ändern sich.

**Boards und To-dos sind dasselbe, zwei Ansichten.** Ein To-do ist die Arbeitseinheit; ein Board ist eine Anordnung von To-dos. Ein To-do kann auf einem Board stehen oder auch nicht — beides ist gültig. Siehe [To-dos](/pages/system/help/projects/todos).

Standardmäßig sieht ein Board jeder im Viertel; du kannst eingrenzen, wer es sieht, im Zielgruppen-Bereich — so wie bei einem Beitrag.
