## Admin: Gemeinschaften

Der **Gemeinschaften**-Tab ist, wo eine Global-Admin die Gemeinschaften des Viertels hält — die benannten Gruppen von Bewohnern (ein Gebäude, eine Straße, ein gemeinsames Projekt), auf die eine Zielgruppe eingeschränkt werden kann.

**So fügst du eine hinzu oder bearbeitest du sie.** Erstelle eine Gemeinschaft, gib ihr einen Namen und eine kurze Beschreibung, und bearbeite sie jederzeit. Eine Gemeinschaft ist eine Organisationseinheit — kein Feed und keine Gruppe, sondern das, worauf eine Gruppe, ein Beitrag oder eine Zielgruppe verweisen kann.

**So setzt du die Zugehörigkeit.** Entscheide, welche Bewohner zu welcher Gemeinschaft gehören. Zugehörigkeit macht aus einer Gemeinschaft eine echte Zielgruppe: ein auf eine Gemeinschaft beschränkter Beitrag wird von ihren Mitgliedern (und der Autorin) gesehen, nicht vom ganzen Viertel.

**Was sie nicht ist.** Eine Gemeinschaft ist nicht dasselbe wie eine [Gruppe](/pages/system/help/groups) (eine Gruppe hat ihren eigenen Feed und ihren Mitglieder-Tab) oder ein [Tag](/pages/system/help/tags) (ein Tag ist ein Etikett auf Inhalt). Eine Gemeinschaft ist die Einheit von *wer wer ist* im Viertel. Siehe [Zielgruppe](/pages/system/help/audience) dafür, wie eine Gemeinschaft als Zielgruppen-Wahl erscheint, wenn du postest.
