## Einträge pro Seite

**Einträge pro Seite** bestimmt, wie viele Dinge eine Liste zeigt, bevor du zur nächsten Seite scrollest — Beiträge im Feed, To-dos in der Liste, Einträge im Verzeichnis.

**So setzt du deine.** Öffne **Einstellungen → Einträge pro Seite** und wähle eine Zahl. Sie wird auf deinem Konto gespeichert.

**Was sie ändert.** Die Länge jeder Liste und jedes Feeds, die du liest. Eine größere Zahl zeigt mehr auf einmal (weniger Seitenumblätterungen); eine kleinere zeigt weniger (schnellere Seiten). Es ist eine Lese-Einstellung, kein Limit — es ändert nie *was* du sehen kannst, nur wie viel auf einer Seite steht.

**Was sie nicht ändert.** Sie versteckt nichts und ändert nicht, wer etwas sehen kann — die Zielgruppe entscheidet das. Es geht rein darum, wie dir die Liste paginiert wird.

Wenn du keine wählst, gilt die Standard der Plattform.
