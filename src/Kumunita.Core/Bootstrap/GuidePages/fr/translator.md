## Traducteurs

Un **traducteur** est un résident à qui est accordé le droit d'ajouter et de modifier une version d'une langue d'une chose que la plateforme porte déjà — une page, une description de groupe, un nom de communauté, ou un message ou une réponse.

**Ce qu'un traducteur peut faire.**
- **Ajouter une traduction** d'une page, d'un groupe, d'un nom de communauté, d'un message ou d'une réponse — dans une langue que l'instance a activée.
- **Modifier une traduction** qu'il a ajoutée, à tout moment.

**Ce qu'un traducteur ne peut pas faire.**
- **Changer l'original.** Les mots de l'auteur sont ceux de l'auteur ; un traducteur ajoute une version d'une langue à côté, jamais par-dessus.
- **Traduire pour la machine.** Une traduction est un acte humain — la plateforme ne traduit jamais par machine l'écriture d'un résident, et un traducteur n'insère pas une sortie machine comme si c'était la sienne.
- **Remplacer un administrateur global.** Un traducteur n'a aucun droit sur les propres pages de la plateforme, sur la modération, ou sur l'adhésion d'un groupe — ce sont les lanes d'un administrateur global (ou, si c'est concédé, d'un modérateur).

Le travail d'un traducteur est visible : l'interface montre, à côté d'une chose traduite, la personne qui a ajouté cette traduction, et l'original est toujours à un clic.
