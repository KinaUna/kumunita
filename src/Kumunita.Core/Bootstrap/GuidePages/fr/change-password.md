## Changer le mot de passe

Changer ton **mot de passe** est comment tu définis un nouveau pour te connecter à ton compte.

**Comment le changer.** Ouvre **Paramètres → Changer le mot de passe**. Entre ton mot de passe actuel, puis le nouveau, et confirme. Il est enregistré sur ton compte.

**Ce qu'il fait.** À partir de là, tu te connectes avec le nouveau mot de passe ; l'ancien cesse de fonctionner. Si tu es connecté sur d'autres appareils, ils sont invités à se reconnecter.

**Si tu l'oublies.** Un mot de passe oublié est géré par le flux de réinitialisation de la plateforme (ou par un administrateur global, pour un compte enfant — voir [Comptes enfants](/pages/system/help/child-accounts)). Changer un mot de passe n'est pas la même chose que supprimer un compte — ton compte et ton contenu restent intacts ; seul le secret de connexion change.

Ton mot de passe est à toi. Personne d'autre sur la plateforme — y compris un administrateur — ne peut le lire ; il est seulement utilisé pour vérifier qu'il correspond quand tu te connectes.
