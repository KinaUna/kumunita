## Notes

Une note est un court texte qui est à toi, rattaché à quelque chose sur la plateforme — un message, un groupe, un événement, une page, un objectif ou un projet, une tâche, un tableau, un document, une annonce, ou un article d'inventaire. Une note est la tienne, pour toi — elle n'apparaît jamais sur la chose à laquelle elle est rattachée, et personne d'autre ne peut la voir.

**En ajouter une.** Ouvre la chose et clique sur **Ajouter une note**, écris ta note, et enregistre. Plus tard, le bouton dit **Voir la note** ; ouvre-la pour la modifier ou la supprimer.

**Trouver les tiennes.** Ouvre **Notes** dans la barre du haut. Tes notes sont regroupées par le type de chose à laquelle elles se rapportent. Tu peux aussi les rassembler dans des dossiers — crée un dossier, puis déplace une note dedans — pour garder une collection sur un même sujet rassemblée.

Une note est un rappel pour toi, pas un commentaire pour l'auteur de la chose ni pour ses lecteurs.
