## Admin : communautés

L'onglet **Communautés** est où un administrateur global tient les communautés du quartier — les groupes nommés de résidents (un bâtiment, une rue, un projet commun) auxquels le contenu peut être restreint.

**Pour en ajouter ou modifier une.** Crée une communauté, donne-lui un nom et une courte description, et modifie-les à tout moment. Une communauté est une unité d'organisation — ni un flux ni un groupe, mais ce sur quoi un groupe, une publication ou un public peuvent pointer.

**Pour définir l'adhésion.** Décide quels résidents appartiennent à quelle communauté. L'adhésion est ce qui fait d'une communauté un public réel : une publication restreinte à une communauté est vue par ses membres (et l'auteur), pas par tout le quartier.

**Ce qu'elle n'est pas.** Une communauté n'est pas la même chose qu'un [groupe](/pages/system/help/groups) (un groupe a son propre flux et son onglet membres) ou un [tag](/pages/system/help/tags) (un tag est une étiquette sur le contenu). Une communauté est l'unité fonctionnelle de *qui est qui* dans le quartier. Voir [Public](/pages/system/help/audience) pour comment une communauté apparaît comme un choix de public quand tu publies.
