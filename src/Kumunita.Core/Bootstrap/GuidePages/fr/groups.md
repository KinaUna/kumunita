## Groupes

Un groupe rassemble les riverains autour d'une chose commune — un bâtiment, un projet, un loisir.

**Public et privé.** Un groupe **public** est ouvert à tous ; un groupe **privé** est sur invitation, et seul ses membres peuvent le voir, y poster ou le prendre dans l'audience d'un message. Les deux types t'aident à organiser le quartier.

**Pour en créer un.** Choisis **Créer un groupe**, donne-lui un nom et une courte description, et choisis s'il est public ou privé. Tu peux modifier le nom et la description à tout moment.

**Messages de groupe.** Un groupe a son propre fil. Un message que tu fais dans un groupe est vu par les membres du groupe (et par tous ceux que tu ajoutes à son audience). Tu peux poster dans un groupe comme dans le fil communautaire — le sélecteur d'audience contient simplement le groupe.

**Quitter.** Un membre peut quitter un groupe ; le groupe garde ses messages. Un propriétaire de groupe ou un administrateur global peut retirer un membre ou fermer un groupe.
