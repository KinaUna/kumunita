## Tableaux

Un tableau est un mur de colonnes qui arrange les tâches, pour que tu voies d'un coup d'œil où en est le travail. Il vit dans l'onglet **Tableaux** de Projets.

**Comment en créer un.** Ouvre l'onglet **Tableaux** et choisis **Nouveau tableau**. Donne-lui un nom, puis ajoute les colonnes que tu veux.

**Colonnes.** Une colonne est un pilier vertical du tableau. Une colonne peut porter un statut — une tâche qui y entre reprend ce statut — et une limite optionnelle sur le nombre de tâches qu'elle retient. Utilise les colonnes pour *montrer* où est le travail, pas pour le verrouiller : déplacer une carte est une vue de l'état, pas un verrou dessus.

**Déplacer une tâche.** Ouvre une tâche et choisis sa colonne de tableau, ou déplace-la sur le tableau. La tâche garde tout ce qu'elle avait (assigné, sous-tâches, commentaires) — seule sa colonne, et le statut porté par la colonne, changent.

**Tableaux et tâches sont la même chose, deux vues.** Une tâche est l'unité de travail ; un tableau est une disposition de tâches. Une tâche peut être sur un tableau ou en dehors — les deux sont valides. Voir [Tâches](/pages/system/help/projects/todos).

Par défaut, un tableau est visible par tous dans la communauté ; tu peux restreindre qui le voit dans la section public — de la même manière que pour une publication.
