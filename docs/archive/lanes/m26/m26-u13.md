## Understanding

This unit applies the **U10 `_Sort` pattern** to the **announcements**,
**documents**, and **inventory** list surfaces — the view-model `Sort` field
+ the `@Html.Partial("_Sort", ...)` + the pager-carry + the `SortSpec`
threading — with the **pinned Web tests** (U2 §2.6). **Reuse U10's
`SortViewModel`/`_Sort` verbatim — do not fork.** Documents offer the extra
`size` key; inventory offers the extra `name` key (C-SORT·1/F9).

## Rules
- **Reuse** U10's `SortViewModel`/`_Sort` verbatim (C-SORT·1 — each surface
  passes **its own** allowed-key `Options`; documents' `size` + inventory's
  `name` are offered in **their** `Options` only, F9).
- **C-SORT·8** — each surface's pager carries **its own** `sort`/`dir`.
- **C-SORT·2** — the `null`/no-sort pin is unchanged.
- **C-SORT·4** — authorization is **untouched**; **do not** touch document
  access control (ADR 0122) or the inventory owner-kind filter (frozen).
