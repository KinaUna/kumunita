## Understanding

This unit applies the **U10 `_Sort` pattern** to the **search** surface
(`/search` — the `SearchController.Index` action + `SearchIndexViewModel` +
`Views/Search/Index.cshtml`, a single paged surface over the ten content
surfaces) — the view-model `Sort` field + the `@Html.Partial("_Sort", ...)` +
the pager-carry + the `SortSpec` threading into `SearchService.
SearchSurfaceAsync` — with the **pinned Web tests** (U2 §2.6). **Reuse U10's
`SortViewModel`/`_Sort` verbatim — do not fork.** **Relevance is NOT a sort
option** (M8 frozen — the `Options` are the date/title keys only, a named
non-decision).

- **Reuse** U10's `SortViewModel`/`_Sort` verbatim (C-SORT·1 — the search
