## Understanding

This unit adds the **additive `SortSpec? sort = null`** parameter to the
**three event seams** (`EventService.ListUpcomingAsync` / `ListPastAsync` /
`ListGroupEventsAsync`) + the `IEventService` seams, applying the events
allowlist (U2 §2.2: upcoming `start` default **asc**, past `start` default
**desc**, `created`, `title`) + the tie-breaker, and the **pinned Core tests**
(U2 §2.5, the `Event*_*` set). **`null` preserves each sub-surface's current
direction exactly (C-SORT·2)** — upcoming asc, past desc — do **not** collapse
them to one.

## Rules
- **C-SORT·2** — `null` keeps each sub-surface's current direction; the
  **upcoming-asc** vs **past-desc** split is **preserved** (do not collapse
  them).
- **C-SORT·4** — the `CanSeeAsync` call is **unchanged** (no new audit row).
- **C-SORT·5** — the tie-breaker `.ThenBy(e => e.Id)` is present on every
  non-null sort path.
- **Do not** touch the group-event audience gate (frozen) or the
  recurring-event lane (M18, frozen).
- **Do not** change the `HasMore`/paging computation.
