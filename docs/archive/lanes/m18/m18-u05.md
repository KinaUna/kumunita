# M18 · U05 — The composer recurrence picker (the create / edit form)

**U02 and U04 must be done first** (the Core `CreateAsync` / `UpdateAsync` lanes already accept the `Recurrence` field on `CreateEventRequest` / `UpdateEventRequest` — this unit wires the form to it). This unit is **Web-only**; the exit gate is `dotnet build Kumunita.slnx -c Debug` + `dotnet exec tests\Kumunita.Web.Tests\bin\Debug\net10.0\Kumunita.Web.Tests.dll`, both green.

## Goal

Add the recurrence picker to the **single** composer / edit form: a `Recurrence` select (None / Daily / Weekly / Monthly / Yearly), an `Interval` number input (≥ 1, default 1), and a `Count` / `Ends` radio ("Ends after" vs. "Ends on"). The picker posts plain form fields (no body-parse — the `Location` / `Capacity` shape); the controller maps them onto the `CreateEventRequest` / `UpdateEventRequest.Recurrence` field the Core lane (U02 / U04) already reads. The picker is **hidden** on the edit lane for a non-head row (a non-head row's `RecurrenceRule` is `null` — only the head carries the rule, D3).

Locked decisions: **D7** (the composer affordance), **D3** (the head is the only row that carries the rule), **F1** (the picker shape). The `kw-l` key *names* are locked by U00 (D9); the *string values* land in U07 — this unit references the key names but does not author the JSON.

## Deliverables (4 files)

1. **`src/Kumunita.Web/Models/EventEditorModel.cs`** (edit) — add the three picker fields (form-bound plain fields, the `Location` / `Capacity` shape):

   ```csharp
   // M18 (ADR 0119, D2/D7) — the composer's recurrence picker. Plain form fields
   // (the <see cref="Location"/> / <see cref="Capacity"/> shape — display / author
   // metadata, no body-parse). The controller maps these onto the
   // <see cref="Kumunita.Core.Events.CreateEventRequest"/> /
   // <see cref="Kumunita.Core.Events.UpdateEventRequest"/> .Recurrence field (U02 /
   // U04). <c>Recurrence</c> is a string form field ("none" / "daily" / "weekly" /
   // "monthly" / "yearly"); <c>Interval</c> is a number (≥ 1); <c>EndsAfterCount</c>
   // and <c>EndsOnDate</c> are the two radio-exclusive end conditions (the author
   // picks one; the other posts null / empty).
   [Display(Name = "events.recurrence.none")] public string Recurrence { get; set; } = "none";
   [Range(1, 365)] public int? RecurrenceInterval { get; set; } = 1;
   public int? EndsAfterCount { get; set; }
   public DateTime? EndsOnDate { get; set; }
   /// <summary>
   /// The row's existing series state (set by the controller on the edit lane):
   /// <c>true</c> when this row is a **non-head** occurrence (<see
   /// cref="Kumunita.Core.Events.Event.RecurrenceHeadId"/> non-null) — the
   /// composer **hides** the picker in that case (only the head carries the rule,
   /// D3). <c>false</c> on the create lane and on a head row.
   /// </summary>
   [BindNever] public bool IsNonHeadOccurrence { get; set; }
   ```

   In `IsValid()`: when `Recurrence != "none"` (case-insensitive), require `RecurrenceInterval >= 1` **and** exactly one of `EndsAfterCount` / `EndsOnDate` set (the D2 mutual-exclusion-in-intent; if both or neither are set, add a model error keyed `events.recurrence.need_end`). A `Recurrence == "none"` row validates exactly as today (the zero-change branch).
