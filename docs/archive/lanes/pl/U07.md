# U07 — Project detail + composer + edit

**Goal:** add the **project authoring surface**: `GET
/projects/projects/{id}` (the detail — title, description rendered
markdown, **status**, **start / due dates** (`kw-dt`), the **goal link**
when associated (D10 — `pl.project.goal_link`), audience, **associated
to-dos + boards** via the U04 `projectId` filter lanes, created date,
author) + `GET /projects/projects/new` / `POST /projects/projects` (the
composer — Title, Description `bindRichEditor`, Status text field,
StartAt / DueAt `datetime-local`, the **goal picker**, audience trio,
language + component pickers) + `GET /projects/projects/{id}/edit` /
`POST /projects/projects/{id}` (the edit — standing creator ∪
GlobalAdmin, the `UpdateProjectRequest` full-update shape with
`ClearGoal`). **`dotnet build` + `npm run build` clean; Web tests pass.**

**Entry reads:** U06's handoff section (the goal detail / composer exist
+ the `pl.goal.*` keys + `dotnet build` clean);
`docs/design/pl-goals-projects-design.md` §5 (the project detail /
composer wire — the field order, the goal-picker shape, the associated
to-dos / boards sections) + §9.1 (the `pl.project.*` keys this unit
registers);
`src/Kumunita.Web/Controllers/ProjectsController.cs` (after U06 — the
goal actions' shapes + the M5 `BoardNew` / `BoardEdit` full-update POST
shapes to mirror); `src/Kumunita.Web/Views/Projects/BoardNew.cshtml` /
`BoardEdit.cshtml` (the composer markup to mirror);
`src/Kumunita.Core/Projects/IProjectService.cs` (the U03 project seams
— the exact signatures + the `CreateProjectRequest` /
`UpdateProjectRequest` DTO shapes with `ClearGoal` + the ADR 0079
`StartAt` / `DueAt` shapes; the U04 `projectId` filter on
`ListTodosAsync` / `ListBoardsAsync` — the associated-lists lanes the
detail view calls);
`src/Kumunita.Core/Localization/KnownTranslationKeys.cs` (the `pl.*`
keys registered so far — this unit adds its own `pl.project.*` set only).
