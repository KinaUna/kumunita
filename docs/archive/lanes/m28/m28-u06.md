# M28 U06 — The guardian's Detail "Time limits" section + the `ChildAccountItem` `HasTimeLimits` badge + the surface tests

## Context (self-contained)

M28 = **Guardian time limits**: a **guardian** sets a per-child schedule
(hours × days-of-week, Blocked/Allowed polarity) that **gates the child's
whole-platform access** (a sign-out, the `BlockedAccountMiddleware` analog).
This is the **inverse of the M20 quiet lane** (ADR 0121) but on the **GU
guardian surface** (ADR 0028). U00 locked the design doc + ADR 0151. U01
created the doc + enum. U02 authored the pure evaluator. U03 added the three
seams + implementation. U04 shipped the `TimeLimitMiddleware`. U05 landed
the closed `kw-l` key set (× 4).

**U06 ships the guardian's user-facing surface** (D6) — a "Time limits"
section on the child's `/me/children/{childId}` Detail page (the GU Detail
page's existing suspend / membership / invitation sections as the shape) +
the `ChildAccountItem` `HasTimeLimits` badge (the `Blocked` flag precedent)
+ the 3 F5-surface tests. **The lane's user-facing surface.**

**The surface shape (D6, the register's "no self-lane" rule):**
- The section is on the **child's Detail page** (`/me/children/{childId}`),
  NOT a new route (the GU Detail page's existing sections as the shape).
- GET seeds the form with the current schedule (`GetChildTimeLimitAsync` —
  the U03 guardian-gated read).
- POST saves / clears (`SetChildTimeLimitAsync` — the U03 guardian-gated
  write, one audit row, the `guardian.timelimit.flash_saved` / `_cleared`
  flash).
- The `ChildAccountItem` GU Index card gains a **4th field**
  (`HasTimeLimits`) — the `Blocked` flag precedent (U06 re-pins the 3-field
  → 4-field record + the GU Index test).
- **No `/settings/time-limit`** (the child cannot set/clear their own —
  C-M28·7, the "no self-lane" rule).
- A GlobalAdmin reaches the same write seam (the G·5 safety valve) — the
  Detail page is the **single** surface; the GlobalAdmin standing is resolved
  by the seam (the U03 `SetChildTimeLimitAsync` gate = active `GuardianLink`
  ∪ GlobalAdmin), not a separate admin page.

## Rules

- The section is on the **child's Detail page** (NOT a new route — D6).
- **No `/settings/time-limit`** (the child cannot set/clear their own —
  C-M28·7, the "no self-lane" rule).
- The `ChildAccountItem` re-pin is **3-field → 4-field** (the
  `HasTimeLimits` badge) — U06 updates the GU Index test that asserts the
  3-field shape (the `Blocked` flag precedent).
- The `SaveTimeLimits` POST is the **`LocaleController.SaveQuiet`** shape
  (the `enabled` / `mode` / `hours` / `daysOfWeek` / `clear` form fields +
  the `TempData["info"]` flash idiom).
- The `kw-l` keys are bound to U05's `guardian.timelimit.*` set (NOT the
  M20 `settings.quiet.*` keys — those are the notification lane's,
  unchanged).
- The GlobalAdmin reaches the same write seam (the G·5 safety valve) — the
  Detail page is the **single** surface; the GlobalAdmin standing is resolved
  by the U03 `SetChildTimeLimitAsync` gate (active `GuardianLink` ∪
  GlobalAdmin), not a separate admin page.
