## Goal

D1 + D2 rendered as code (the **export** half):

- **`TranslationBulkExporter`** — a **pure function** (no session, no
  audit, no HTTP — the `IcsWriter` "BCL-only, pure, closed subset"
  discipline) that turns the closed-set matrix + column order + per-key
  `source` reference into the bundle `string`: the marker row
  (`# kumunita-translation-bundle/1`), the column header
  (`key,source,en,<SortOrder codes…>`), the body rows in
  `AllKeys` declaration order, RFC-4180 quoting, CRLF, a missing stored
  row → **empty cell** (never a synthetic row, C-M15·1).
- **`GetBulkTranslationMatrixAsync(CancellationToken ct = default) →
  IReadOnlyList<TranslationBulkRow>`** on `ILocalizationService` — an
  **additive read seam** (one `GetTranslationsForAsync` round-trip per
  catalog code over `AllKeys`; a missing row → a missing cell, never
  null in the row — the M·12 floor). **No audit row — a read.**
- **4 pinned tests** (names verbatim from the design doc).
