# U10 — the **board Razor views** (list / detail / composer) + the **board action dropdown**

**Goal:** create the **three board Razor views** under
`src/Kumunita.Web/Views/Projects/` — `BoardIndex.cshtml`,
`BoardDetail.cshtml`, `BoardNew.cshtml` — rendering the
**`BoardIndexViewModel`** / **`BoardDetailViewModel`** / **`BoardEditorModel`**
view models U08 created; and wire the **board action dropdown** (delete board)
+ the **card action dropdown** (assign / add subtask / delete / copy-to /
move-to / move-up / move-down / move-left / move-right) on the board detail
view — the **Bootstrap `dropdown`** shape (the `_AccountNav.cshtml` pattern,
the **M2/M3/M4** shared nav-dropdown idiom). The views are **server-rendered**
(Razor Pages / MVC, the **ADR 0001** stack pin); the **F2 / F3 / F4 / F5 /
F6 / F10** FACES are the **service's** (the views render what the service
returns — the **C3** pin). The board `Description` renders through the **one**
`bindRichEditor` (the **ADR 0031** WYSIWYG editor pin — the
`data-rich-editor` + `rich-editor.js` module shape, the **M3/M4** precedent).
The audience grants render through the **`_GrantPickers`** partial (the
**M2/M3/M4 shared** grants-picker shape). All timestamps render through the
**`kw-dt`** TagHelper (the **ADR 0019 / 0020** pin). All labels use **`kw-l`**
keys from the **`projects.board.*`** + **`projects.todo.*`** blocks.
**Key story:** same as U09 — the design doc **§2.6** pins the **floor** of
18 keys; the views + board TS (U09 / U10 / U11) reference a **larger** set;
**U11 ships the *complete* `kw-l` key set** (the §2.6 floor + the
view/TS superset) in all four seeded languages (en / de / fr / da, English
as the fallback). U10's views may reference the full set; U11 is the unit
that adds them to `KnownTranslationKeys.cs`. Build green.
