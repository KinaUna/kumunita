## Goal

M13's scope (the register's Understanding, locked): the **operator's
feedback loop** — two deliverables, both operator-local:

1. **A file log sink** (BCL-only, daily rotation, retention at boot) — the
   host's logs land in dated files under a configurable directory, with a
   pinned day-count retention deleted at boot. The console sink stays.
2. **A usage analytics surface** — one `UsageEvent` document captured by a
   thin middleware (route **template** + `ActorId` or empty + `At`),
   aggregated by a Core service over a pinned 7/30/90-day window, rendered
   on one GlobalAdmin-gated admin section (`/admin/analytics`), with a CSV
   export (`/admin/analytics/export`). **No per-account data is ever
   rendered** (C-M13·3); **no third-party telemetry** (C-M13·1,
   SECURITY.md §5).

Author the primary tier and the decision record, locking the register's
[PROPOSED] set (D1–D8) — or recording any **veto** the user made, with the
locked text replacing it:

- **D1 · Capture shape.** `UsageEvent { Id, At, ActorId, RouteTemplate }`
  + a pure `UsageCapturePolicy.Decide(UsageCaptureInput) →
  UsageCaptureDecision` in `Kumunita.Core.Usage` + one Web middleware.
  **No** status code, no email, no body, no UA, no IP. Skip when no
  endpoint (true 404) or static file. The `ActorId` is the
  `Kumunita.Core.Identity.ClaimTypes.Subject` claim value, empty when
  anonymous. **You lock the exact `UsageCaptureInput` / `UsageCaptureDecision`
  POCO shapes** (the fields, the skip rules) verbatim in the doc.
- **D2 · Surface-key normalization.** A pure `SurfaceKey.Map(string
  routeTemplate) → string` in Core — the top-level segment → surface-key
  map (a **closed list** you pin verbatim in the doc: `posts`, `events`,
  `groups`, `admin`, `messages`, `todos`, `boards`, `projects`, `search`,
  `about`, `terms`, `help`, `privacy`, `conduct`, `language`, `settings`,
  `account`, `my`, `pages`, `community`, `attachments`, `content-image`,
  `notifications`, `calendar`, `whats-new`, `health`), `"other"` fallback.
  **You write the full map verbatim** (U02's `SurfaceKey` class copies it).
- **D3 · Aggregation seam.** `IUsageAnalyticsService` in Core:
  `GetWindowAsync(int windowDays)` → `UsageAnalyticsResult { WindowDays,
  Total, AuthenticatedTotal, AnonymousTotal, DistinctActors, SurfaceRanking }`
  + `GetCsvRowsAsync(int windowDays)` → `IReadOnlyList<UsageCsvRow>`.
  `windowDays` pin: 7/30/90; unknown → `ArgumentOutOfRangeException`.
  `SurfaceRanking` sorted by `Total` descending, ties `Surface` ascending.
  **`NewSignups` is dropped** — `User : IdentityUser` has no created-at
  column (only `ExternalId`); named deferral, own ADR. **You lock the exact
  POCO shapes** (`UsageAnalyticsResult`, `SurfaceRow`, `UsageCsvRow`)
  verbatim.
- **D4 · The admin surface.** `AdminAnalyticsController`

  IUsageAnalyticsService analytics)`. `GET /admin/analytics?window=30`

  → CSV (`text/csv; charset=utf-8` + `Content-Disposition: attachment;
