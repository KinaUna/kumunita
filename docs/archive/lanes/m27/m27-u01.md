# M27 U01 — Framework: `IUserPortabilityService` + the resident-scope marker + the shell

## Context (self-contained)

M27 = **user-scoped portability**: a resident exports/imports **their own
authored data** and resolves per-entity conflicts on import. M27 is a **lane
on the M11 operator portability surface** (the `Kumunita.Core/Portability/`
context) — it reuses M11's frozen archive/manifest/inventory machinery and
adds a resident-scoped service. U00 authored + locked the design doc
(`docs/design/m27-user-scoped-portability-design.md`) + ADR 0148. U01 renders
**D2** (the resident-scope manifest marker) + **D7** (the service shell) as
code: the `IUserPortabilityService` seam + the `UserPortabilityService` shell
(the ctor + the three method signatures, bodies `NotImplementedException`
until U03–U06 fill them) + the **one additive optional** manifest field.
**No export/import logic yet** (U02–U06 own that). **No new authorization
surface** (C-M27·7). **No new document, no new `*DocTypes` surface, no
migration** (D7).

## Goal

Create the `IUserPortabilityService` seam + the `UserPortabilityService` shell
+ the `UserPortabilityImportPlan` / `UserPortabilityImportResult` /
`UserPortabilityEntityResolution` POCO records (the closed shapes from the
design doc §2.1) + the **one** additive optional `PortabilityManifest` field
(the D2 resident-scope marker) + register the service in
`DependencyInjection.cs`.

## Deliverables (≤ 4 files)

1. **`src/Kumunita.Core/Portability/UserPortabilityService.cs`** (new) —
   the `IUserPortabilityService` interface:
   - `Task<Stream> ExportAsync(string residentSubjectId, CancellationToken ct = default);`
   - `Task<UserPortabilityImportPlan> ClassifyAsync(string residentSubjectId, Stream archive, CancellationToken ct = default);`
   - `Task<UserPortabilityImportResult> ResolveAsync(string residentSubjectId, UserPortabilityImportPlan plan, IReadOnlyList<UserPortabilityEntityResolution> resolutions, CancellationToken ct = default);`
   - The `UserPortabilityImportPlan` record (the `clean`/`duplicate`/
     `conflict` classification result — the per-entity list + the per-entity
     reference-availability report).
   - The `UserPortabilityImportResult` record (the `Ok` + the closed failure
     set — the D4 apply outcome).
   - The `UserPortabilityEntityResolution` record (the resident's per-entity
     decision: `AddElsewhere` re-point or `Discard`).
   - The `UserPortabilityService` shell (the ctor over the frozen seams —
     `IDocumentStore`, `IUserInfoService`, `IMediaStore`, `IUserManager` — +
     the three method bodies as `throw new NotImplementedException()` until
     U03–U06).
2. **`src/Kumunita.Core/Portability/PortabilityManifest.cs`** (modify) —
   the **one** additive optional field (the D2 resident-scope marker:
   `public string? Scope { get; set; }` + `public string? ResidentSubjectId
   { get; set; }` — `null` = a plain M11 whole-instance archive). The
   `FormatVersion` + every existing field **unchanged**.
3. **`src/Kumunita.Core/DependencyInjection.cs`** (modify) — the
   `IUserPortabilityService` registration (next to the `IPortabilityService`
   registration, the same shape).
