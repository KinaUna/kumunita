# M27 U10 — Web-surface pins (the resident gate + the one-audit-row + the reads-emit-none)

## Context (self-contained)

M27 = **user-scoped portability**: a resident exports/imports **their own
authored data** and resolves per-entity conflicts. U07/U08 shipped the
`UserPortabilityController` + the index + import upload + resolve-review. U10
implements the **Web-surface pins** from the design doc §Web-pins (D8) in
`tests/Kumunita.Web.Tests/UserPortabilityControllerTests.cs` (the NSubstitute
no-Postgres shape, the M11 `AdminPortabilityController` test shape to mirror —
the gate + the one-audit-row-per-write + the reads-emit-none): the resident
gate (a non-resident / a resident reaching for someone else's data gets no
surface), the one `AccessAudit` row per write (`Via = Owner`), the reads (index,
resolve-review) emit **none** (C-M27·6), the kw-l keys resolve (C-M27·6/7).
**This unit does NOT record the gate** (U11) — each is a distinct unit.

## Goal

Implement the Web-surface pins (the names pinned in the design doc §2.6) in
`tests/Kumunita.Web.Tests/UserPortabilityControllerTests.cs`:
- `Web_Export_ResidentGate` — the resident self-lane gate (a non-resident gets
  no surface; the resident's own data only — the C-M27·6 pin).
- `Web_Export_OneAuditRow_ViaOwner` — the one `AccessAudit` row per write
  (`Via = Owner`, `TargetKind "portability"`, verb `export` — the C-M27·6 pin).
- `Web_Import_OneAuditRow_ViaOwner` — the `import` audit row.
- `Web_ImportResolve_OneAuditRow_ViaOwner` — the `import.resolve` audit row.
- `Web_Reads_EmitNoAuditRow` — the reads (index, resolve-review) emit **none**
  (the C-M27·6 pin — the ADR 0105 "reads never audit" shape).
- `Web_FailClosed_Render` — the fail-closed render of the
  `UserPortabilityImportResult` closed-failure set.
- `Web_KwL_KeysResolve` — the kw-l keys resolve (the C-M27·6 pin).
