# M27 U08 — Web: the per-entity resolve-review UI + the `ResolveAsync` POST + the resolve kw-l keys

## Context (self-contained)

M27 = **user-scoped portability**: a resident imports **their own authored
data** and resolves per-entity conflicts. U07 shipped the index + import
upload + export. U08 renders **D5/D4's Web surface, part 2**: the **resolve-
review** view (the `conflict` + `duplicate` entities the resident must decide
on — each with the "add elsewhere" picker (re-point the absent reference to a
group/component/page/tag the resident **is** a member of / own) or the
"discard" action) + the `POST /account/portability/import/resolve` (the
`ResolveAsync` delegation) + the resolve kw-l keys. **The resident's
per-entity choice — the lane's headline mechanic** (C-M27·4). **No auto-
merge** (the author's choice is absolute).

## Goal

Add the `POST /account/portability/import/resolve` action to
`UserPortabilityController` (the `ResolveAsync` delegation, the one-audit-row
`Via = Owner` verb `import.resolve`, the fail-closed render of the
`UserPortabilityImportResult`) + the `ResolveReview.cshtml` view (the per-
entity resolve review — each `conflict`/`duplicate` entity with the "add
elsewhere" picker — the `_AudienceEditor` group/component picker **reused** —
or the "discard" action; the one form-bound `UserPortabilityEntityResolution`
set the resolve POST submits) + the resolve kw-l keys in
`KnownTranslationKeys` × en/de/fr/da.
