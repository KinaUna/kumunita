# M19 · U04 — The `/admin/guests` GlobalAdmin controller + views + the `/admin` index affordance

**U00 must be done first** (the design doc's §7 / §9 lock the exact actions and
keys this unit consumes), **U01 must be done first** (the
`IIdentityService.GetGuestAccessAsync` / `SetGuestAccessAsync` seams this unit
rides), and **U03 must be done first** (the `kw-l` keys this unit renders). This
unit is **Web-only**; the exit gate is
`dotnet build Kumunita.slnx -c Debug` +
`dotnet exec tests\Kumunita.Web.Tests\bin\Debug\net10.0\Kumunita.Web.Tests.dll`,
both green. **It does not touch the Core seam (U01), the claim mint (U02), or
the `kw-l` keys (U03)** — it owns exactly one surface: the GlobalAdmin's
`/admin/guests` control plane.

## Goal

Implement the design doc's §7 (the `/admin/guests` admin surface — F1, D6), and
land the GATE-3 Web-layer tests (the controller delegates to the **single**
audited write lane; the GlobalAdmin standing is enforced at the boundary; the
affordance is hidden-not-disabled for non-GlobalAdmin actors).

The locked decisions this unit implements: **D6** (the `/admin/guests`
GlobalAdmin surface, the ADR 0050 precedent — a dedicated controller, gate
checked first on GET+POST, affordances hidden-not-disabled), **F1** (the admin
creates a guest and settles the standing), **C-M19·5** (the allowance write is
single + audited — the controller delegates to U01's lane, it does not store the
document itself).
