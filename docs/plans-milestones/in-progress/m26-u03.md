## Understanding

This unit adds the **pure Core** sort foundation — the `SortSpec` value
object + the `SortKeys.Parse` closed-allowlist parser (C-SORT·1/3) — in a new
`Kumunita.Core.Query` namespace, with the 6 pinned pure tests (U2 §2.5). It
is the **only** unit that touches the `Kumunita.Core.Query` namespace; every
later Core unit (U4–U9) builds a `SortSpec` from a seam's `?sort=`/`?dir=` and
applies the per-surface allowlist. **No list seam is touched in this unit**
(that is U4–U9).
