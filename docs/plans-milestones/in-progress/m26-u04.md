## Understanding

This unit adds the **additive `SortSpec? sort = null`** parameter to the
**three post-feed seams** (`PostService.ListFeedAsync` / `ListAllFeedAsync` /
`ListGroupFeedAsync`) + their interface seams, applying the post-feed
allowlist (U2 §2.2: `created` default desc, `modified`, `title`) + the
`.ThenBy(Id)` tie-breaker when `sort` is non-null, and the **pinned Core
tests** (U2 §2.5, the `PostFeed_*` set). **`null` preserves the current
order exactly (C-SORT·2).** The `HasMore`/`Total` computation is **untouched**.
