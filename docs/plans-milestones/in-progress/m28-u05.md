# M28 U05 — The closed kw-l key set (× 4) + the parity pin

## Context (self-contained)

M28 = **Guardian time limits**: a **guardian** sets a per-child schedule
(hours × days-of-week, Blocked/Allowed polarity) that **gates the child's
whole-platform access** (a sign-out, the `BlockedAccountMiddleware` analog).
This is the **inverse of the M20 quiet lane** (ADR 0121) but on the **GU
guardian surface** (ADR 0028). U00 locked the design doc + ADR 0151 (the
closed kw-l key list is pinned in the design doc §2.7). U01–U04 shipped the
doc + enum, the pure evaluator, the three seams + impl, and the
`TimeLimitMiddleware` (which references `account.time_limit.login_message`).

**U05 lands the closed `kw-l` key set** (the guardian Detail section + the
login landing) into **all four** `KnownTranslationKeys` dicts (en/de/fr/da)
+ keeps the parity pin green. **This is the M27 "all four dicts" lesson,
held** — a key missing from even one dict fails the
`KnownTranslationKeys_ParityTests` pin.

**The keys are a DISTINCT namespace** (NOT the M20 `settings.quiet.*` /
`admin.quiet.*` keys — those are the notification lane's, **unchanged**).
The M28 keys are `guardian.timelimit.*` + `account.time_limit.*`.

**The 14 keys (the D7 set, pinned in the design doc §2.7):**
- `guardian.timelimit.title` — the Detail section heading.
- `guardian.timelimit.description` — the section blurb.
- `guardian.timelimit.enabled` — the master checkbox label.
- `guardian.timelimit.mode_label` — the mode (Blocked/Allowed) radio label.
- `guardian.timelimit.mode_blocked` — the "Blocked" radio option.
- `guardian.timelimit.mode_allowed` — the "Allowed" radio option.
- `guardian.timelimit.hours_label` — the hours multi-select label.
- `guardian.timelimit.days_label` — the days-of-week multi-select label.
- `guardian.timelimit.save` — the Save button.
- `guardian.timelimit.clear` — the Clear button.
- `guardian.timelimit.flash_saved` — the "saved" flash.
- `guardian.timelimit.flash_cleared` — the "cleared" flash.
- `guardian.timelimit.badge_set` — the `ChildAccountItem` "time-limits
  set?" badge (the `Blocked` flag precedent).
- `account.time_limit.login_message` — the `?error=time-limit` login
  landing message (U04 references it).

## Goal

Add the closed `kw-l` key set (14 keys × 4 languages = 56 values) to **all
four** `KnownTranslationKeys` dicts (en/de/fr/da) + author the closed-set
parity pin. **The M20 `settings.quiet.*` / `admin.quiet.*` keys are
untouched** (the C-M28·5 "M20 untouched" pin).

## Rules

- The keys must land in **all four** dicts (the `KnownTranslationKeys_
  ParityTests` pin — a key missing from even one dict fails the build).
- The M20 `settings.quiet.*` / `admin.quiet.*` keys are **untouched** (the
  C-M28·5 "M20 untouched" pin — U05 adds the M28 keys to the **same** dicts
  but does **not** modify the M20 keys).
- The `en` values are the **canonical source text** (the design doc §2.7
  text verbatim) — the `de`/`fr`/`da` values are the **translations** (U05
  provides the 3 non-English values for each key).
- The keys are a **closed, enumerated set** (the D7 idiom, the
  `Onboarding_KwL_Set` / the M20 `settings.quiet.*` precedent) — no free-
  form key, no typo (the ADR 0120 D4 "closed, enumerated set" idiom).
