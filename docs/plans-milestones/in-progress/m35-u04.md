# M35 · U04 — Web: the `KioskController` + `KioskDisplayViewModel` + `Views/Kiosk/Index.cshtml` chrome-hidden display

**You are the U04 agent.** This is a **Web code** unit. It implements the
`/kiosk` signed-in display — the `KioskController` (`GET /kiosk` +
`GET /kiosk/slide`), the `KioskDisplayViewModel`, and the
`Views/Kiosk/Index.cshtml` chrome-hidden layout (the ADR 0104
`body.kmb-page-expanded` idiom — the navbar / footer / flash /
pinned-announcement hidden, the slide fills the viewport). The per-slide
section renders the **same** board / calendar / todos Razor partials the
board detail / calendar / todos index views use (the M35·6 pin — the kiosk
does not re-author them). **No** new `AccessAction` / `AccessVia` /
`Decide()` branch (the M35·1 / M35·3 pin). **No** new JS / npm package (the
M35·7 pin).

**Read the register first** —
`docs/plans-milestones/plan-m35-kiosk-mode.md` §U04 + the "one thing"
section M35·3, M35·5, M35·6. It locks the `KioskController` actions, the
`KioskDisplayViewModel` shape, the chrome-hidden layout, and the
"reused, not re-shape" + "reused, not re-authored" pins.

## Deliverables (≤ 4 files)

1. `src/Kumunita.Web/Controllers/KioskController.cs` — the thin controller.
   (a) `GET /kiosk` `[Authorize]` — reads the `KioskPlaylist` via
   `IKioskService.GetPlaylistAsync` (a `null` / empty row → the
   `kiosk.empty` message, the M35-8 FACE); builds the
   `KioskDisplayViewModel` (the `Views` + the two intervals + the **first
   slide's** resolved content — the first `KioskView`'s board / calendar /
   todos content via the **frozen** read seam for the **signed-in viewer**);
   renders `Views/Kiosk/Index.cshtml`. (b) `GET /kiosk/slide?slide=N&t=<ts>`
   `[Authorize]` — returns the **Nth** slide's content (the `KioskView` at
   index `N`) via the **frozen** read seam; a slide the viewer cannot see
   returns a **denied-shape** view model (the `kiosk.slide_denied` message —
   M35-5 FACE — **not** a 404). **No** new `AccessAction` / `AccessVia` /
   `Decide()` branch (the M35·1 / M35·3 pin — the frozen read seam is the
   authority).
2. `src/Kumunita.Web/Models/KioskDisplayViewModel.cs` — the display model:
   `IReadOnlyList<KioskView> Views` + `int ViewIntervalSeconds` + `int
   RefreshIntervalSeconds` + the resolved first-slide content (the board /
   calendar / todos view model the slide renders). A `bool HasSlides` member
   (the `kiosk.empty` gate). A `string? DeniedLabel` member (the
   `kiosk.slide_denied` shape).
3. `src/Kumunita.Web/Views/Kiosk/Index.cshtml` — the chrome-hidden display.
   A `body.kmb-page-expanded` class (the ADR 0104 chrome-hide idiom — the
   M35·6 pin) + a `#kiosk-stage` element (the `data-slides` /
   `data-view-interval` / `data-refresh-interval` `data-*` attributes the
   `kiosk.ts` reads) + the first slide's content (the board / calendar /
   todos partial `@await Html.PartialAsync`'d verbatim — the M35·6 pin) +
   the `kiosk.*` `kw-l` keys (the `kiosk.title` / `kiosk.empty` /
   `kiosk.slide_denied` / `kiosk.next_slide` / `kiosk.refreshed`) + a
   `.page-expand-close`-style exit affordance (the M35·6 pin — the ADR 0104
   idiom). **No** new JS, **no** new npm package (the M35·7 pin).
