**Deliverables (closed set):**
- **`tests/Kumunita.Core.Tests/NotificationServiceTests.cs`**
  (new) — the **12 FACES tests** (the `PostgresFixture`
  shape, the M4 / M5 service-test precedent), the
  **exact names** from design doc §6.4:
  - **F1** `Emit_PostReply_Stores_InboxRow_And_Stages_Email_For_Author`
    (the C-M6·2 / C-M6·7 pin: the `Notification` row is
    stored with `RecipientId == post.AuthorId`,
    `Kind == NotificationKinds.PostReply`, `ReadAt ==
    null`; the `IMailerStage.StageAsync` is called once
    with the `notification:post.reply:{replyId}`
    idempotency key, the recipient's
    `Profile.EmailLanguage` as the template language).
  - **F2** `Emit_GroupPost_Stores_InboxRow_Per_Member_Excluding_Author`
    (the C-M6·2 / C-M6·7 pin: one `Notification` row per
    group member, *excluding* the post's author; the
    per-member idempotency key
    `notification:group.post:{postId}:{member}`).
  - **F3** `Emit_EventRsvp_Stores_InboxRow_And_Stages_Email_For_Event_Author`
    (the C-M6·2 / C-M6·7 pin: the `Notification` row is
    stored with `RecipientId == event.AuthorId`,
    `Kind == NotificationKinds.EventRsvp`; the
    `IMailerStage.StageAsync` is called once).
  - **F4** `Emit_EventReminder_Stores_InboxRow_M4_Email_Unchanged`
    (the C-M6·5 pin: the `Notification` row is stored
    with `Kind == NotificationKinds.EventReminder`, the
    M6 inbox key
    `notification:event.reminder:{eventId}:{date}`; the
    M4 email key `remind:{eventId}:{userId}` is
    *unchanged* — the two keys coexist).
  - **F5** `Emit_ReportFiled_Stores_InboxRow_For_Content_Author`
    (the C-M6·2 / C-M6·7 pin: the `Notification` row is
    stored with `RecipientId == <the content's author>`,
    `Kind == NotificationKinds.ReportFiled`).
  - **F6** `Emit_ReportAssigned_Stores_InboxRow_For_Assigned_Moderator`
    (the C-M6·2 / C-M6·7 pin: the `Notification` row is
    stored with `RecipientId == assignedToModeratorId`,
    `Kind == NotificationKinds.ReportAssigned`).
  - **F7** `Emit_ReportResolved_Stores_InboxRow_For_Filer_And_Assignee`
    (the C-M6·2 / C-M6·7 pin: *two* `Notification` rows
    are stored — one for the filer, one for the
    assignee; the two distinct idempotency keys
    `notification:report.resolved:{reportId}:filed` +
    `notification:report.resolved:{reportId}:assigned`).
  - **F8** `Emit_TodoAssign_Stores_InboxRow_For_Person_Assignee`
    (the C-M6·2 / C-M6·7 pin: the `Notification` row is
    stored with `RecipientId == assigneeId`,
    `Kind == NotificationKinds.TodoAssign`; the
    person-only pin — the group / community assign is a
    *follow-on lane*, not a test failure).
  - **F9** `Emit_KindDisabled_Preferences_InboxRow_Stored_Email_Not_Staged`
    (the C-M6·7 pin: the `Notification` row is *still*
    stored — the inbox is the *record*; the
    `IMailerStage.StageAsync` is **not** called — the
    preference governs the *email*, not the *inbox*).
  - **F10** `Emit_SameIdempotencyKey_Second_Call_Is_NoOp`
    (the C-M6·4 pin: a *second* call to
    `EmitAsync` with the *same* idempotency key does
    **not** store a *second* `Notification` row and does
    **not** call `IMailerStage.StageAsync` a *second*
    time — the re-emission-is-a-no-op pin).
  - **F11** `ListInbox_And_CountUnread_Do_Not_Emit_AccessAudit_Row`
    (the C-M6·3 pin: the `ListInboxAsync` +
    `CountUnreadAsync` call sites do **not** call
    `IAuthorizationService` (the NSubstitute
    `DidNotReceive` assertion) and do **not** store an
    `AccessAudit` row (the `PostgresFixture` query
    assertion)).
  - **F12** `Emit_Uses_Recipient_EmailLanguage_Sender_Language_For_Ugc`
    (the C-M6·6 pin: the `IMailerStage.StageAsync`
    subject + body template language is the
    **recipient's** `Profile.EmailLanguage` (the ADR
    0061 resolution, the NSubstitute
    `IUserInfoService.GetProfileAsync` shape); the UGC
    snippet in the body is in the **sender's** authored
    language (the ADR 0018 pin — the `ITranslationProvider`
    call shape)).
