# U05 — the **`NotificationsController`** (the `/notifications` inbox + the unread-count poller + the mark-all-read POST + the preferences GET / POST) + the **view models**

**Goal:** create
**`src/Kumunita.Web/Controllers/NotificationsController.cs`**
with the **five routes** (the `/notifications` inbox, the
`/notifications/unread-count` poller endpoint, the
`/notifications/mark-all-read` POST, the
`/notifications/preferences` GET, the
`/notifications/preferences` POST) + the **two view models**
(`NotificationsInboxViewModel`, `NotificationPreferencesViewModel`) —
the **exact** routes + signatures from design doc §6.4.
**The service is frozen (U03); the controller *calls* it,
never re-derives the access decision (the C-M6·3 pin).**

  the 50-row cap).
- **`src/Kumunita.Web/Controllers/EventsController.cs`**

  precedent** (the `[Authorize]` shape, the
  `User.FindFirstValue(ClaimTypes.NameIdentifier)` actor-id

  constructor-injection shape, the `Redirect` / `ForbidResult`
  / `NotFound` split — the M5 `ProjectService` caller

  not re-registers).
- **`docs/adr/0006-module-boundary-contracts.md`** (the
  `IAuthorizationService` frozen-surface section) — the
  **one rule**: the controller does **not** call
  `IAuthorizationService` for the inbox read (the C-M6·3
  pin — a personal read, not an `AccessAction` decision);
  it *does* call `IAuthorizationService` for the
  **auth-gate** (the `[Authorize]` attribute's
  claim-verification, the M4 / M5 precedent — the gate is
  the *identity* check, not the *audience* check).

**Deliverables (closed set):**
- **`src/Kumunita.Web/Controllers/NotificationsController.cs`**
  (new) — the **five routes**, the **exact** shapes from
  design doc §6.4:
  - **`GET /notifications`** (the inbox): `[Authorize]`,
    extract the actor id from the principal (the
    `User.FindFirstValue(ClaimTypes.NameIdentifier)`
    precedent), call
    `NotificationService.ListInboxAsync(actorId)` (the
    C-M6·3 pin — no `IAuthorizationService` call, the
    personal-read shape), return `View(new
    NotificationsInboxViewModel { Notifications = ...,
    Count = ... })` — the **F11** FACE (no audit row on
    inbox read, the C-M6·3 pin).
  - **`GET /notifications/unread-count`** (the poller
    endpoint): `[Authorize]`, extract the actor id, call
    `NotificationService.CountUnreadAsync(actorId)`, return
    `Json(new { count })` — the **C-M6·8** pin (the
    `int` return, the `application/json` content type, the
    30-second poller's call target).
  - **`POST /notifications/mark-all-read`** (the state
    lane): `[Authorize]`, extract the actor id, call
    `NotificationService.MarkAllReadAsync(actorId)`,
    return `RedirectToAction("Index")` (the
    `Redirect`-back-to-inbox shape, the M5
    `AssignTodoAsync` caller pattern).
  - **`GET /notifications/preferences`** (the preference
    read): `[Authorize]`, extract the actor id, call
    `NotificationService.GetPreferencesAsync(actorId)`,
    return `View(new
    NotificationPreferencesViewModel { KindsEnabled = ...,
    AllKinds = NotificationKinds.All })` — the **C-M6·9**
    pin (the lean-default: `KindsEnabled == null` → all
    enabled).
  - **`POST /notifications/preferences`** (the preference
    write): `[Authorize]`, extract the actor id, bind the
    `NotificationPreferencesViewModel`, call
    `NotificationService.SetPreferencesAsync(actorId,
    viewModel.KindsEnabled)`, return
    `RedirectToAction("Index")` (the
    `Redirect`-back-to-inbox shape).
  - **The constructor:** `NotificationsController(
    NotificationService notifications)` — the **frozen**
    service (the C-M6·11 reuse pin — no new seam).
- **`src/Kumunita.Web/Models/NotificationViewModels.cs`**
  (new) — the **two view models** (the M4 / M5 view-model
  precedent, the `EventViewModels.cs` shape):
  - `sealed record
    NotificationsInboxViewModel { IReadOnlyList<Notification>
    Notifications; int Count; }` (the 50-row cap, the
    C-M6·8 pin).
  - `sealed record
    NotificationPreferencesViewModel { IReadOnlyList<string>?
    KindsEnabled; IReadOnlyList<string> AllKinds; }`
    (the `KindsEnabled` nullable-list shape, the C-M6·9
    pin; the `AllKinds` is the nine
    `NotificationKinds` constants — the closed set, the
    C-M6·2 pin).
- **Nothing else.** No Razor views (U06), no
  `kw-l` keys (U07), no `.ts` module (U08), no tests (U09),
  no ADR.
