# M25 U3 — `CommunityStorageSettings` doc + `StorageSettingsDocTypes` + boot wiring

> **Sealed unit.** One fresh agent, ~32K context window. Self-contained. The
> register (`docs/plans-milestones/plan-m25-upload-limits.md`) is the
> cross-reference; when the two disagree, **this file wins for what to do**.
> **Exit: build green.** **Precondition:** design doc Part 2 exists (U2).

## Understanding

This unit creates the **one new M25 document** (`CommunityStorageSettings`) and
its **registration surface** (`StorageSettingsDocTypes`), and wires it into
**both** boot paths (the dev loop in `Program.cs` and the all-env
`SchemaBootstrap`). It mirrors the `M3DocTypes` pattern exactly (a new
parallel doc surface, ADR 0004 §B.1). **No service, no tests yet** — U4 adds
the service + tests. The only new *data* surface M25 introduces is this doc;
the rest (the service, the gate, the views) are behavior.

## Deliverables (≤ 4 files)

1. **`src/Kumunita.Core/Usage/CommunityStorageSettings.cs`** — the POCO per
   §2.1: stable string `Id` = `"community"`; `long? MaxFileBytes` (admin
   per-file override; `null`/absent ⇒ env fallback); `long PerUserQuotaBytes`
   (`0` = unlimited); `DateTimeOffset Modified`; `string? ModifiedById`.
   Doc-comment anchoring C-UP·1 (admin-set) + C-UP·5 (sentinels).
2. **`src/Kumunita.Core/Usage/StorageSettingsDocTypes.cs`** —
   `public static void Configure(StoreOptions opts) {
   opts.Schema.For<CommunityStorageSettings>(); }`.
3. **`src/Kumunita.Core/Bootstrap/SchemaBootstrap.cs`** — add
   `StorageSettingsDocTypes.Configure(opts);` next to the existing doc-surface
   calls (one line added).
4. **`src/Kumunita.Web/Program.cs`** — add the
   `StorageSettingsDocTypes.Configure(...)` call in the dev-loop path, next to
   the existing calls (one line added).

## Rules

- ADR 0004 §B.1: the doc is **Marten-native** (POCO, a stable string `Id`),
  delta-detected + idempotent, **create-if-missing on read** (the read lane is
  the create-if-missing seam — U4's `GetOrCreateAsync`; **no hand-rolled
  seed**).
- Do **not** touch `IMediaStore`, `MediaObject`, or `MediaOptions` (C-UP·1/4).
- Do **not** add a service or a test in this unit.
