# U01 — `ProjectGoal` + `Project` docs + the two adapters + `M5DocTypes` surface + `ProjectId` on `TodoItem` / `KanbanBoard`

**Goal:** author the **four new Core types** (the two docs + the two
adapters) + **extend the `M5DocTypes` surface** (the two new docs + the
`ProjectId` indexes on `TodoItem` / `KanbanBoard`) + **add the `ProjectId?`
field** to `TodoItem` + `KanbanBoard`; **`dotnet build` clean**; one `PL`
unit test (the doc shapes compile + register + the adapter surface matches
the frozen `IAuditableResource` 6-member pin).

**Entry reads:** U00's handoff section (the D1–D12 lock + the exact C#
shapes from `docs/design/pl-goals-projects-design.md` §9.1–§9.2 + §9.5);
`docs/design/pl-goals-projects-design.md` (the primary reference tier);
`src/Kumunita.Core/Projects/TodoItem.cs` (the **existing** doc — the
`ProjectId?` field is **additive** on it, the C-M3·2 feed-filter pin, the
field-by-field provenance table to mirror); `src/Kumunita.Core/Projects/KanbanBoard.cs`
(the **existing** doc — the same additive `ProjectId?` field);
`src/Kumunita.Core/Projects/TodoItemToAuditableResource.cs` +
`KanbanBoardToAuditableResource.cs` (the **existing** two adapters — the
6-member `IAuditableResource` surface + the `TargetKind` string pin the two
new adapters mirror); `src/Kumunita.Core/Authorization/IAuditableResource.cs`
(the **frozen** 6-member interface — confirm the exact member set before
writing the two new adapters); `src/Kumunita.Core/M5DocTypes.cs` (the
**existing** surface — the `Index` / `UniqueIndex` shape + the
`opts.Schema.For<T>()` call shape the two new docs mirror; the `TodoItem` /
`KanbanBoard` index block the two new `ProjectId` indexes extend);
`src/Kumunita.Core/Authorization/Audience.cs` (the **exact** `Audience`
shape — confirm the `Kumunita.Core.Authorization` namespace the two new docs
reference); `tests/Kumunita.Core.Tests/PostgresFixture.cs` (the test harness
U01's test uses — the `M5DocTypes` boot path).

**Deliverables (6 files, 4 new + 2 edits):**
- `src/Kumunita.Core/Projects/ProjectGoal.cs` (new): the `ProjectGoal`
  doc, **verbatim** from the design doc §9.1 (the D2 shape). The XML doc
  mirrors the `TodoItem.cs` / `KanbanBoard.cs` provenance-table style —
  every field named with its ADR precedent, the **No** `IsDraft` / **No**
  dates / **No** `ProjectId` pins.
- `src/Kumunita.Core/Projects/Project.cs` (new): the `Project` doc,
  **verbatim** from the design doc §9.1 (the D3 shape). The XML doc
  mirrors the same provenance-table style — every field named with its ADR
  precedent, the **No** `IsDraft` pin, the `Status?` string-not-enum pin
  (C-M5·4 carried over), the `StartAt?` / `DueAt?` optional-date pin (ADR
  0079).
- `src/Kumunita.Core/Projects/ProjectGoalToAuditableResource.cs` (new):
  the adapter, **verbatim** from the design doc §9.2 — the 6-member
  `IAuditableResource` surface, `TargetKind => "goal"` (**exact** string).
  The XML doc mirrors the `TodoItemToAuditableResource.cs` style.
- `src/Kumunita.Core/Projects/ProjectToAuditableResource.cs` (new): the
  adapter, **verbatim** from the design doc §9.2 — `TargetKind =>
  "project"` (**exact** string). The XML doc mirrors the same style.
- `src/Kumunita.Core/M5DocTypes.cs` (edit): extend `Configure` — the two
  new docs registered **after** the `BoardItemPlacement` block (the
  `opts.Schema.For<ProjectGoal>()` + the `(ComponentId, Created)` index,
  the `opts.Schema.For<Project>()` + the `(ComponentId, Created)` index +
  the `GoalId` index); the **`ProjectId` index** on `TodoItem` +
  `KanbanBoard` (extend the existing `opts.Schema.For<TodoItem>()` +
  `opts.Schema.For<KanbanBoard>()` blocks with a `.Index(t => t.ProjectId)`
  / `.Index(b => b.ProjectId)` line). The XML doc note on the `Configure`
  method updated (the two new docs + the two new indexes named, the ADR
  0086 reference).
- `src/Kumunita.Core/Projects/TodoItem.cs` (edit): add the `ProjectId?`
  field (the C-M3·2 feed-filter pin, the `ComponentId` shape — the XML doc
  comment mirrors the `ComponentId` line's style: `// a feed filter, never a
  gate (C-M3·2) — the Project association (ADR 0086)`). **No** other change
  to the existing field set.
- `src/Kumunita.Core/Projects/KanbanBoard.cs` (edit): the same additive
  `ProjectId?` field, the same XML doc comment style. **No** other change
  to the existing field set.
- `tests/Kumunita.Core.Tests/ProjectDocShapeTests.cs` (new): one test —
  `ProjectGoal_Project_ResolveAndRegister` (the two new docs boot through
  `M5DocTypes.Configure` without error, the two new adapters implement
  `IAuditableResource` — the `TargetKind` strings assert `"goal"` /
  `"project"` exactly, the `TodoItem.ProjectId` + `KanbanBoard.ProjectId`
  fields exist + are nullable). **One** test, not a suite — the unit is
  about the **doc shapes** compiling + registering, not behavior.

**Sequencing note:** this unit **does not** touch `IProjectService` /
`ProjectService` / any Web file — the service seams are U02–U04's, the Web
is U05–U09's. The `ProjectId` field on `TodoItem` / `KanbanBoard` is
**additive** (ADR 0004 §B.1 — Marten's `ApplyAllConfiguredChangesToDatabaseAsync`
delta-detects the new column at boot; **zero migration for existing rows** —
existing to-dos / boards simply have `ProjectId == null`).

- `dotnet build Kumunita.slnx -c Debug` clean (zero errors, zero new
  warnings).
- The one test passes: `dotnet exec tests\Kumunita.Core.Tests\bin\Debug\net10.0\Kumunita.Core.Tests.dll -class "Kumunita.Core.Tests.ProjectDocShapeTests"`.
- **No** `IProjectService` / `ProjectService` / Web / view / `kw-l` change.
