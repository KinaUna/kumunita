# U04 — Association lanes (`SetTodoProjectAsync` / `SetBoardProjectAsync`) + `projectId` filter on the existing to-do / board read lanes

**Goal:** add the **two association seams** to `IProjectService`
(**verbatim** from the design doc §9.3 — `SetTodoProjectAsync` /
`SetBoardProjectAsync`) + the **`projectId` filter parameter** on the
**existing** `ListTodosAsync` / `ListBoardsAsync` read seams (additive —
an optional parameter appended to the end of the existing signatures, the
`unassignedOnly` optional-param precedent ADR 0073 already set on
`ListTodosAsync`), **implement** them in `ProjectService` (the standing
re-check, the project `GoalId`-style guard — a non-null `projectId`
pointing at a soft-deleted or unreadable project is **refused**, the
`AccessAudit` rows), + the **pinned Core tests** (the design doc §9.6
association pins). **`dotnet build` clean; all new + existing tests pass.**

**Deliverables (3 file edits + test additions):**
- `src/Kumunita.Core/Projects/IProjectService.cs` (edit):
  - the two association seams, **verbatim** from the design doc §9.3, in
    the new `// --- PL association lanes (U04) ---` section;
  - the **`string? projectId = null`** parameter appended to
    `ListTodosAsync` (after `unassignedOnly`) + `ListBoardsAsync` (after
    `page`) — **optional with default `null`** so every existing call
    site (M5 code + the U02–U03 Core tests) compiles **unchanged**; the
    XML doc gains the `projectId` paragraph (a filter, never a gate —
    C-M3·2; narrows the candidate set to the to-dos / boards whose

- `src/Kumunita.Core/Projects/ProjectService.cs` (edit):
  - `SetTodoProjectAsync`: load the to-do (404 if absent / soft-deleted);
    the **standing re-check** — creator ∪ assignee ∪ GlobalAdmin (the
    `AssignTodoAsync` shape, 403 if denied); when `projectId != null`,
    **the project guard** — load the project (404 if absent /
    soft-deleted) + `CanAsync(Read)` (403 if denied); write
    `todo.ProjectId = projectId` (the `null` unassociate path skips the
    guard); stamp `Modified`; the `todo.set_project` `AccessAudit` row
    (`TargetKind = "todo"`); return the updated to-do.
  - `SetBoardProjectAsync`: the same shape over the board — load (404),
    standing **creator ∪ GlobalAdmin** (the `UpdateBoardAsync` ADR 0070
    shape, 403), the project guard (404 / 403), write
    `board.ProjectId`, stamp `Modified`, the `board.set_project`
    `AccessAudit` row (`TargetKind = "board"`); return the updated board.
  - `ListTodosAsync` / `ListBoardsAsync`: the `projectId` candidate
    filter (`p => p.ProjectId == projectId` when non-null — the
    `unassignedOnly` / `ComponentId` filter shapes, **before** the
    `CanSeeAsync(Read)` survivor pass).
