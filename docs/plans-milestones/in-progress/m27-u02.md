# M27 U02 — Framework: the resident-scope filter + the per-kind business keys

## Context (self-contained)

M27 = **user-scoped portability**: a resident exports/imports **their own
authored data** and resolves per-entity conflicts on import. U00 locked the
design doc + ADR 0148. U01 created the `IUserPortabilityService` seam + the
shell + the manifest marker. U02 renders **D1** (the resident-scope inventory
as data) + **D4's business keys** as the **resident-scope filter** (which doc
families + which ownership field scopes each) + the **per-kind business-key**
matchers (D4's `duplicate` matcher + the `conflict` reference-availability
report both drive off these). **Pure, over the frozen M11
`PortabilityDocTypes` inventory** — no service logic, no writes, no new
document. This is the "what belongs to the resident" + "what is the same
entity" map U03 (export filter) and U04 (classification) loop.

## Goal

Create the `UserScopeInventory` (the D1 closed resident-scope inventory as
data — the `Type` → **ownership field** map + the **excluded** list) + the
`UserBusinessKeys` (the D4 per-kind business-key matchers) + compose them in
the `UserPortabilityService` shell (the `ScopeFilter` + `MatchBusinessKey`
methods U03/U04 call). **No export/import logic yet** (U03–U06 own that).

## Deliverables (≤ 4 files)

1. **`src/Kumunita.Core/Portability/UserScopeInventory.cs`** (new) — the D1
   closed resident-scope inventory as **data**:
   - The `Type` → **ownership field** map (the exact map from the design doc
     §2.2 — `Post`→`AuthorId`, `PostReply`→`AuthorId`, `Event`→`AuthorId`,
     `TodoItem`→`AuthorId`, `InventoryItem`→`AuthorId`, `Document`→`OwnerId`,
     `Bookmark`→`OwnerId`, `Message`→`SenderId` ∪ participant, `Profile`→the
     resident's own `SubjectId`, `Group`→`OwnerId` ∪ member, + the minimal
     identity reference set).
   - The **excluded** list (the C-M27·3 ownership-not-read pin — the other
     residents' rows, the operator `config.json` state, the M11 "Excluded" set:
     `AccessAudit` / `OutboxEmail` / `EmailDeadLetter` / `IdentityToken` /
     `AuditPurgeSummary`).
2. **`src/Kumunita.Core/Portability/UserBusinessKeys.cs`** (new) — the D4
   per-kind business-key matchers (the `duplicate` matcher: `Post`→
   `(AuthorId, Created, Title?, Body-hash)`, `Tag`→`Slug`, `Document`→
   `(OwnerId, Created, Title?, hash)`, + the closed set from the design doc
   §2.3 — a pure `bool Matches(string type, object a, object b)` over the POCO
   set, no session, no write).
3. **`src/Kumunita.Core/Portability/UserPortabilityService.cs`** (modify) —
   the **filter** + **matcher** composition methods:
   - `IReadOnlyList<object> ScopeFilter(IReadOnlyList<object> docs, string residentId)`
     — the U02 scope filter (the resident's rows only, the C-M27·3 pin).
   - `bool MatchBusinessKey(string type, object a, object b)` — the U02
     business-key matcher (the D4 `duplicate` detector).
   - The three interface methods still `NotImplementedException` until U03–U06.
