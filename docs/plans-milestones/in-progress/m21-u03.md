# M21 · U03 — `DocumentController` (index/detail/new + upload POST + download GET) + view models

**You are the U03 agent.** This is a **Web** unit. It adds the `DocumentController`
(the five actions: `Index`, `Detail`, `New`, `Upload`, `Serve`) + its view models.
It **serves the bytes as a download** behind a single `Read` decision (D6/D7),
**gates the upload standing at the Web boundary** (D5 — `GlobalAdmin ∪
Moderator`), and **uses `MediaOptions.IsDocumentAllowed`** for the upload
allowlist (D3). It does **not** add the Razor views (U04) or the `kw-l` keys
(U04). **Exit: `dotnet build` clean + `Kumunita.Web.Tests` green (including the
new `DocumentControllerTests`).**

**Read the design doc + ADR first** — they lock the C# in this unit (D5/D6/D7,
C-M21·3/5/6/7). The `AttachmentController` is your source of truth for the
serve/upload mechanics (the 5-step ordering, `Content-Disposition: attachment`,
the RFC 6266 `SanitizeFilename`, the `IsValidMediaId`, the 400/413/415 guard
ordering). The design doc is your source of truth for the *locked surface* (the
Deny→404 posture, the upload standing set, the route/action names).

## Goal

Give M21 its five Web routes:
- `GET /documents` — the feed (index), one `CanSeeAsync` aggregate row;
- `GET /documents/{id}` — the detail, one `CanAsync` decision row, **Deny → 404**;
- `GET /documents/new` — the upload form (gated D5);
- `POST /documents` — the upload write lane (gated D5, D3 allowlist, 400/413/415);
- `GET /documents/{id}/download` — the byte serve (D6, `Content-Disposition:
  attachment`, behind a single `Read` decision, **Deny → 404**).

### 3. `src/Kumunita.Web/Controllers/DocumentController.cs`

The five actions. Mirror `AttachmentController`'s serve/upload mechanics; gate
the upload standing at the boundary (D5); serve the bytes as a download (D6);
Deny → 404 (D7).

```csharp
using Kumunita.Core.Documents;
using Kumunita.Core.Media;
using Kumunita.Web.Models;
using Kumunita.Web.Security;
using Microsoft.AspNetCore.Authorization;
using Microsoft.AspNetCore.Mvc;
using Microsoft.Extensions.Options;
using Marten;

namespace Kumunita.Web.Controllers;

/// <summary>
/// M21 (ADR 0122, U03) — the documents routes: the feed (index), the detail,
/// the upload form, the upload write lane, and the download serve. The
/// authorization is the per-<see cref="Document"/> <c>Read</c> decision (one
/// <see cref="Kumunita.Core.Authorization.IAuthorizationService"/> call, one
/// audit row — emitted **by** the frozen seam, not this controller; C-M21·3).
/// The upload standing is gated at **this** boundary (D5 —
/// <c>GlobalAdmin ∪ Moderator</c>); the Core service is standing-agnostic. The
/// bytes ride the frozen ADR 0011 <see cref="IMediaStore"/> (D3); the document
/// allowlist is <see cref="MediaOptions.IsDocumentAllowed"/> (D3). The download
/// is <c>Content-Disposition: attachment</c> (D6) behind a single <c>Read</c>
/// decision, Deny → <b>404</b> (D7 — not 403; feed and detail agree).
/// </summary>
public sealed class DocumentController(
    DocumentService documents,
    IMediaStore media,
    IOptions<MediaOptions> mediaOpts,
    IDocumentStore store) : Controller
{
    // ── GET /documents — the feed (index) ─────────────────────────────
    [HttpGet("/documents")]
    [Authorize]
    public async Task<IActionResult> Index(int page = 1)
    {
        var actorId = KumunitaPrincipal.SubjectId(User);
        if (actorId is null) return Unauthorized();

        var result = await documents.ListAsync(actorId, page);
        var vm = new DocumentIndexViewModel(
            Visible: result.Visible,
            HasMore: result.HasMore,
            Page: result.Page,
            CanUpload: KumunitaPrincipal.IsGlobalAdmin(User) || KumunitaPrincipal.IsModerator(User));
        return View("Index", vm);
    }

    // ── GET /documents/{id} — the detail (Deny → 404, D7) ─────────────
    [HttpGet("/documents/{id}")]
    [Authorize]
    public async Task<IActionResult> Detail(string id)
    {
        var actorId = KumunitaPrincipal.SubjectId(User);
        if (actorId is null) return Unauthorized();

        var result = await documents.GetAsync(id, actorId);
        if (result.Document is null) return NotFound(); // missing or Deny — the same posture (D7)

        var vm = new DocumentDetailViewModel(
            Document: result.Document,
            CanDownload: true, // the GetAsync decision allowed; the download re-runs the same Read
            DownloadUrl: $"/documents/{id}/download");
        return View("Detail", vm);
    }

    // ── GET /documents/new — the upload form (gated D5) ───────────────
    [HttpGet("/documents/new")]
    [Authorize]
    public IActionResult New()
    {
        // D5 — the upload standing gate (Web boundary). A non-privileged actor
        // gets 404 (not 403 — the non-leaky posture: the form's existence is
        // not leaked to non-privileged actors).
        if (!KumunitaPrincipal.IsGlobalAdmin(User) && !KumunitaPrincipal.IsModerator(User))
            return NotFound();
        return View("New");
    }

    // ── POST /documents — the upload write lane (gated D5, D3 allowlist) ─
    [HttpPost("/documents")]
    [Authorize]
    [ValidateAntiForgeryToken]
    public async Task<IActionResult> Upload(
        [FromForm] string title,
        [FromForm] string? summary,
        [FromForm] string audienceJson,
        [FromForm] IFormFile? file)
    {
        var subject = KumunitaPrincipal.SubjectId(User);
        if (subject is null) return Unauthorized();

        // D5 — the upload standing gate (Web boundary, same as New).
        if (!KumunitaPrincipal.IsGlobalAdmin(User) && !KumunitaPrincipal.IsModerator(User))
            return NotFound();

        // D3 — the guards-before-write ordering (C-ATT·6 shape, verbatim from
        // AttachmentController.Upload): empty → 400, oversize → 413, disallowed
        // type → 415, **no file written on any guard**.
        if (string.IsNullOrWhiteSpace(title)) return BadRequest("A title is required.");
        if (file is null || file.Length == 0) return BadRequest("Choose a file.");
        if (mediaOpts.Value.MaxBytes > 0 && file.Length > mediaOpts.Value.MaxBytes)
            return StatusCode(StatusCodes.Status413RequestEntityTooLarge);
        if (!mediaOpts.Value.IsDocumentAllowed(file.ContentType))
            return StatusCode(StatusCodes.Status415UnsupportedMediaType);

        // D3 — store-first (orphan-safe), then the Core write in the caller's
        // session (C-M21·4 — one SaveChangesAsync, the domain write and any
        // in-session audit row commit or roll back atomically).
        using var ms = new MemoryStream();
        await file.CopyToAsync(ms);
        var stored = await media.PutAsync(ms.ToArray(), file.FileName, file.ContentType, subject);

        // Parse the audience (the Web-only boundary — Core stays body-parse-free).
        // Match the exact Audience shape to what the Post/Announcement upload
        // lanes pass (verify against how PostService.CreatePostAsync's draft
        // carries Audience in the Web layer).
        var audience = ParseAudience(audienceJson);

        var draft = new DocumentUpload(
            Title: title.Trim(),
            Summary: string.IsNullOrWhiteSpace(summary) ? null : summary.Trim(),
            MediaId: stored.Id,
            Filename: file.FileName,
            ContentType: file.ContentType,
            SizeBytes: file.Length,
            Audience: audience);

        await using var session = store.OpenTransactionSession();
        var doc = await documents.UploadAsync(draft, subject, session);
        return RedirectToAction(nameof(Detail), new { id = doc.Id });
    }

    // ── GET /documents/{id}/download — the byte serve (D6, Deny → 404) ──
    [HttpGet("/documents/{id}/download")]
    public async Task<IActionResult> Serve([FromRoute] string id)
    {
        // No [Authorize] — the authorization is the per-document Read decision
        // below (the image/attachment lane's choice: an anonymous visitor to a
        // public document must be served; Deny → 404).
        //
        // Step 1: load the document (raw read, no decision yet). A missing
        // document → 404 (zero audit rows).
        Document? doc = null;
        await using (var s = store.QuerySession())
        {
            doc = await s.LoadAsync<Document>(id);
        }
        if (doc is null) return NotFound(); // missing → 404 (zero rows)

        // Step 2: the single Read decision (one audit row, by the frozen seam —
        // NOT this action; C-M21·3). Deny → 404 (D7 — not 403).
        var actorId = KumunitaPrincipal.SubjectId(User) ?? "";
        var result = await documents.GetAsync(id, actorId);
        if (result.Document is null) return NotFound(); // Deny → 404 (D7) + one Deny row (by the decision)

        // Step 3: serve the bytes (D6 — Content-Disposition: attachment; the
        // stored Content-Type, already validated at write).
        var stored = await media.GetAsync(doc.MediaId);
        if (stored is null) return NotFound(); // store miss → 404 (defensive)
        var stream = await media.OpenReadAsync(doc.MediaId);
        Response.Headers["X-Content-Type-Options"] = "nosniff";
        var filename = SanitizeFilename(doc.Filename ?? stored.Filename, id);
        Response.Headers["Content-Disposition"] =
            "attachment; filename=\"" + filename + "\"; filename*=UTF-8''" + Uri.EscapeDataString(filename);
        return File(stream, doc.ContentType);
    }

    // ── helpers (mirror AttachmentController) ─────────────────────────
    private static string SanitizeFilename(string? original, string id)
    {
        if (string.IsNullOrWhiteSpace(original)) return id + ".bin";
        var cleaned = new System.Text.StringBuilder(original.Length);
        foreach (var c in original)
        {
            if (c < ' ' || c == '"' || c == '\\' || c == '/' || c == ';' || c == ':' || c == '<' || c == '>' || c == '?' || c == '|')
                continue;
            cleaned.Append(c);
        }
        return cleaned.Length == 0 ? id + ".bin" : cleaned.ToString();
    }

    /// <summary>
    /// Parses the audience JSON from the upload form into the frozen
    /// <see cref="Kumunita.Core.Authorization.Audience"/> shape. **Match the
    /// exact serialization the Post/Announcement upload lanes use** (verify
    /// against how their Web controllers build the draft's Audience) — the
    /// audience is written verbatim (C-M21·1); this is the Web-only parse
    /// boundary.
    /// </summary>
    private static Kumunita.Core.Authorization.Audience ParseAudience(string audienceJson)
    {
        // TODO(U03): match the exact Audience serialization the existing
        // Post/Announcement upload Web lanes use (grep the Web layer for how
        // they build PostDraft.Audience / AnnouncementDraft.Audience). The
        // shape is the frozen Audience (Mode/Grants/Community/AllResidents) —
        // the parse is Web-only; Core receives the frozen shape verbatim.
        throw new NotImplementedException("Mirror the Post/Announcement upload audience parse — verify against the Web layer before implementing.");
    }
}
```
