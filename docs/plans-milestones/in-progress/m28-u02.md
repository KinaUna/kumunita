# M28 U02 — The pure `GuardianTimeLimitEvaluator` + the pure-evaluator tests

## Context (self-contained)

M28 = **Guardian time limits**: a **guardian** sets a per-child schedule
(hours × days-of-week, Blocked/Allowed polarity) that **gates the child's
whole-platform access** (a sign-out, the `BlockedAccountMiddleware` analog).
This is the **inverse of the M20 quiet lane** (ADR 0121) but on the **GU
guardian surface** (ADR 0028), using the **same pure-evaluator discipline**
(wall-clock-first, ADR 0019). U00 locked the design doc + ADR 0151. U01
created the `GuardianTimeLimitSchedule` doc + `TimeLimitMode` enum.

**U02 authors the pure function** — the `static`
`GuardianTimeLimitEvaluator.IsAllowedNow(schedule, now, zone)` (namespace
`Kumunita.Core.UserInfo`) — the **exact mirror** of M20's
`QuietScheduleEvaluator.IsQuietNow`, but with the **polarity inverted**:
M20's `IsQuietNow` returns `true` = the email is **held** (the restriction);
M28's `IsAllowedNow` returns `true` = the child **MAY use the platform**
(the permission). The wall-clock-first ADR 0019 discipline, the
`null`/`Enabled == false` floor, and the `Hours`/`DaysOfWeek` window test
are **identical** to M20. **No service, no middleware, no Web.**

## Goal

Author the `static` pure `GuardianTimeLimitEvaluator` (namespace
`Kumunita.Core.UserInfo`) + the F1/F2/F3/F4 pure-evaluator tests. The exact
mirror of `QuietScheduleEvaluator.IsQuietNow`, but
`IsAllowedNow(schedule, now, zone)` → `bool` (true = the child MAY use the
platform now). **No service, no middleware, no Web.**

## Deliverables (2 files)

1. **`src/Kumunita.Core/UserInfo/GuardianTimeLimitEvaluator.cs`** (new) —
   `public static class GuardianTimeLimitEvaluator`:
   ```csharp
   public static bool IsAllowedNow(
       GuardianTimeLimitSchedule? schedule,
       DateTimeOffset now,
       TimeZoneInfo effectiveZone)
   {
       ArgumentNullException.ThrowIfNull(effectiveZone);

       // C-M28·3 — the floor: no schedule, or the master off → always
       // allowed (the child is never restricted).
       if (schedule is null || !schedule.Enabled)
           return true;

       // C-M28·6 — wall-clock-first (ADR 0019): convert the instant to the
       // child's effective zone's local time, THEN read the hour + day
       // (the kw-dt TagHelper + EventReminderService discipline).
       var wall = TimeZoneInfo.ConvertTime(now, effectiveZone);

       // An empty axis = "all" (the D2 "empty = all hours / all days"
       // reading, the M20 shape verbatim).
       var hourMatches   = schedule.Hours.Length     == 0 || schedule.Hours.Contains(wall.Hour);
       var dayMatches    = schedule.DaysOfWeek.Length == 0 || schedule.DaysOfWeek.Contains((int)wall.DayOfWeek);
       var windowMatches = hourMatches && dayMatches;   // the window contains the instant

       // The polarity INVERSE of M20:
       //   Blocked mode → the child is restricted DURING the window
       //     → allowed iff the instant is OUTSIDE the window (!windowMatches)
       //   Allowed mode → the child is restricted EXCEPT the window
       //     → allowed iff the instant is INSIDE the window (windowMatches)
       return schedule.Mode == TimeLimitMode.Blocked
           ? !windowMatches
           :  windowMatches;
   }
   ```
   A doc-comment on the class pinning: C-M28·2 (pure function, not an
   authorization decision), C-M28·3 (the floor), C-M28·6 (wall-clock-first),
   the M20 inverse framing (the polarity is inverted because here **allowed**
   is the permission, not the restriction).
2. **`tests/Kumunita.Core.Tests/GuardianTimeLimitEvaluatorTests.cs`** (new) —
   the F1–F4 pure tests (the exact names from the design doc §2.6):
   - `F3_Missing_Schedule_Is_Always_Allowed` — `IsAllowedNow(null, any, any)`
     → `true` (C-M28·3).
   - `F3_Disabled_Schedule_Is_Always_Allowed` — `IsAllowedNow(Enabled=false,
     any, any)` → `true` (C-M28·3).
   - `F1_Blocked_InWindow_Is_Restricted` — `Blocked` mode, `Hours=[22]`,
     `now=22:30 UTC`, `zone=UTC` → `false` (restricted during the window).
   - `F1_Blocked_OutOfWindow_Is_Allowed` — `Blocked` mode, `Hours=[22]`,
     `now=14:00 UTC`, `zone=UTC` → `true` (allowed outside the window).
   - `F2_Allowed_InWindow_Is_Allowed` — `Allowed` mode, `Hours=[9,10,11]`,
     `now=10:00 UTC`, `zone=UTC` → `true` (allowed inside the window).
   - `F2_Allowed_OutOfWindow_Is_Restricted` — `Allowed` mode,
     `Hours=[9,10,11]`, `now=22:00 UTC`, `zone=UTC` → `false` (restricted
     outside the window).
   - `F4_Verdict_Differs_Between_Zones` — `Blocked` mode, `Hours=[22]`,
     `now=21:30 UTC`, `zone=UTC+2` → `false` (21:30 UTC = 23:30 local,
     inside the window) vs `now=21:30 UTC`, `zone=UTC` → `true` (21:30 local,
     outside the window) (C-M28·6, the M20
     `IsQuietNow_Verdict_Differs_Between_UTC2_And_UTC` analog).

## Rules

- **No service, no middleware, no Web** (a pure-function unit).
- The evaluator is in `Kumunita.Core.UserInfo` (the GU surface, not
  `Notifications`) — the `UserInfo` context does not depend on
  `Notifications` (the evaluator is a **separate** pure function from
  `QuietScheduleEvaluator`, but shares the exact evaluation discipline).
- The polarity is the **inverse** of M20's `IsQuietNow` (allowed = permission,
  not restriction) — this is the **load-bearing** difference.
- The `null`/`Enabled == false` floor returns `true` (allowed) — the **opposite**
  of M20's floor (which returns `false` = never quiet).
- The tests are **pure** (no `PostgresFixture`, no `IDocumentStore`, no
  `IUserInfoService` — just the POCO + the `TimeZoneInfo` + the `DateTimeOffset`).
