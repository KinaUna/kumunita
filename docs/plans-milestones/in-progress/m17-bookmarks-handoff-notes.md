## U03 — BookmarksController + /bookmarks list view + 12 `bm.*` keys (×4) + nav entry + 5 pinned Web tests

- **Controller surface confirmed** (`src/Kumunita.Web/Controllers/BookmarksController.cs`, the design doc §2.2 shape verbatim): `GET /bookmarks` → `Index()` — `SubjectId(User)` null/empty ⇒ non-leaky `NotFound()` **before** any seam call (the C-M17·2 "operator has no read standing" gate, ADR 0105), else `await bookmarks.ListAsync(actorId)` → `View(result)`; `POST /bookmarks/{targetKind}/{targetId}/remove` → `Remove()` with `[ValidateAntiForgeryToken]` — same `SubjectId` gate ⇒ 404, else `await using var session = store.LightweightSession(); await bookmarks.RemoveAsync(actorId, targetKind, targetId, session); await session.SaveChangesAsync();` → `Redirect("/bookmarks")`.
