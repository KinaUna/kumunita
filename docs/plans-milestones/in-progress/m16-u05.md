## Goal

Add the **edit/delete actions**, the **check-out/check-in action buttons** (+
confirmation), and the **nav entry** (the sidebar "Inventory" link, the M5 `projects`
nav-entry shape). The check-out/check-in actions route to the U03 write lanes (the
standing probe is **server-side** — F4; the Web `[Authorize]` is a convenience
pre-gate only). The usage-history section is already in the U04 detail view; U05 wires
the action buttons to it.

**The locked decisions you implement (from the design doc — read the Web-action +
nav-entry sections verbatim):**
- **D5 / C-M16·5** — the check-out/check-in/edit/delete actions route to the U03
  standing probes (the **server-side** source of truth); the Web `[Authorize]`
  attribute is a **convenience pre-gate only**, never the source of truth (F4).
- **D4 / C-M16·3** — the check-out action triggers the **atomic** transition (F1); the
  "currently with" display reads `CurrentHolderId`; the history section reads the
  append-only checkout records.
- **§kw-l** — the action + nav keys (`inv.detail.edit` / `inv.detail.delete` /
  `inv.detail.checkOut` / `inv.detail.checkIn` / `inv.nav` / `inv.edit.title` /
  `inv.edit.submit`) are already registered by U04 (the U00 §kw-l list); U05 **uses**
  them, does not re-register.
