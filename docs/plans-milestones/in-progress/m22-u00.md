doc and ADR 0132, and it locks the register's [PROPOSED] set (D1–D8,
C-M22·1…C-M22·6, FACES F1–F5, the closed `onboarding.*` kw-l key set, the §gate

the register's [PROPOSED] set is either confirmed or amended *in this unit*."

one additive `Profile` field + one owner-scope lane** (the register's D1/D2) —
there is **no new bounded context, no new `*DocTypes` surface, no new
`Program.cs` boot line, no new adapter, no new storage lane**.
