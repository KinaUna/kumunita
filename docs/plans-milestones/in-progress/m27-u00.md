# M27 U00 — Lock the design: `m27-user-scoped-portability-design.md` + ADR 0148

## Context (self-contained)

M27 is **user-scoped portability**: a **resident** exports / backs up **their own
authored data** (posts, replies, events, projects, documents, pages, messages,
bookmarks, profile) and imports it into another instance where their data may
not fit the community's structure/authorization — so on import the user
**manually resolves conflicts per entity** (add it elsewhere or discard it).

**M27 is the explicit follow-on lane M11 (ADR 0108) deferred.** M11 shipped
the **operator-scoped, whole-instance** `*.kumunita` archive: a GlobalAdmin
moves the *entire* instance in and out, fail-closed, no-secrets. M27 reuses
that machinery (the `Kumunita.Core/Portability/` context — the BCL-only
`KumunitaArchive` ZIP (de)serializer, the `PortabilityManifest` self-describing
head, the frozen `PortabilityDocTypes` 44-doc inventory, the no-secret posture)
but **scopes it to one resident** and **adds the one mechanic M11 did not
have**: on import, the resident **manually resolves conflicts per entity**.

**The M11 vs M27 distinction:**

| Axis | M11 (shipped) | M27 (this lane) |
|---|---|---|
| Actor | GlobalAdmin | the resident themself |
| Scope | the whole instance (44 doc types) | **one resident's authored data** (a closed subset) |
| Import semantic | **restore** (fail-closed, all-or-nothing) | **merge with per-entity conflict resolution** (add elsewhere / discard) |
| Reference conflicts | rejected (referential integrity) | **surfaced to the resident** as a resolve step |
| Secrets | identity graph travels (secrets reset) | resident's own account is anchor; **no credential material** |
| Audit `Via` | `Admin` | `Owner` (the resident self-lane) |

**M27 owns the M11 deferred lane** the ADR named "per-slice portability (one
user's data out)" + the "import-merge (onto a diverged instance)" fragment.
M27 is **not** cross-neighborhood federation and **not** the backup-automation
surface — both stay deferred.

**What M27 builds on (frozen, verified seams):**
- `Kumunita.Core/Portability/` (M11, ADR 0108) — `KumunitaArchive`,
  `PortabilityManifest` (format `kumunita/portability/1`), `PortabilityDocTypes`
  (44-entry closed inventory), `PortabilityPrincipal` (no-secret identity
  graph POCO), `PortabilityService` (the operator seam).
- The `*DocTypes` surfaces — the per-resident scope is a **subset** of the M11
  inventory, filtered by the resident's `AuthorId`/`OwnerId`/`RecipientId`/
  participant fields.
- The content-addressed media store (ADR 0011).
- The resident self-lane house pattern — `/settings/...` sections,
  `AccessVia.Owner`, `[Authorize]` verified-resident gate, the `kw-l`
  closed-key registry.
- The milestone-flip contract — `Milestones.cs` + README + STATUS +
  ARCHITECTURE + `MilestonesTests.cs`, moved **in the close unit (U13)**.

## Decisions to lock (the [PROPOSED] set — refine where the source says more)

- **D1 · Scope = the resident's authored data (ownership, not read).**
  In-scope doc families (pinned, the ownership field per doc): `Post`
  (`AuthorId`) + `PostReply` (`AuthorId`) + `PostTranslation`/`ReplyTranslation`
  (`AuthorId`) + `AnnouncementComment` (`AuthorId`) + `Event` (`AuthorId`) +
  `EventRsvp` (`UserId` = the resident) + `EventTranslation` (`AuthorId`) +
  `ProjectGoal`/`Project`/`TodoItem`/`KanbanBoard` (`AuthorId`) + their
  translations/comments/placements + `InventoryItem` (`AuthorId`) + `Document`
  (`OwnerId`) + `DocumentFolder` (`OwnerId`) + `Conversation` (participant) +
  `Message` (`SenderId` ∪ participant) + `Page` (`AuthorId`) + `Tag`
  (creator) + `Bookmark` (`OwnerId`) + `Profile` (the resident's own `Bio`/
  `TagIds`) + `Group`/`GroupMembership`/`GroupInvitation`/`GroupJoinRequest`
  (for groups the resident created or is a member of — needed to make their
  content resolvable on import). **Excluded:** the operator instance-identity
  (community name, language catalog, `LocaleSettings`), the other residents'
  data, credential material (the C-M11·2 boundary), `AccessAudit` /
  `OutboxEmail` / `EmailDeadLetter` / `IdentityToken` / `AuditPurgeSummary`
  (the M11 "Excluded" set). **The scope is ownership, not read** — the
  resident's *authored/owned* rows, never "everything they can see."
- **D2 · The archive reuses M11's format at the resident scope.** Same BCL-only
  `*.kumunita` ZIP layout + the `PortabilityManifest` head. The `format`
  authority stays `kumunita/portability/1`. M27 adds **one additive, optional**
  manifest field (`Scope? = "resident"` + `ResidentSubjectId?`) — `null` = a
  plain M11 whole-instance archive (the ADR 0098 additive-frozen-surface
  precedent: existing readers keep compiling, a plain M11 archive still
  imports whole). **No new package.**
- **D3 · Export = a resident-scoped filter over M11's closed inventory.**
  `ExportAsync(residentSubjectId)` produces the **same** `*.kumunita` shape
  but with `docs/{Type}.json` arrays **filtered to the resident's authored/
  owned rows** + the resident's media + the minimal no-secret identity
  reference set. **No-secrets** holds (C-M27·2). One `AccessAudit` row
  (`TargetKind "portability"`, `Via = Owner`, verb `export`).
- **D4 · Import = validate-then-merge with per-entity conflict resolution.**
  **Before any write**, classify each in-scope entity:
  - **`clean`** — no conflict, ready to apply;
  - **`duplicate`** — an equivalent entity already exists (matched by a
    per-kind **business key**);
  - **`conflict`** — a reference target the entity depends on is absent (the
    group/component/page/tag the resident's data pointed at does not exist or
    the resident is not a member of).
  The resident then **resolves each non-clean entity**: **add it elsewhere**
  (re-point the missing reference to a target they pick) **or discard it**.
  Clean entities are applied in one batch. A rejected/aborted resolve writes
  **nothing** (fail-closed). **No auto-merge** (ADR 0001-B — the author's
  choice is absolute).
- **D5 · The surface is the resident's own, thin + audited + quiet.**
  `UserPortabilityController` at `/account/portability` (`[Authorize]`,
  verified resident; the resident's own data only — no GlobalAdmin break-glass,
  no audience decision): `GET` (index), `GET /export` (streams), `POST /import`
  (validate + classify), `POST /import/resolve` (apply decisions). Each **write**
  emits **one** `AccessAudit` row (`Via = Owner`, `TargetKind "portability"`,
  verb `export`/`import`/`import.resolve`); **reads** emit **none**.
- **D6 · Zero new authorization surface.** Reuses `AccessVia.Owner` (already
  exists). The per-entity resolve is a **business decision in the resident's
  UI**, not an `AccessAction` — the frozen `IAuthorizationService` is
  untouched.
- **D7 · Core home = a new resident-scoped service over the M11 context.**
  `UserPortabilityService` (new file in the **existing**
  `Kumunita.Core/Portability/` context — a lane **on** the M11 surface, not a
  new bounded context) with `IUserPortabilityService`: `ExportAsync` /
  `ClassifyAsync` / `ResolveAsync`. No new document, no new `*DocTypes`
  surface, **no migration**.
- **D8 · Tests: a Core round-trip + no-secret/self-scoped + per-entity conflict
  + Web-surface pins.** The three acceptance tests (closed-loop / handoff /
  part-vs-whole) + the Web pins.
- **D9 · kw-l keys + the deferred lanes.** The resident-facing strings × 4
  languages. **Deferred:** cross-neighborhood federation, backup-automation/
  cron, resident delete-all, community-level import-merge.

## Invariants to lock

- **C-M27·1** — the archive reuses the M11 format (the `format` authority
  unchanged) + one additive optional resident-scope marker. A plain M11
  archive still validates/imports unchanged.
- **C-M27·2** — the archive travels the data, never the secrets (carries the
  M11 C-M11·2 boundary). No credential material.
- **C-M27·3** — scope is ownership, not read. Another resident's content is
  **absent** from the archive.
- **C-M27·4** — import is fail-closed on the write path + the resident's
  choice is absolute (no auto-merge, no half-apply).
- **C-M27·5** — per-entity conflict classification is pre-write. A `conflict`
  entity never auto-applies.
- **C-M27·6** — the surface is the resident's own, audited, quiet. Each write
  emits exactly one `AccessAudit` row (`Via = Owner`); reads emit none.
- **C-M27·7** — zero new authorization surface. The `IAuthorizationService`
  surface count is unchanged.
- **C-M27·8** — docs parity holds at the flip (the close unit, U13).

## FACES to lock

- **F1** — the resident's data is portable out (one `*.kumunita` archive of
  their authored rows + media + identity reference set).
- **F2** — their data comes back intact where it fits.
- **F3** — their data never carries a secret.
- **F4** — where it doesn't fit, the resident decides per entity (add elsewhere
  or discard; nothing auto-merged, nothing half-applied).
- **F5** — the surface is quiet + audited + the resident's own (no GlobalAdmin
  break-glass, reads emit no audit row).
