# M32 · U04 — Web: public general issue-submission surface (`/issues/new`)

**You are the U04 agent.** This is a **code** unit (Web only). It ships the
public general issue-submission surface — the `IssueController` (the
`GET /issues/new` form + the `POST /issues/new` submission, **no**
`[Authorize]` gate — the M32·4 anonymous-safe pin), the `IssueFormModel`

`IErrorReportService.CreateAsync` with `Origin = "general"` (the M32·4 pin).

## Deliverables (≤ 3 files)

- **`src/Kumunita.Web/Controllers/IssueController.cs`** (new) — the
  **public** issue-submission controller (M32·4 — **no** `[Authorize]` gate).
  `[Route("issues")]`. `GET /issues/new` → `View(new IssueFormModel())`.
  `POST /issues/new` → bind `IssueFormModel` (the `Description` +
  `ContactEmail` fields), validate (`Description` required, non-blank — a
  form-level 400 re-render, the M32·4 pin), call
  `IErrorReportService.CreateAsync(new ErrorReportDraft(SubjectId,
  Description, ContactEmail, RequestId, ExceptionType: null, UserAgent,
  Origin: "general"))` (M32·4 — `Origin = "general"`, `ExceptionType =
  null`), re-render with `FormSubmitted = true` (the `issue.thanks`
  confirmation). `SubjectId` is the signed-in resident's
  `KumunitaPrincipal.SubjectId(User)` or `""` (anonymous). `RequestId` is
  `HttpContext.TraceIdentifier`. `UserAgent` is
  `Request.Headers.UserAgent` (truncated to 256). Inject
  `IErrorReportService` (constructor — the M31 `HomeController` injection
  shape).
- **`src/Kumunita.Web/Models/IssueFormModel.cs`** (new) — the form model
  (the M31 `ErrorReportFormModel` shape): `Description` (string,
  `[Required]`, `[StringLength(2000)]`), `ContactEmail` (string?,
  `[EmailAddress]`), `FormSubmitted` (bool, default `false`).
- **`src/Kumunita.Web/Views/Issues/New.cshtml`** (new) — the form view. The
  `issue.title` / `issue.intro` / `issue.description.label` /
  `issue.description.placeholder` / `issue.email.label` /
  `issue.email.placeholder` / `issue.submit` `kw-l` keys (the U06 closed set,
  the M31 `Error.cshtml` form shape). A `<textarea>` for the description, an
  `<input type="email">` for the optional contact email, a submit button. The
  form POSTs to `/issues/new` with the anti-forgery token. **Not** inside a
  `[Authorize]` gate (M32·4). When `Model.FormSubmitted` is `true`, render
  the `issue.thanks` confirmation instead of the form.
