# U02 — `Projects` context: the four documents + `M5DocTypes` + DI + boot wiring

**Goal:** create `src/Kumunita.Core/Projects/` with the four POCOs
(`TodoItem`, `KanbanBoard`, `KanbanLane`, `BoardItemPlacement`) exactly as
shaped in the design doc §2.2; create `src/Kumunita.Core/M5DocTypes.cs` (the
new surface, exactly §2.4); register the surface + the new context in DI and
both boot paths; build green. The service (U04) and the adapters (U03) land
after this unit — this unit only ships the document types + the surface
registration, so the schema exists before the lanes are written.

**Entry reads:**
- The design doc §2.2 (the exact `TodoItem` / `KanbanBoard` / `KanbanLane` /
  `BoardItemPlacement` shapes — the field names, the optionality, the `null`
  semantics are **the** pin) and §2.4 (the `M5DocTypes` surface + the
  business-key unique indexes).
- `src/Kumunita.Core/Events/Event.cs` + `EventRsvp.cs` (the **M4 document
  shape** to mirror — the conventional `string` `Id`, the optional `Audience`,
  the `Created` / `Modified?` stamps, the doc-comment convention).
- `src/Kumunita.Core/M4DocTypes.cs` (the **surface pattern** to mirror — the
  `Configure(StoreOptions)` entry point, the index / unique-index calls, the
  doc-comment convention).
- `src/Kumunita.Core/Posts/Post.cs` (the **`Audience` + `ComponentId` +
  `IsDeleted` + `TagIds` + `LanguageCode`** shape carried onto `TodoItem`).
- `src/Kumunita.Core/M2DocTypes.cs` (the `UniqueIndex` call shape — the
  `KanbanLane` `(BoardId, Order)` + the `BoardItemPlacement`
  `(BoardId, LaneId, Order)` / `(TodoItemId, BoardId)` unique-index shape).
- `src/Kumunita.Web/Program.cs` L110–125 (the `M4DocTypes.Configure(opts);`
  call at L117 — the **surface-registration site** U02 places
  `M5DocTypes.Configure(opts);` next to it; plus the dev-only
  `ApplyAllDatabaseChangesOnStartup` loop + the `SchemaBootstrap.ApplyAsync`
  boot — the `M5DocTypes` surface is registered via the `Configure` call, so
  both boot paths pick it up automatically — **U02's one edit site**).
- `src/Kumunita.Core/Bootstrap/SchemaBootstrap.cs` (the versioned
  storage-feature boot — `ApplyAllConfiguredChangesToDatabaseAsync` applies
  **all** registered surfaces; **M4 did not touch this file, so U02 does not
  either** — read-only context, no edit).
- `src/Kumunita.Core/DependencyInjection.cs` L179–190 (the
  `IEventService` registration shape — the `IProjectService` registration
  pattern **U04** mirrors; **U02 does not edit this file** — read-only
  context for U04's seam shape).
- `tests/Kumunita.Core.Tests/PostgresFixture.cs` (the harness shape — no test
  change in this unit, but the fixture is where `M5DocTypes` is first
  exercised in U12).

**Deliverables (5 files + 1 edit, no tests):**
- `src/Kumunita.Core/Projects/TodoItem.cs` (new) — the §2.2 `TodoItem`
  POCO, verbatim: `Id` (a `string`, the conventional Marten id), `Title`
  (non-empty), `Body?` (Markdown, optional), `ComponentId?` (a feed filter,
  never a gate — C-M3·2), `AuthorId`, `AssigneeId?` (a `SubjectId` —
  display + standing, **never** a gate), `Status?` (a string — the state
  label; `null` = none; **not** an enum), `ParentId?` (the sole hierarchy
  mechanism — `null` = top-level), `Audience?` (the exact post `Audience` —
  ADR 0001-B / 0036, `null` = public), `IsDeleted` (bool, `false` default —
  the ADR 0024 shape), `LanguageCode`, `TagIds`, `ImageIds`, `AttachmentIds`,
  `Created`, `Modified?`. **No** `BoardId` / `LaneId` / `Order` (C-M5·2);
  **no** `IsDraft` (the ADR 0037 draft lane is out of scope for M5 — D8a).
- `src/Kumunita.Core/Projects/KanbanBoard.cs` (new) — the §2.2
  `KanbanBoard` POCO, verbatim: `Id`, `Title` (non-empty), `Description?`
  (Markdown — the ADR 0025 shape), `ComponentId?` (a feed filter, never a
  gate — C-M3·2), `AuthorId` (the standing owner), `Audience?` (the exact
  post `Audience` — ADR 0001-B / 0036, `null` = public), `IsDeleted` (bool,
  `false` default — the ADR 0024 shape), `LanguageCode`, `Created`,
  `Modified?`. **No** `IsDraft` (D8a). **No** `Audience` on a lane (C-M5·3 —
  a lane's visibility is the board's).
- `src/Kumunita.Core/Projects/KanbanLane.cs` (new) — the §2.2 `KanbanLane`
  POCO, verbatim: `Id`, `BoardId` (the parent board), `Title` (non-empty —
  the lane label), `Status?` (a string — the status a lane imparts on a to-do
  moved into it; `null` = the lane imparts no status), `MaxItems?` (an int —
  the lane's capacity; `null` = no limit; **advisory**, refused not dropped —
  C-M5·5), `Order` (an int — the lane's position within the board, 0-based,
  the column order), `Created`, `Modified?`. **No** `Audience` (a lane's
  visibility is the board's — C-M5·3).
- `src/Kumunita.Core/Projects/BoardItemPlacement.cs` (new) — the §2.2
  `BoardItemPlacement` POCO, verbatim: `Id`, `TodoItemId` (the to-do),
  `BoardId` (the board), `LaneId` (the lane), `Order` (an int — the to-do's
  position within the lane, 0-based, the card order), `Created`, `Modified?`.
  **No** `Audience` (the placement's visibility is the to-do's + the board's
  — C-M5·3).
- `src/Kumunita.Core/M5DocTypes.cs` (new) — the §2.4 surface, verbatim:
  `public static class M5DocTypes { public static void Configure(StoreOptions opts) { … } }`
  (the `M4DocTypes` pattern verbatim). The four documents registered:
  - `TodoItem` — conventional `string` `Id` (Marten's default); the
    `(ComponentId, Created)` **feed-ordering** index (the
    `ListTodosAsync` feed orders survivors by `Created` descending — the
    M4 `Event` `(ComponentId, Start)` index shape); the `ParentId` index
    (the subtask lookup — the `GetTodoAsync` subtask read).
  - `KanbanBoard` — conventional `string` `Id`; the `(ComponentId, Created)`
    feed-ordering index (the `ListBoardsAsync` feed shape).
  - `KanbanLane` — conventional `string` `Id`; the `(BoardId, Order)`
    **unique** index (a lane's position within its board is a business key —
    the `EventRsvp` `(EventId, UserId)` unique-index shape, the last-write-wins
    concurrency exception).
  - `BoardItemPlacement` — conventional `string` `Id`; the `(BoardId, LaneId,
    Order)` **unique** index (a to-do's position within a lane is a business
    key — the same `EventRsvp` shape); the `(TodoItemId, BoardId)` **unique**
    index (a to-do appears on a board at most once — the M5 pin, the
    `EventRsvp` `(EventId, UserId)` shape carried to the to-do / board pair).
- `src/Kumunita.Web/Program.cs` (edit — the **only** edit) — add the
  `M5DocTypes.Configure(opts);` call **next to** the
  `M4DocTypes.Configure(opts);` call (L117, the surface-registration site —
  the M3/Media/Page/Tag/M4 precedent). This is the one edit site; the dev-only
  `ApplyAllDatabaseChangesOnStartup` loop and the `SchemaBootstrap.ApplyAsync`
  boot both pick the `M5DocTypes` surface up automatically (it is registered
  via the `Configure` call). **The `IProjectService` DI registration is
  U04's** (the interface doesn't exist until U04 — this unit ships the model
  + surface only, so the schema exists before the lanes are written).
