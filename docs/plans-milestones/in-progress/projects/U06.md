# U06 — the **placement + reorder lanes** (move up/down, move left/right + the lane-status auto-update, move-to-board, copy-to-board, the lane-limit refusal)

**Goal:** implement the **placement + reorder lanes** of `IProjectService` in
`src/Kumunita.Core/Projects/ProjectService.cs`, replacing the
`NotImplementedException` stubs U04 left: `MoveTodoWithinLaneAsync` (reorder
within a lane), `MoveTodoToAdjacentLaneAsync` (change lane + the lane-status

enforces. (The **hierarchy cycle guard** (C-M5·7) is **U05's** pin — it lives in
`UpdateTodoAsync`, where a reparent can create a cycle; U06 does not touch
`ParentId`.) **The `IProjectService` interface is frozen** (U04) — this unit
**implements** the stubbed methods, it does **not** re-shape the seam. Build
green.

**Deliverables (1 file edit, no new files, no tests):**
- `src/Kumunita.Core/Projects/ProjectService.cs` (edit) — replace the
  **placement-lane** stubs with the real implementation:
  - `public async Task<BoardItemPlacement> MoveTodoWithinLaneAsync(string placementId, string direction, string actorId, IReadOnlySet<string> actorRoles, CancellationToken ct = default)`
    — **`direction` is `"up"` or `"down"`** (a string, not an enum — the
    ADR 0031 plain-GET/POST posture; validate). Load the
    `BoardItemPlacement` row; resolve its `TodoItemId` → the `TodoItem`;
    **the standing re-check** over the **to-do** (C-M5·6): the
    **creator ∪ assignee ∪ GlobalAdmin** matrix. **Reorder** within the lane:
    swap `Order` with the adjacent card (the `BoardItemPlacement` row with
    the next lower / higher `Order` in the same lane — `"up"` = lower `Order`,
    `"down"` = higher `Order`). If the to-do is already at the edge (no
    adjacent card in that direction), the move is a no-op (the `Order` is
    unchanged). The **lane-limit refusal** (C-M5·5) does **not** apply to a
    reorder within a lane (the lane's placement count is unchanged). The
    `AccessAudit` row (`todo.move_within_lane`, `TargetKind "todo"`) is
    stored in the caller's session (C3).
  - `public async Task<BoardItemPlacement> MoveTodoToAdjacentLaneAsync(string placementId, string direction, string actorId, IReadOnlySet<string> actorRoles, CancellationToken ct = default)`
    — **`direction` is `"left"` or `"right"`** (a string, not an enum;
    validate). Load the `BoardItemPlacement` row; resolve its `LaneId` → the
    `KanbanLane`; resolve the lane's `BoardId` → the `KanbanBoard`; resolve
    the placement's `TodoItemId` → the `TodoItem`; **the standing
    re-check** over the **to-do** (C-M5·6): the **creator ∪ assignee ∪
    GlobalAdmin** matrix. **Change lane** (same board): find the adjacent
    lane (the `KanbanLane` row with the next lower / higher `Order` in the
    same board — `"left"` = lower `Order`, `"right"` = higher `Order`); if
    the lane is already at the edge (no adjacent lane in that direction), the
    move is a no-op. **The lane-limit refusal** (C-M5·5): if the target lane's
    `MaxItems` is non-null and the target lane already has `MaxItems`
    placements (count the `BoardItemPlacement` rows with `BoardId ==
    boardId && LaneId == targetLaneId`), the move is **refused** (a
    `InvalidOperationException` with the lane's `Title` in the message;
    nothing is written). If the target lane's `MaxItems` is null or the
    target lane is below the limit, the placement's `LaneId` is set to the
    target lane's id; `Order` is reset to the **end** of the target lane (the
    max `Order` + 1 in the target lane). **The lane-status auto-update**
    (C-M5·4): if the target lane's `Status` is non-null, the to-do's `Status`
    is set to that lane's status (in the same transaction — C3); if the
    target lane's `Status` is null, the to-do's status is unchanged.
    `KeyNotFoundException` (404) on an absent placement / lane / board /
    to-do. The `AccessAudit` row (`todo.move_to_lane`, `TargetKind "todo"`)
    is stored in the caller's session (C3).
  - `public async Task<BoardItemPlacement> MoveTodoToBoardAsync(string todoItemId, string targetBoardId, string actorId, IReadOnlySet<string> actorRoles, CancellationToken ct = default)`
    — **relocate** the placement (C-M5·8): load the `TodoItem` row;
    **the standing re-check** over the **to-do** (C-M5·6): the
    **creator ∪ assignee ∪ GlobalAdmin** matrix. Load the target
    `KanbanBoard` row; load its **first lane** (the `KanbanLane` row with the
    lowest `Order` in the target board). **The lane-limit refusal** (C-M5·5)
    applies to the target's first lane (the same C-M5·5 rule: if the first
    lane's `MaxItems` is non-null and at the limit, refuse). **The
    lane-status auto-update** (C-M5·4) applies to the target's first lane
    (the same C-M5·4 rule: if the first lane's `Status` is non-null, set the
    to-do's `Status` to that lane's status). Delete the placement rows on the
    **source** board (all the `BoardItemPlacement` rows with
    `TodoItemId == todoItemId && BoardId != targetBoardId` — the to-do's
    placements on other boards); create a new `BoardItemPlacement` row on the
    target board's first lane (`TodoItemId = todoItemId`, `BoardId =
    targetBoardId`, `LaneId = firstLaneId`, `Order = maxOrder + 1`). The
    to-do is now on the target board (and only the target board).
    `KeyNotFoundException` (404) on an absent to-do / board / lane. The
    `AccessAudit` row (`todo.move_to_board`, `TargetKind "todo"`) is stored in
    the caller's session (C3).
  - `public async Task<TodoItem> CopyTodoToBoardAsync(string todoItemId, string targetBoardId, string actorId, IReadOnlySet<string> actorRoles, CancellationToken ct = default)`
    — **duplicate** the to-do (C-M5·8): load the source `TodoItem` row;
    **the standing re-check** over the **to-do** (C-M5·6): the
    **creator ∪ assignee ∪ GlobalAdmin** matrix. Load the target
    `KanbanBoard` row; load its **first lane**. **The lane-limit refusal**
    (C-M5·5) applies to the target's first lane (the same C-M5·5 rule). **The
    lane-status auto-update** (C-M5·4) applies to the target's first lane
    (the same C-M5·4 rule: the **copy's** status is set to the first lane's
    status, if non-null). Create a new `TodoItem` row with the same `Title` /
    `Body` / `Status` / `AssigneeId` / `Audience` / `ComponentId` /
    `LanguageCode` / `TagIds` / `ImageIds` / `AttachmentIds` (the
    **`AuthorId` is the actor**, not the original's author — the copy is a
    new to-do, not a clone); **no** `ParentId` (a copy is always top-level — a
    subtask is not copied as a subtask; the copy is its own to-do, C-M5·7).
    Create a new `BoardItemPlacement` row on the target board's first lane
    (`TodoItemId = copy.Id`, `BoardId = targetBoardId`, `LaneId = firstLaneId`,
    `Order = maxOrder + 1`). The original to-do is **untouched** (C-M5·8).
    `KeyNotFoundException` (404) on an absent source to-do / target board /
    lane. The `AccessAudit` row (`todo.copy_to_board`, `TargetKind "todo"`)
    is stored in the caller's session (C3).
