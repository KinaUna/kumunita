# U05 — the **write lanes** (to-do create / edit / assign / add-subtask / delete; board create / lane CRUD / board delete)

**Goal:** implement the **write lanes** of `IProjectService` in
`src/Kumunita.Core/Projects/ProjectService.cs`, replacing the
`NotImplementedException` stubs U04 left: the **to-do** write lanes
(`CreateTodoAsync` / `UpdateTodoAsync` / `AssignTodoAsync` /
`AddSubtaskAsync` / `DeleteTodoAsync`) + the **board** write lanes
(`CreateBoardAsync` / `UpdateLaneAsync` / `DeleteBoardAsync`). Every
mutating lane **re-checks standing server-side** (the **creator ∪ assignee
∪ GlobalAdmin** matrix for to-do mutations; the **creator ∪ GlobalAdmin**
matrix for board / lane mutations — the ADR 0014 / 0016 / 0017 precedent
extended with the assignee as a collaborator, C-M5·6). **The
`IProjectService` interface is frozen** (U04) — this unit **implements** the
stubbed methods, it does **not** re-shape the seam. Build green.

**Deliverables (1 file edit, no new files, no tests):**
- `src/Kumunita.Core/Projects/ProjectService.cs` (edit) — replace the
  **write-lane** stubs with the real implementation:
  - `public async Task<TodoItem> CreateTodoAsync(string actorId, IReadOnlySet<string> actorRoles, CreateTodoRequest request, CancellationToken ct = default)`
    — insert a new `TodoItem` row: `Title` (non-empty — validate), `Body?`
    (Markdown — the ADR 0025 shape, optional), `ComponentId?` (a filter,
    never a gate — C-M3·2), `AuthorId = actorId`, `AssigneeId?` (a
    `SubjectId` — display + standing, **never** a gate), `ParentId?` (the
    sole hierarchy mechanism — `null` = top-level; a new to-do's `ParentId`
    is always a pre-existing to-do's id, so a cycle cannot form at creation
    time — the **hierarchy cycle guard** (C-M5·7) is enforced in
    `UpdateTodoAsync`, where a reparent can create one), `Audience?` (the
    exact post `Audience` — ADR 0001-B / 0036, `null` = public),
    `IsDeleted = false`, `LanguageCode`, `TagIds`, `ImageIds`, `AttachmentIds`,
    `Created = DateTimeOffset.UtcNow`, `Modified = null`. **No** `IsDraft`
    (D8a — a to-do is published on creation). The `AccessAudit` row
    (`todo.create`, `TargetKind "todo"`) is stored in the caller's session
    (C3). The author becomes the standing owner (the `AuthorId` branch).
  - `public async Task<TodoItem> UpdateTodoAsync(string todoItemId, string actorId, IReadOnlySet<string> actorRoles, UpdateTodoRequest request, CancellationToken ct = default)`
    — load the `TodoItem` row; **the standing re-check** (C-M5·6): the actor
    is allowed iff **creator** (`TodoItem.AuthorId == actorId`) ∪ **assignee**
    (`TodoItem.AssigneeId == actorId`) ∪ **GlobalAdmin** (`actorRoles`
    contains the GlobalAdmin role — the ADR 0017 override branch). If denied,
    `UnauthorizedAccessException` (403). If `Allowed`, apply the
    `UpdateTodoRequest` fields (`Title?` / `Body?` / `ComponentId?` /
    `Status?` / `LanguageCode` / `TagIds?`). **The hierarchy / reparenting**
    (C-M5·7): if `request.ClearParent` is `true`, set `ParentId = null`
    (unparent back to top-level); else if `request.ParentId` is non-null, set
    `ParentId = request.ParentId` (reparent to that to-do) — **and the
    hierarchy cycle guard**: before applying the reparent, walk the
    `ParentId` chain **down** from the to-do being updated (its descendants);
    if `request.ParentId` is the to-do itself or one of its descendants, the
    reparent would create a cycle (the to-do would become its own ancestor) —
    **refuse** with an `InvalidOperationException` and the would-be parent's
    `Title` in the message; nothing is written (the `F9_ReparentToDescendant_Refused`
    pin). Both `ParentId == null` + `ClearParent == false` is a no-op on the
    hierarchy. **`AuthorId` / `Created` are preserved untouched** (the
    standing owner is not reassigned on a to-do update); `Modified =
    DateTimeOffset.UtcNow` on a real change. `KeyNotFoundException` (404) on
    absent. The `AccessAudit` row (`todo.update`, `TargetKind "todo"`) is
    stored in the caller's session (C3).
  - `public async Task<TodoItem> AssignTodoAsync(string todoItemId, string actorId, IReadOnlySet<string> actorRoles, string? assigneeId, CancellationToken ct = default)`
    — load the `TodoItem` row; **the standing re-check** (C-M5·6): the same
    **creator ∪ assignee ∪ GlobalAdmin** matrix. Set `AssigneeId =
    assigneeId` (`null` = unassign); `Modified = DateTimeOffset.UtcNow`.
    `KeyNotFoundException` (404) on absent. The `AccessAudit` row
    (`todo.assign`, `TargetKind "todo"`) is stored in the caller's session
    (C3).
  - `public async Task<TodoItem> AddSubtaskAsync(string parentTodoItemId, string actorId, IReadOnlySet<string> actorRoles, CreateTodoRequest request, CancellationToken ct = default)`
    — load the parent `TodoItem` row; **the standing re-check** over the
    **parent** (C-M5·6): the same **creator ∪ assignee ∪ GlobalAdmin**
    matrix. Insert a new `TodoItem` row with `ParentId = parentTodoItemId`
    (the sole hierarchy mechanism — C-M5·7); the parent's `ParentId` is
    unchanged. `KeyNotFoundException` (404) on an absent parent. The
    `AccessAudit` row (`todo.add_subtask`, `TargetKind "todo"`) is stored in
    the caller's session (C3).
  - `public async Task DeleteTodoAsync(string todoItemId, string actorId, IReadOnlySet<string> actorRoles, CancellationToken ct = default)`
    — load the `TodoItem` row; **the standing re-check** (C-M5·6): the same
    **creator ∪ assignee ∪ GlobalAdmin** matrix. **Soft-delete** the to-do
    (sets `IsDeleted = true` — the ADR 0024 author-lane shape) + **cascade**
    to the descendant subtree (the `TodoItem` rows transitively reachable via
    `ParentId` — C-M5·7; the cascade is a `foreach` over the descendant ids,
    each soft-deleted). `KeyNotFoundException` (404) on absent. The
    `AccessAudit` row (`todo.delete`, `TargetKind "todo"`) is stored in the
    caller's session (C3).
  - `public async Task<KanbanBoard> CreateBoardAsync(string actorId, IReadOnlySet<string> actorRoles, CreateBoardRequest request, CancellationToken ct = default)`
    — insert a new `KanbanBoard` row: `Title` (non-empty — validate),
    `Description?` (Markdown — the ADR 0025 shape), `ComponentId?` (a filter,
    never a gate — C-M3·2), `AuthorId = actorId`, `Audience?` (the exact post
    `Audience` — ADR 0001-B / 0036, `null` = public), `IsDeleted = false`,
    `LanguageCode`, `Created = DateTimeOffset.UtcNow`, `Modified = null`.
    **No** `IsDraft` (D8a). Then insert the `KanbanLane` rows (the
    `CreateBoardRequest.Lanes`: each `CreateLaneRequest` → a `KanbanLane`
    row with `BoardId = board.Id`, `Title`, `Status?`, `MaxItems?`, `Order`).
    The author becomes the standing owner (the `AuthorId` branch). The
    `AccessAudit` row (`board.create`, `TargetKind "board"`) is stored in the
    caller's session (C3).
  - `public async Task<KanbanLane> UpdateLaneAsync(string laneId, string actorId, IReadOnlySet<string> actorRoles, UpdateLaneRequest request, CancellationToken ct = default)`
    — load the `KanbanLane` row; **the standing re-check** over the
    **board** (C-M5·6): the lane's standing is the **board's** — the actor is
    allowed iff **creator** (`KanbanBoard.AuthorId == actorId`) ∪
    **GlobalAdmin** (`actorRoles` contains the GlobalAdmin role). The
    **assignee branch does not apply to a lane** (a lane is not its own
    standing surface — C-M5·6). If denied, `UnauthorizedAccessException`
    (403). If `Allowed`, apply the `UpdateLaneRequest` fields (`Title?` /
    `Status?` / `MaxItems?` / `Order?`); `Modified = DateTimeOffset.UtcNow` on
    a real change. `KeyNotFoundException` (404) on absent. The
    `AccessAudit` row (`board.update_lane`, `TargetKind "board"`) is stored in
    the caller's session (C3).
  - `public async Task DeleteBoardAsync(string boardId, string actorId, IReadOnlySet<string> actorRoles, CancellationToken ct = default)`
    — load the `KanbanBoard` row; **the standing re-check** over the board
    (C-M5·6): the **creator ∪ GlobalAdmin** matrix (the assignee branch does
    not apply to a board). **Soft-delete** the board (sets `IsDeleted = true`
    — the ADR 0024 author-lane shape) + **delete** the board's `KanbanLane`
    rows + **delete** the board's `BoardItemPlacement` rows (the placements
    are **not** cascaded to the to-dos — a to-do on a deleted board is still
    standalone, C-M5·2). `KeyNotFoundException` (404) on absent. The
    `AccessAudit` row (`board.delete`, `TargetKind "board"`) is stored in the
    caller's session (C3).
