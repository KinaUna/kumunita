## TD — Tag display on post detail + editable tags on edit + nav discoverability (2026-09-20)

**Status:** landed. A follow-up to the closed TG lane that fixes three user-visible gaps found after ship: **(1)** tags were undiscoverable (no `/tags` link anywhere in the nav/footer), **(2)** a post's tags were not shown on the post detail page, and **(3)** the edit form did not seed or allow editing/removing a post's existing tags. All three are additive Web-lane affordances over the **frozen** `ITagService` read seam + the U8b `AttachToPostAsync` write seam — **no new seam, no signature change, no Core re-scope** (the §2.6 no-new-methods / no-new-seam invariants hold: `TagService.cs` / `ITagService.cs` are untouched; the one `PostService.UpdatePostAsync` edit is a guard-loosening on the *already-frozen* attach seam, not a new member).

- **(a) Display on post detail (the "read, not a decision" surface).** `PostsController.Detail` resolves the post's `TagIds` (which hold `Tag` **Ids**, not slugs — `PostService` writes `resolved.Select(t => t.Id)`) through the existing access-scoped `ITagService.ListForActorAsync(actor)` read seam (already resolves the `DisplayedName` in the viewer's language, ADR 0005 order) and filters to the post's ids. A dangling `TagId` whose `Tag` row the actor cannot resolve is simply dropped (C-TG·1 — a broken reference renders as **nothing**, not a 404/error). `PostDetailViewModel` gains `IReadOnlyList<(string Slug, string DisplayedName)> Tags` (default `[]`); `Views/Posts/Detail.cshtml` renders each as a `<a class="badge …" href="/tags/{slug}">` inside the `Model.Post.DeletedAt is null` block (a deleted post shows no tags). The `ITagService` is injected into `PostsController` as an **optional trailing** `tags = null` ctor param (the `translationProvider = null` idiom — existing test-construction sites keep compiling; DI always supplies the live seam).
- **(b) Editable + removable tags on edit.** `PostService.UpdatePostAsync`'s write guard is loosened from `tagSlugs is { Count: > 0 }` to `tagSlugs is not null` — a **tri-state**: `null` = preserve the post's existing tags (call sites that omit the arg keep the prior no-op), empty non-null = **detach all** (the U8b `AttachToPostAsync` empty-set detach — it sets `Post.TagIds` unconditionally once standing passes), non-empty = attach. `PostsController` Edit POST now passes `model.TagIds is null ? null : TagSlugs.Parse(model.TagIds)` — the bound `string?` distinguishes "field absent" (JS off ⇒ preserve, a JS-disabled author must not lose tags) from "present-empty" (author removed every chip ⇒ detach).
- **(c) Pre-seed the edit form with the post's current tags.** `PostComposeViewModel` gains `[BindNever] IReadOnlyList<string> ExistingTagSlugs` (default `[]`) — the tag-suggest input's starting chips. **Slugs, not display names:** a translated/accented display name would throw in `DeriveSlug` on re-save (C-TG·4), so the seed is the charset-safe business key. `Views/Posts/Edit.cshtml` renders it as `data-tag-suggest-initial='<json>'` (slugs have no single quotes ⇒ safe in a single-quoted attribute). `client/lib/tag-suggest.ts` reads `input.dataset.tagSuggestInitial` (a JSON array), adds each to its `selected` set on init (try/catch degrades to no seed — a display affordance, never a gate), and now calls `syncHidden()` before the final `renderChips()` so the hidden `TagIds` field + chips reflect the seed. A new/untagged post has no attribute ⇒ unchanged free-text behavior.
- **(d) Re-render re-seeds (the destructive-detach guard).** Because the Edit POST **re-renders** the form on a validation error or a bad slug (`return View(model)`), and `ExistingTagSlugs` is `[BindNever]` (so `[]` on POST), the seeding was factored into `SeedExistingTagSlugsAsync(Post?)` (its own short-lived `store.QuerySession()`; a missing post ⇒ `[]`) and called from **both** the GET and the POST re-render paths. Without the POST re-seed, a validation-error re-render would open the tag input with no chips and — under the new empty-set-detach semantics — a follow-up submit would **silently drop the author's intended tags**.
