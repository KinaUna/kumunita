# M27 U07 — Web: the `/account/portability` index + the import upload + the export kw-l keys

## Context (self-contained)

M27 = **user-scoped portability**: a resident exports/imports **their own
authored data** and resolves per-entity conflicts. U03 shipped the export.
U04/U05/U06 shipped the classify + resolve model + apply. U07 renders **D5's
Web surface, part 1**: the `UserPortabilityController`
(`/account/portability` — the resident's own data, `[Authorize]`, verified)
with the index (the export button + the import upload form + the status area)
+ the `GET /account/portability/export` stream action (reusing the M11
`Content-Disposition: attachment` shape) + the `POST
/account/portability/import` (the `ClassifyAsync` delegation) + the export /
import kw-l keys. Mirrors `AdminPortabilityController` in shape but at the
resident scope + `Via = Owner`. **Zero new authorization surface** (C-M27·7) —
the gate is the resident self-lane (`[Authorize]` verified), the resident's
own data only.

## Goal

Create the `UserPortabilityController` (the `/account/portability` index +
`GET /account/portability/export` + `POST /account/portability/import` (the
`ClassifyAsync` delegation, the fail-closed render of the
`clean`/`duplicate`/`conflict` report)) + the `Index.cshtml` view (the export
button + the import upload form + the status area) + the export / import
kw-l keys in `KnownTranslationKeys` × en/de/fr/da.
