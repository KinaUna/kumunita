## Understanding

This unit adds the **GlobalAdmin-gated** `GET /admin/storage` surface — a
**read-only** view of the four metrics (total used, available,
user-content used, per-user table) + the per-user table (paged, sorted by
bytes desc) + one nav row on the `/admin` hub. It mirrors the M13
`AdminAnalyticsController` (the `GlobalAdmin` gate + the `QuerySession`
read + the "no audit row on a read" discipline). **No form, no write, no
settings** — M25's U5/U6 own the set-lane. **The `/admin/storage` surface
is the M24 admin view — M25's `/admin/storage` is the admin *settings*
view (the per-file limit + per-user quota); the two surfaces are
distinct** (M24 is *metrics*, M25 is *settings*; the M25 plan names
`/admin/storage` for its settings view, but M25's U5 is written to
"reuse M24's metrics seam if present" — see `in-progress/m25-u05.md` line
37 — so the two can coexist on the same route if M25's U5 extends M24's
view, or M25 can use a distinct route like `/admin/storage/settings` —
the M25 agent's call, not M24's).
