> **Sealed unit.** One fresh agent, ~32K context window. Self-contained. The

## Understanding

This unit applies the **U10 `_Sort` pattern** to the **tag** surfaces (by-tag
posts, by-tag pages — the `TagController` `ByTag` action +
`TagByTagViewModel`, a **dual-pager** surface with `PagerPosts` +
`PagerPages`) and the **people-find** surfaces (the `FindPeopleController`
`FindPeopleByTag`/`FindPeopleByBio` actions + the `FindPeople*ViewModel`s) —
the view-model `Sort` field + the `@Html.Partial("_Sort", ...)` + the pager-
carry + the `SortSpec` threading — with the **pinned Web tests** (U2 §2.6).
**Reuse U10's `SortViewModel`/`_Sort` verbatim — do not fork.** **Note:** the
`TagByTagViewModel` dual-pager surface (posts + pages) gets **its own** `Sort`
per section (C-SORT·1/F9), mirroring the `PagerPosts`/`PagerPages` split —
the tag-pages `created`-**asc** default (C-SORT·2) must be preserved exactly.

## Rules
- **Reuse** U10's `SortViewModel`/`_Sort` verbatim (C-SORT·1 — each surface
