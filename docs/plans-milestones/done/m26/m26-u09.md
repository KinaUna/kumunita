## Understanding

This unit adds the **additive `SortSpec? sort = null`** parameter to the
**search seam** (`SearchService.SearchSurfaceAsync` + the
`ISearchService` seam), applying the search allowlist (U2 §2.2: `created`
default desc + the surface's `title`/`name` key) to the **per-surface**
orderings (the 10 `OrderByDescending(...Created)` sub-queries), + the
tie-breaker, and the **pinned Core tests** (U2 §2.5, the `Search*_*` set).
**`null` preserves the per-surface `OrderByDescending(Created)` exactly
(C-SORT·2).** **Relevance is NOT a sort key** (M8 frozen — a named
non-decision).
