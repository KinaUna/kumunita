> register (`docs/plans-milestones/plan-m26-sorting.md`) is the

## Understanding

This unit adds the **additive `SortSpec? sort = null`** parameter to the
**three misc-list seams** (`AnnouncementService.ListVisiblePagedAsync`,
`DocumentService.ListAsync`, `InventoryService.ListItemsAsync`) + their
interfaces, applying the allowlists (U2 §2.2: announcements `created`/
`modified`/`title`; documents `created`/`modified`/`title`/`size`; inventory
`created`/`modified`/`name`) + the tie-breaker, and the **pinned Core tests**
(U2 §2.5). **`null` preserves each surface's current order exactly (C-SORT·2).**

## Deliverables (≤ 4 files)
1. **The 3 service files** — the 3 seams gain `SortSpec? sort = null`; `null`
   keeps each surface's current order **exactly**; non-null applies the
   allowlist `switch` + `.ThenBy(Id)`. Documents' `size` sorts on `SizeBytes`
   (numeric).
2. **The 3 interfaces** — the matching `SortSpec? sort = null` parameters.
3. **`tests/Kumunita.Core.Tests/MiscList/MiscListSortTests.cs`** (or one file
   per surface, per U2 §2.5) — the pinned `Announcement*_*`/`Document*_*`/
   `Inventory*_*` tests (each: null-default pin, the extra key —
   `Document_SortSize`, `Inventory_SortName_Ordinal`, the `modified`/`title`
   keys, invalid-key fallback, tie-break).

## Rules
- **C-SORT·2** — `null` keeps each surface's current order (all 3:
  `OrderByDescending(Created)`).
- **C-SORT·4** — no new audit row; **do not** touch document access control
  (ADR 0122) or the inventory owner-kind/component filter (frozen).
- **C-SORT·5** — the tie-breaker is present on every non-null sort path.
- **Do not** change the `HasMore`/paging computation.
