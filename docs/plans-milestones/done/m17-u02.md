## Goal

Create the `Kumunita.Core.Bookmarks` service seam: **`IBookmarkService`**
(the public surface) + **`BookmarkService`** (the composition service — a
concrete class pairing the frozen seams with the host-registered Marten
`IDocumentStore`, the M2 `DirectoryService` / M3 `PostService` shape), the
result types (per design doc §2.2), and the DI registration in
`Kumunita.Core/DependencyInjection.cs`. Then the **14 pinned Core tests**.

**The locked decisions you implement (from the design doc — read §2.2, §2.3,
§2.4, §2.5 verbatim):**
- **D2** — a bookmark is a **personal-by-id** record; the list lane makes
  **no** `CanSeeAsync` pass over the bookmark rows themselves (C-M17·2).
- **D3** — the write lane (bookmark / toggle) **re-runs the target's own
  frozen `Read` decision** before the row is created; Deny ⇒ `Refused`
  (the Web layer maps to **404**, not 403), **no row survives**.
- **D4** — toggle = idempotent add / physical remove; **no** `IsDeleted`;
  a duplicate bookmark is a **no-op** (the `AlreadyBookmarked` result);
  re-bookmark after removal is a fresh `Created`.
- **D5** — the list resolves each row by `TargetKind` + `TargetId` against
  the owning surface's read seam; a dangling row renders as a **degraded**
  label (no title, no link, no id) — and the unbookmark control still
  works on it.

2. `src/Kumunita.Core/Bookmarks/BookmarkResult.cs` — the result types
   (the **exact** §2.2 shape, verbatim):
   ```csharp
   public enum BookmarkToggleStatus
   {
       Bookmarked,        // a new row was created
       AlreadyBookmarked, // a row already existed (the F1 no-op)
       Refused,           // the D3 write-lane visibility check failed (404)
       Removed,           // the row was physically removed
       NotBookmarked,     // no row existed to remove (a no-op)
   }

   public sealed record BookmarkToggleResult(
       BookmarkToggleStatus Status,
       string? BookmarkId);   // the row's Id (null on Refused / NotBookmarked)

   public sealed record BookmarkRow(
       string TargetKind,
       string TargetId,
       string? Title,         // null when Degraded
       string? Link,          // null when Degraded
       bool Degraded,
       DateTimeOffset Created);

   public sealed record BookmarkGroup(
       string Kind,           // one of the closed set
       IReadOnlyList<BookmarkRow> Items);

   public sealed record BookmarkListResult(
       IReadOnlyList<BookmarkGroup> Groups);
   ```
   Each type carries a `/// <summary>` documenting the locked decisions
   (D4/D5) it implements, mirroring the `PostDetailResult` tone.

3. `src/Kumunita.Core/Bookmarks/BookmarkService.cs` — the composition
   service (a concrete class, the M2 `DirectoryService` / M3 `PostService`
   shape — it **composes two seams**, not itself a seam):
   - **Constructor**: `IUserInfoService`, `IAuthorizationService`,
     `IDocumentStore`, `IAnnouncementService`, `IPageService`,
     `IEventService`, `IProjectService` (the frozen seams + the host-
     registered Marten store).
   - **`ListAsync`**: loads the owner's `Bookmark` rows (ordered by
     `Created` descending), groups them by `TargetKind` (the closed set,
     §2.1), and resolves each row's `Title` / `Link` / `Degraded` by
     `TargetKind` (the D5 mechanism, §2.4 — the owning surface's read
     seam; a dangling row is `Degraded: true`, no title, no link, no id).
   - **`ToggleAsync`**: first re-runs the target's **own** frozen `Read`
     decision (the D3 write-lane check, §2.3 — the *same call the detail
     page uses*: `PostService.GetPostAsync` / `IEventService.GetAsync` /
     `IProjectService.GetTodoAsync` / `IAnnouncementService.GetAsync` /
     the page surface's own read seam — `GetByPathAsync` /
     `ResolvePageAsync`, see Entry read 7); if the target is not visible
     (null / `KeyNotFoundException` / `UnauthorizedAccessException`),
     returns `Refused` (the Web layer maps to a 404) **and no row is
     created**.
     Otherwise, checks for an existing row (the `AlreadyBookmarked`
     no-op, F1); if none, creates a fresh `Bookmark` row (a new `Id`,
     a fresh `Created`) and returns `Bookmarked`.
   - **`RemoveAsync`**: deletes the row **physically** (no `IsDeleted`,
     D4); returns `Removed` if a row was deleted, `NotBookmarked` if none
     existed.
