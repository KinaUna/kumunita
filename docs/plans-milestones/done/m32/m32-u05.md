## Deliverables (≤ 7 files)

- **`src/Kumunita.Web/Services/IEscalationForwarder.cs`** (new) — the Web-
  layer interface (M32·5 — namespace `Kumunita.Web.Services`, **not**
  `Kumunita.Core`): `public interface IEscalationForwarder { Task
  <EscalationResult> ForwardAsync(string reportId, CancellationToken ct =
  default); }` + `public sealed record EscalationResult(bool Configured,
  bool Success, int? StatusCode, string? Error);` (the §2.1 shape verbatim).
- **`src/Kumunita.Web/Services/EscalationForwarder.cs`** (new) — the impl.
  Constructor: `(IConfiguration configuration, IErrorReportService
  errorReports, IHttpClientFactory httpClientFactory)`. `ForwardAsync`: read
  `configuration["KUMUNITA:ESCALATION_ENDPOINT"]` (M32·6 —
  `IConfiguration` maps `KUMUNITA_ESCALATION_ENDPOINT`). **If absent** →
  `return new EscalationResult(Configured: false, Success: false,
  StatusCode: null, Error: null)`. **If present** → load the report via
  `errorReports.ListAsync(1)` (a read — no audit), filter to the `reportId`,
  **if missing** → `return new EscalationResult(Configured: true, Success:
  false, StatusCode: null, Error: "report not found")`. **If found** →
  `var client = httpClientFactory.CreateClient(); client.Timeout =
  TimeSpan.FromSeconds(10);`, build the JSON payload (`{ id, subjectId,
  description, contactEmail, requestId, exceptionType, origin, created }`),
  `var response = await client.PostAsJsonAsync(endpoint, payload, ct);`,
  `return new EscalationResult(Configured: true, Success:
  response.IsSuccessStatusCode, StatusCode: (int)response.StatusCode, Error:
  response.IsSuccessStatusCode ? null : response.ReasonPhrase)`. **Catch** a
  `TaskCanceledException` / `HttpRequestException` → `return new
  EscalationResult(Configured: true, Success: false, StatusCode: null, Error:
  ex.Message)` (M32·7 — a transport error is a failed forward).
- **`src/Kumunita.Web/Controllers/ErrorReportAdminController.cs`** (modify) —
  add the `IEscalationForwarder? escalationForwarder = null` ctor param
  (M32·5 — optional, the M31 `localization`/`translationProvider` optional-
  ctor-param precedent). Add `GET /admin/error-reports/{id}` (the detail
  view — load the report via `ListAsync(1)`, **if missing** → `NotFound()`,
  **if found** → `View(new AdminErrorReportDetailViewModel { Report =
  report })`). Add `POST /admin/error-reports/{id}/resolve` — bind the
  `ResolutionNote` (string?), call
  `errorReports.MarkResolvedAsync(id, actor, resolutionNote)` (M32·8), **if
  `null`** (no-op) → redirect with **no** flash, **if non-null** → redirect
  with a `TempData["info"]` flash (the `errorreport.resolve.flash` kw-l key).
  Add `POST /admin/error-reports/{id}/escalate` — **if
  `escalationForwarder is null`** → redirect with a `TempData["error"]`
  flash (the `errorreport.escalate.not_configured` kw-l key); **else** →
  `var result = await escalationForwarder.ForwardAsync(id);`, **if
  `result.Configured == false`** → redirect with a `TempData["error"]` flash
  (the `errorreport.escalate.not_configured` kw-l key, M32·6); **if
  `result.Success == false`** → redirect with a `TempData["error"]` flash
  (the `errorreport.escalate.flash_failure` kw-l key, M32·7 — **no** state
  change); **if `result.Success == true`** → `await
  errorReports.MarkResolvedAsync(id, actor, "Escalated to operator
  endpoint")` (M32·7 — the successful forward stamps `resolved`), redirect
  with a `TempData["info"]` flash (the
  `errorreport.escalate.flash_success` kw-l key).
