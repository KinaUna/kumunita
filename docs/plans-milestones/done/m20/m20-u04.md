## Deliverables (3 files)

### 1. `src/Kumunita.Core/Notifications/NotificationFlushService.cs` (D5)

A **Wolverine-free static class** (the `EventReminderService` shape) that the
Web `NotificationFlushHandler` (U05) calls with a live `IDocumentStore`:

```csharp
/// <summary>
/// M20 (ADR 0121, D5) — the §6.4 durable notification-flush job's business
/// logic (the EventReminderService precedent verbatim — a Wolverine-free
/// static class the Web host's thin adapter (U05) calls with a live
/// IDocumentStore). Per run: (1) load the bounded set of Notification rows
/// with EmailDeferred == true (ordered by Created); (2) for each, re-resolve
/// the ADR 0019 effective zone + re-evaluate the PURE
/// QuietScheduleEvaluator.IsQuietNow (D3) at the RUN instant; (3) for each
/// NO LONGER quiet, stage the held email via the frozen IMailerStage under the
/// deferred key (U03's NotificationService.DeferredKey) and flip that row's
/// EmailDeferred == false; (4) leave each STILL-quiet row EmailDeferred ==
/// true (re-checked next run). One SaveChangesAsync per run (C3). Re-runnable:
/// a row already cleared (EmailDeferred false) is never re-staged (the §6.2
/// idempotent guard + the deferred-key outbox dedup, C-M20·4).
/// </summary>
public static class NotificationFlushService
{
    /// <summary>One flush run. Returns the number of emails delivered this
    /// run (for the handler's log line). `now` is passed explicitly so the
    /// boundary is deterministic under the test harness (the
    /// EventReminderService shape verbatim — the AuditPurgeHandler "now is
    /// passed explicitly" precedent).</summary>
    public static async Task<int> FlushAsync(
        IDocumentStore store,
        DateTimeOffset now,
        IMailerStage mailer,
        ILocalizationService localization,
        ITranslationProvider translationProvider,
        IUserInfoService userInfo,
        CancellationToken ct = default);
}
```

Implement: query `Notification` rows where `EmailDeferred == true` (order by
`Created`); for each, `GetQuietScheduleAsync` (U02) + resolve the effective zone
(the ADR 0019 chain — `userInfo` profile `TimeZone` → `localization.
GetDefaultTimezoneAsync()` → `UTC`) + `QuietScheduleEvaluator.IsQuietNow` (D3);
if **not** quiet, build the email subject/body the way `EmitAsync` did (reuse
the recipient's `Profile.EmailLanguage` + the `notification.{kind}.subject` /
`.body` templates + the UGC snippet the row already carries in
`Notification.Body`/`Subject` — the row stores the localized display values),
stage via `mailer.StageAsync(session, NotificationService.DeferredKey(kind,
sourceId), recipient, subject, body)` (U03's key), set
`notification.EmailDeferred = false`, and collect the recipients' emails (a
recipient with no email is skipped — the M4/M6 "no address to deliver to"
precedent, but the row is **still** cleared so it is not re-tried forever — see
the `C-M20·4` note below); `SaveChangesAsync` once. **Do not** call
`EmitAsync` (it would re-store the inbox row — D7 / §drift-guard).

> **`C-M20·4` "no address" note:** if a deferred row's recipient has no email
> (no `Profile.Email`), there is nothing to stage — clear `EmailDeferred ==
> false` anyway (the row is resolved; it is not a "still pending" email). The
> GATE-4 pin covers the deliverable path; the no-address path is a documented
> edge in the design doc §7 (the `EventReminderService` "recipient without a
> `Profile` email is skipped" precedent, applied to a *deferred* row).

```csharp
/// <summary>
/// M20 (ADR 0121, D6) — how often the §6.4 notification-flush job re-checks
/// the held (deferred) notification emails, in **minutes**. An *additive*

/// (missing row → 60) is resolved in the Core read seam, not here.
/// </summary>
public int QuietCheckMinutes { get; set; } = 60;
```

## Pinned tests (add to the `Kumunita.Core.Tests` `NotificationService` / flush test file)

- **GATE-4 pin (C-M20·4 — never loss + idempotent)** —
  `FlushAsync_ClearsQuietRow_StagesEmail_Once`: a row with `EmailDeferred ==
  true` whose schedule is **no longer** quiet at the run instant → `FlushAsync`
  stages the email under `DeferredKey` (assert the faked `IMailerStage` was
  called once with that exact key) and clears `EmailDeferred == false`. A
  **second** `FlushAsync` run stages **nothing** (the row is cleared; idempotent).
- **GATE-4 pin (still-quiet stays deferred)** —
  `FlushAsync_StillQuietRow_Stays_Deferred`: a row whose schedule is **still**
  quiet at the run instant → `FlushAsync` stages **nothing** and leaves
  `EmailDeferred == true` (re-checked next run).
- **GATE-6 pin (C-M20·6 — floor + GlobalAdmin-only + one audit)** —
  `SetQuietCheckMinutesAsync_FloorsAndAudits`: a missing `LocaleSettings` row
  reads back `60` (`GetQuietCheckMinutesAsync`); a valid write (e.g. `15`)
  persists + appends **exactly one** `AccessAudit` row (`Via = Admin`); an
  out-of-range value (`0` or `99999`) throws `ArgumentOutOfRangeException` and
  writes nothing.
