# M20 · U07 — Admin cadence surface: `AdminQuietController` + the `/admin` affordance (Web)

**You are the U07 agent.** This is a **Web** unit: it adds the
**GlobalAdmin-gated** `/admin/quiet` surface — the thin control plane over the
**flush cadence** (`QuietCheckMinutes`, D6) — mirroring the
`AdminSignupController` (ADR 0050) / `AdminTimezoneController` (ADR 0019)
singleton-toggle shape verbatim. It **consumes** U04's two audited seams
(`GetQuietCheckMinutesAsync` / `SetQuietCheckMinutesAsync`) and U06's four
`admin.quiet.*` kw-l keys, and adds **none** of its own. It does **not** add
the resident section (U06) nor the flush job (U05). Exit: **Web.Tests**.

## Deliverables (3 files + pins)

### 1. `AdminQuietController.cs` — the cadence surface

Mirror `AdminSignupController` verbatim (dedicated controller, not a new
dependency on the constructor-pinned `AdminController` — the same reason ADR
0050 chose a dedicated `/admin/signup` controller):

```csharp
using Kumunita.Core.Notifications;
using Kumunita.Web.Security;
using Microsoft.AspNetCore.Authorization;
using Microsoft.AspNetCore.Mvc;

namespace Kumunita.Web.Controllers;

/// <summary>
/// The /admin/quiet surface (ADR 0121 D6) — the GlobalAdmin's thin control
/// plane over the notification-flush cadence (how often the §6.4 job re-checks
/// the held, deferred emails, in minutes). Mirrors AdminSignupController
/// (ADR 0050) / AdminTimezoneController (ADR 0019) exactly:
/// Roles.GlobalAdmin-gated, a thin wrapper over the ONE audited
/// NotificationService seam (GetQuietCheckMinutesAsync /
/// SetQuietCheckMinutesAsync), and the audit row is the service's (exactly
/// one AccessAudit, Via = Admin, action notification.quiet.cadence — the
/// singleton-toggle shape, the same as signup.set-open /
/// timezone.set-default).
/// </summary>
[Route("admin/quiet")]
[Authorize(Roles = Kumunita.Core.Identity.Roles.GlobalAdmin)]
public sealed class AdminQuietController(
    NotificationService notifications) : Controller
{
    private static string? ActorId(System.Security.Claims.ClaimsPrincipal user) =>
        KumunitaPrincipal.SubjectId(user);

    /// <summary>
    /// GET /admin/quiet — reads the current cadence (the U04 read seam, which
    /// floors a missing LocaleSettings row to 60) into the form.
    /// </summary>
    [HttpGet]
    public async Task<IActionResult> Index()
    {
        var model = new CadenceAdminViewModel
        {
            Minutes = await notifications.GetQuietCheckMinutesAsync()
        };
        return View(model);
    }

    /// <summary>
    /// POST /admin/quiet — sets the cadence. Delegates to
    /// SetQuietCheckMinutesAsync (the single audited write lane — exactly one
    /// AccessAudit row, Via = Admin). The seam validates 5–1440
    /// (ArgumentOutOfRangeException out of range) and owns the audit; the
    /// GlobalAdmin standing check is this controller's [Authorize] gate (the
    /// ADR 0050 split — the controller owns the role, the service owns the
    /// audit). Success → a surfaced info + redirect (the change is live on the
    /// very next flush tick — data, not config).
    /// </summary>
    [HttpPost]
    [ValidateAntiForgeryToken]
    public async Task<IActionResult> Save(int minutes)
    {
        var actor = ActorId(User) ?? string.Empty;
        try
        {
            await notifications.SetQuietCheckMinutesAsync(minutes, actor);
            // The admin shell's local convention (the AdminSignupController /
            // AdminTimezoneController shape) — a plain-English TempData["info"]
            // flash on the POST; the admin.quiet.flash_saved kw-l key (U06) is
            // the view's save-confirmation label, not a TempData string.
            TempData["info"] = "The notification flush cadence is now " +
                               minutes + " minutes.";
        }
        catch (ArgumentOutOfRangeException ex)
        {
            TempData["error"] = ex.Message; // the seam's 5–1440 range message
        }
        return RedirectToAction(nameof(Index));
    }

    // ── View model (public nested type so the Razor view can bind to it) ──
    public sealed class CadenceAdminViewModel
    {
        public int Minutes { get; init; } = 60;
    }
}
```

> **Note on the flash key:** the `admin.quiet.*` kw-l keys (U06's set —
> `title` / `cadence_label` / `save` / `flash_saved`) are consumed on the
> **view** (`Quiet.cshtml`), where they render as a `kw-l`-resolved label.
> The `TempData["info"]` flash on the POST is plain English (the
> `AdminSignupController` / `AdminTimezoneController` convention — the admin
> shell is mostly non-kw-l English; this view's `KwLRegistryConsistencyTests`
> static-key scan would break on an interpolated kw-l key). The pin in
> Deliverable 4 asserts the `admin.quiet.*` keys are present in the registry
> (U06 authored them); it does **not** assert the exact `TempData` string.

### 4. Web pin tests (≥3, in `tests/Kumunita.Web.Tests/`)

- **Pin 1 — GlobalAdmin read/write round-trip.** With a GlobalAdmin principal,
  `GET /admin/quiet` returns the cadence from
  `GetQuietCheckMinutesAsync` (assert the faked seam was called);
  `POST /admin/quiet` with `minutes=30` calls
  `SetQuietCheckMinutesAsync(30, actor)` (assert the faked seam was called
  with `30` + the signed-in actor) and redirects.
- **Pin 2 — non-GlobalAdmin refused (GATE-6 surface side).** With a
  non-GlobalAdmin principal (a plain Member), `GET /admin/quiet` and
  `POST /admin/quiet` are **refused** (the `[Authorize(Roles = GlobalAdmin)]`
  gate → 403 / a redirect to the sign-in page — the ADR 0050 gate pin
  shape). Assert the Core `SetQuietCheckMinutesAsync` seam is **not** called
  on the refused POST.
- **Pin 3 — out-of-range write surfaces the seam's error, no audit.**
  `POST /admin/quiet` with `minutes=0` (or `99999`) → the seam throws
  `ArgumentOutOfRangeException` → the action surfaces the error (assert the
  faked seam was called, the exception was caught, and no
  `TempData["info"]` success flash is set). The **one audit row on the valid
  path** is already pinned in Core.Tests (U04's GATE-6); this pin asserts the
  Web boundary does not add a second audit.
