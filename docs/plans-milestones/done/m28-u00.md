# M28 U00 — Lock the design: `m28-guardian-time-limits-design.md` + ADR 0151

## Context (self-contained)

M28 = **Guardian time limits**: for a **child's** account, a **parent/guardian
sets when the child may use the platform** — allow or block certain hours of
each day and days of the week. It is a **new lane on the GU guardian surface**
(ADR 0028 / ADR 0038), the **inverse of the M20 notification-quiet lane**
(ADR 0121): M20 lets a *resident* hold their own *notification emails* during
a window; M28 lets a *guardian* gate a *child's* *whole-platform access*
during a window. It reuses the M20 **pure-evaluator shape** (the
`QuietScheduleEvaluator.IsQuietNow(schedule, now, zone)` discipline,
wall-clock-first per ADR 0019) but flips the **owner** (guardian, not
resident), the **polarity** (allowed/restricted, not quiet/held), and the
**effect** (a sign-out access gate, not an email deferral).

**What U00 locks (this is the sign-off gate for the whole milestone):**
1. **D1–D9** (the register's [PROPOSED] set — refine where the source says
   more, recording the refinement).
2. **C-M28·1 … C-M28·7 invariants** (each with a one-line note).
3. **F1–F6 FACES** (each bound to an invariant).
4. **The `GuardianTimeLimitSchedule` field pin** (the
   `NotificationQuietSchedule` shape, per-child id = `ChildId`).
5. **The `TimeLimitMode` enum pin** (`Blocked`/`Allowed`, the

6. **The pure-evaluator pin** (`IsAllowedNow(schedule, now, zone)`).
7. **The three-seam pin on `IUserInfoService`** (the D4 seam set).

   `BlockedAccountMiddleware` shape).
