# M27 U03 — Export: the resident-scoped document + media export

## Context (self-contained)

M27 = **user-scoped portability**: a resident exports/imports **their own
authored data**. U00 locked the design doc + ADR 0148. U01 created the
`IUserPortabilityService` seam + the shell + the manifest marker. U02 created
the resident-scope filter + the per-kind business keys. U03 renders **D3** as
code: `UserPortabilityService.ExportAsync` — produce the **same** `*.kumunita`
archive shape as M11 but with the `docs/{Type}.json` arrays **filtered to the
resident's authored/owned rows** (U02's filter) + the resident's media + the
minimal no-secret identity reference set, the `manifest.json` carrying the D2
resident-scope marker. Reuses the M11 `KumunitaArchive` writer + the M11
no-secret `PortabilityPrincipal` shape verbatim. One `AccessAudit` row
(`TargetKind "portability"`, `Via = Owner`, verb `export`).

Owner` verb `export`) + author the **export pins** in
`tests/Kumunita.Core.Tests/UserPortabilityExportTests.cs` (the self-scoped pin,
the no-secret pin, the D2 marker present, the plain-M11-archive still
