## Goal

Create the `Kumunita.Core.Inventory` bounded context: the **two documents**
(`InventoryItem`, `InventoryCheckout`), the **`M16DocTypes`** surface (with the
**open-checkout unique partial index** — the F1 witness), and the
**`InventoryItemToAuditableResource`** adapter — all registered in `Program.cs`.

**The locked decisions you implement (from the design doc — read §2 + §9.2 verbatim):**
- **D1** — two documents, one new surface (`M16DocTypes`), additive, idempotent, zero
  migrations (the M9/M5 `*DocTypes` precedent).
- **D2** — access via the **frozen** `IAuthorizationService` + an **adapter**
  (`TargetKind = "inventory"`); the adapter is the **exact** M5
  `ProjectToAuditableResource` 6-member projection (`Id`/`Name`/`OwnerId`/`Audience`/
  `ComponentId`/`TargetKind`).
- **D3** — `OwnerKind` is a **string** label (`shared`/`community`/`private`), never an
  access gate.
- **D4** — the checkout record is **append-only**; at most **one open checkout per
  item**, enforced by a **unique partial index** on `(ItemId)` where `CheckedInAt IS
  NULL` (the M9 `convo_uidx_pair` shape).
- **C-M16·1** — M16 adds an *adapter*, not a *branch*.

## Deliverables (6 files)

1. `src/Kumunita.Core/Inventory/InventoryItem.cs` — the item document: `Id` (string,
   surrogate), `Name` (non-empty — the card label + the adapter `Name`), `OwnerKind`
   (string: `shared`/`community`/`private`, the M5 `KanbanStatuses` shape — D3),
   `Description` (optional Markdown), `ComponentId` (a feed filter, never a gate —
   C-M3·2), `AuthorId` (the standing owner — D5), `Audience` (the exact `Post`
   `Audience`, `null` = public — D2/D3), `CurrentHolderId` (nullable — who it's
   currently with; `null` = in the pool — D4), `IsDeleted` (the ADR 0024 soft-delete
   flag), `LanguageCode` (the ADR 0018 authored-in tag), `Created`, `Modified`.
2. `src/Kumunita.Core/Inventory/InventoryCheckout.cs` — the append-only usage record:
   `Id`, `ItemId`, `BorrowerId`, `CheckedOutAt`, `CheckedInAt` (nullable — open when
   null), `Note` (optional). **No** `Modified` (append-only — D4).
3. `src/Kumunita.Core/M16DocTypes.cs` — the surface (D1): `opts.Schema.For<InventoryItem>()`
   (the `(ComponentId, Created)` + `(OwnerKind, Created)` feed/filter indexes) +
   `opts.Schema.For<InventoryCheckout>()` (the `(ItemId, CheckedOutAt)`
   thread-ordering index + the **unique partial index** on `(ItemId)` where
   `CheckedInAt IS NULL` — the F1 idempotency witness, D4).
4. `src/Kumunita.Core/Inventory/InventoryItemToAuditableResource.cs` — the adapter (D2,
   the **exact** `ProjectToAuditableResource` 6-member projection): `Id = Item.Id`,
   `Name = Item.Name`, `OwnerId = Item.AuthorId`, `Audience = Item.Audience` (projected
   verbatim, never mutated), `ComponentId = Item.ComponentId`, `TargetKind = "inventory"`.
   `sealed`.
5. `src/Kumunita.Web/Program.cs` — `M16DocTypes.Configure(opts);` added to the
   `*DocTypes.Configure(opts)` block (after `M9DocTypes.Configure(opts)`).
6. A pinned Core test (in `tests/Kumunita.Core.Tests/`) — the `M16DocTypes` surface
   registers both documents + the unique partial index exists (the M9/M5
   doc-registration test shape).
