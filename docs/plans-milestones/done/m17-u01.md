## Goal

Create the `Kumunita.Core.Bookmarks` bounded context: the **one document**
(`Bookmark`), the **`M17DocTypes`** surface (with the **unique index** on
`(OwnerId, TargetKind, TargetId)` — the F1/D4 witness + the `(OwnerId,
Created)` list-ordering index), and wire `M17DocTypes.Configure(opts)` into
the boot path(s). **No service, no Web surface, no adapter** (M17 adds no
adapter at all — D2).

**The locked decisions you implement (from the design doc — read §2.1 +
§2.2 verbatim):**
- **D1** — one document, one new surface (`M17DocTypes`), additive,
  idempotent, zero migrations (the M9/M5 `*DocTypes` precedent).
- **D2** — a bookmark is a **personal-by-id** record; **no**
  `BookmarkToAuditableResource`, **no** new `AccessAction`/`AccessVia`.
- **D4** — one row per (owner, target); the **unique** index on
  `(OwnerId, TargetKind, TargetId)` is the idempotency witness; **no**
  `IsDeleted`, **no** `Modified` on the document.
