# M15 · U04 — Web: the export download + import upload routes + the two views + the `kw-l` keys

> **You are the U04 agent.** Read **this file + your entry reads** and you
> can execute. The design doc is
> `docs/design/m15-translation-bulk-design.md` (primary tier — the only
> authority after U00); the handoff note is

## Goal

D2 + D3 + D4 + D8 rendered in the UI (the **file** half):

- **`GET /admin/languages/{code}/translations/bundle.csv`** — the
  download: `GetBulkTranslationMatrixAsync` + `TranslationBulkExporter`
  compose in the controller (the Web never parses or serializes the
  bundle itself — the Core owns the format), served with the M12 serve
  idiom (`text/csv; charset=utf-8` + `Content-Disposition: attachment` +
  `Cache-Control: no-store`) + the one `translation.export` audit row
  through the additive `RecordTranslationExportAsync` seam (the M13
  analytics-CSV precedent, D4).
- **`POST /admin/languages/{code}/translations/import`** — the upload:
  `IFormFile` → `TranslationBulkImporter` → on a parse success,
  `UpsertManyTranslationsAsync`; on a **refusal**, `StatusCode(422)` +
  `TempData["error"]` naming the first offending row, **no** audit row
  (C-M15·3).
- **Two view affordances** on the existing surfaces: the per-language
  "Download (CSV)" link on the `Index` rows + the upload form on the
  `Translations` view (additive markup — the per-row editor is
  **byte-identical**, C-M15·7; the batch-mode toggle is **U05's**).
- **Three `kw-l` keys × en/de/fr/da** (D8, this unit's share):
  `translations.bulk.export`, `translations.bulk.import`,
  `translations.bulk.import_hint`.
- Both routes join the **existing** `[Authorize(Roles =
  "GlobalAdmin,Translator")]` class gate (D3 — no new gate).
- **3 pinned tests** (names verbatim from the design doc).
