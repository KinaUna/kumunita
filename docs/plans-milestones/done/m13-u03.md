## Goal

D1 rendered as the thin host adapter:

- **`UsageCaptureMiddleware`** (`src/Kumunita.Web/Middleware/`) — the
  `RequestDelegate` middleware. `InvokeAsync`:
  1. Project `HttpContext` → `UsageCaptureInput`:
     - `HasEndpoint` = `httpContext.GetEndpoint() != null`
     - `IsStaticFile` = the endpoint's metadata contains a
       `StaticFileEndpointMetadata`
     - `RouteTemplate` = the HTTP method + the endpoint's
       `RoutePattern.RawText` (e.g. `GET /posts/{id}`)
     - `ActorId` = `httpContext.User?.Identity?.IsAuthenticated == true ?
       httpContext.User.FindFirst(Kumunita.Core.Identity.ClaimTypes.Subject)?
       .Value ?? "" : ""`
  2. Call `UsageCapturePolicy.Decide(input)`.
  3. On `Record`, write one `UsageEvent` via
     `IDocumentStore.LightweightSession()` in a `try/catch` that
     **logs the exception via `ILogger` and re-throws nothing** (C-M13·5).
- **`Program.cs` wiring** — `app.UseMiddleware<UsageCaptureMiddleware>();`
  one line, **after** `app.UseMiddleware<PrivilegedStampMiddleware>()` +
  **before** `app.UseAuthorization()` (after authentication so `User` is
  populated; after `UseRouting()` so `GetEndpoint()` is resolved; before
  `UseAuthorization()` so denied requests are not captured).
- **3 pinned Web tests** (NSubstitute + minimal `WebApplication` host):
  - `UsageCaptureMiddleware_Records_One_Usegevent_Per_Recognized_Request`
  - `UsageCaptureMiddleware_Skips_True_404`
  - `UsageCaptureMiddleware_Skips_When_Store_Throws`
