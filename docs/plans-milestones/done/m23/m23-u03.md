## Goal

Deliver the **"find people with something in common"** read (D4/D6) as **one
new composition service** over **profiles the viewer may already see**: two
**paged** reads — **by profile-tag** and **bio-substring** — each filtering the
candidate set by the match, **gating each survivor by its `Profile.Visibility`**
(via the **existing** `ProfileToAuditableResource`), returning the survivors +
`HasMore`, and emitting **one aggregate `AccessAudit` row** (`targetKind
"directory"`, `VisibleCount`/`HiddenCount` set, `TargetId = null`). A blank
query / a missing tag returns an **empty** page with **no** row (the M8 "no
decision, no row" shape). **Zero new authorization surface** (C-M23·2/D7 —
`IProfileFindService` is a *caller* of the frozen seams, not an extension of
them).

### 1. `src/Kumunita.Core/UserInfo/IProfileFindService.cs`

The interface + the two page DTOs (the design doc §2.4 shape; the `Tag`
reference is the frozen ADR 0044 doc — `using Kumunita.Core.Tags;`):

```csharp
using Kumunita.Core.Tags;

namespace Kumunita.Core.UserInfo;

/// <summary>
/// M23 (ADR 0123 D4) — the "find people with something in common" read: the
/// by-profile-tag + bio-substring finds over the **actor-visible** resident
/// set (D6, the ADR 0044 D5 privacy-pin carried to profiles). A **composition
/// service** in the <c>UserInfo</c> bounded context (the
/// <see cref="DirectoryService"/> shape, ADR 0006-D) — it composes **only**
/// the frozen seams (<see cref="IUserInfoService"/> for the candidate set,
/// <see cref="Authorization.IAuthorizationService"/>.CanSeeAsync for the
/// per-profile <c>Visibility</c> decision via the existing
/// <see cref="ProfileToAuditableResource"/>, the frozen ADR 0044
/// <c>ITagService</c> for the tag resolve) — **zero new authorization surface**
/// (C-M23·2, D7). A match is a **feed organizer, never a gate** (D6); a
/// profile the viewer cannot see never surfaces and its bio/tag never leaks.
/// One aggregate <c>AccessAudit</c> row per read (C-M23·4 — emitted by the
/// frozen <c>CanSeeAsync</c> itself, the M3 <c>ListFeedAsync</c> lane); a blank
/// query / a missing tag returns an empty page with **no** row (the M3
/// 0-candidate / M8 "no decision, no row" shape).
/// </summary>
public interface IProfileFindService
{
    /// <summary>
    /// The by-profile-tag find: the actor-visible profiles whose
    /// <c>TagIds</c> contain the tag resolved from <paramref name="slug"/>
    /// (the C-TG·4 business-key lookup), paged (the ADR 0090 D6
    /// <c>HasMore</c> idiom, <c>PageSize = 30</c>). The gate is the frozen
    /// <c>CanSeeAsync</c> (one aggregate audit row, the M3 lane); a
    /// blank/missing slug returns an empty page with no row.
    /// </summary>
    Task<ProfileTagPage> FindPeopleByTagAsync(string slug, string actorId, int page);

    /// <summary>
    /// The bio-substring find: the actor-visible profiles whose <c>Bio</c>
    /// contains <paramref name="q"/> (case-insensitive substring, the M8 D4
    /// engine), paged (the ADR 0090 D6 <c>HasMore</c> idiom, <c>PageSize = 30</c>).
    /// The gate is the frozen <c>CanSeeAsync</c>; a blank query returns an
    /// empty page with no row (the M3 0-candidate / M8 "no decision, no row"
    /// shape).
    /// </summary>
    Task<ProfileBioPage> FindPeopleByBioAsync(string q, string actorId, int page);
}

/// <summary>
/// M23 (ADR 0123 D4) — a paged by-tag find-people page: the already-
/// <c>Visibility</c>-gated <see cref="Profile"/> survivors, the resolved
/// <see cref="Tag"/> (for the display-name resolution; null on a miss), and
/// the ADR 0090 D6 <c>HasMore</c> flag.
/// </summary>
public sealed record ProfileTagPage(
    IReadOnlyList<Profile> Profiles,
    Tag? Tag,
    bool HasMore);

/// <summary>
/// M23 (ADR 0123 D4) — a paged bio-substring find-people page: the already-
/// <c>Visibility</c>-gated <see cref="Profile"/> survivors and the ADR 0090
/// D6 <c>HasMore</c> flag.
/// </summary>
public sealed record ProfileBioPage(
    IReadOnlyList<Profile> Profiles,
    bool HasMore);
```

### 2. `src/Kumunita.Core/UserInfo/ProfileFindService.cs`

The implementation. **Mirror the M3 `PostService.ListFeedAsync` shape exactly**
(read it first — `src/Kumunita.Core/Posts/PostService.cs` lines ~87–133): the
candidate filter (a feed organizer, never a gate), **one `CanSeeAsync` over
`ProfileToAuditableResource` adapters** (the frozen bulk decision — it emits
the one aggregate audit row **itself**, the M3 C-M3·3 lane, and resolves the
owner branch internally), and returning only the source docs whose id the
`VisibleSet` surfaced. **Do not loop `CanAsync` per profile, and do not
hand-write an aggregate row** — `CanSeeAsync` writes both (the §drift-guard
"one aggregate row" pin is met by the frozen method, not by a second row).

```csharp
using Kumunita.Core.Authorization;
using Kumunita.Core.Tags;

namespace Kumunita.Core.UserInfo;

/// <summary>
/// M23 (ADR 0123 D4/D6) — the by-tag + bio-substring find-people read. A
/// <see cref="DirectoryService"/>-shaped composition service that mirrors the
/// M3 <c>PostService.ListFeedAsync</c> lane: it composes only the frozen seams
/// (<see cref="IUserInfoService"/> for the candidate set,
/// <see cref="IAuthorizationService"/>.CanSeeAsync for the per-profile
/// <c>Visibility</c> decision via the existing
/// <see cref="ProfileToAuditableResource"/>, the host-registered
/// <c>IDocumentStore</c> for the tag resolve) — **zero new authorization
/// surface** (C-M23·2, D7). A match is a feed organizer, never a gate (D6): a
/// profile the viewer cannot see never surfaces and its bio / tag never leaks.
/// The gate + its one aggregate audit row are the frozen <c>CanSeeAsync</c>
/// (the M3 C-M3·3 lane — one call, one aggregate row, the owner branch resolved
/// internally); a blank query / a missing tag returns an empty page with no
/// decision and no row (the M3 0-candidate shape).
/// </summary>
public sealed class ProfileFindService : IProfileFindService
{
    // ADR 0090 D6 — the paged-feed page size (the PostService / TagService
    // `PageSize = 30` precedent).
    private const int PageSize = 30;

    private readonly IUserInfoService _userInfo;
    private readonly IAuthorizationService _authz;
    private readonly Marten.IDocumentStore _store;

    public ProfileFindService(
        IUserInfoService userInfo,
        IAuthorizationService authz,
        Marten.IDocumentStore store)
    {
        _userInfo = userInfo;
        _authz = authz;
        _store = store;
    }

    public async Task<ProfileTagPage> FindPeopleByTagAsync(string slug, string actorId, int page)
    {
        // Blank slug ⇒ empty page, no decision, no row (the M3 0-candidate shape).
        if (string.IsNullOrWhiteSpace(slug))
            return new ProfileTagPage(Array.Empty<Profile>(), null, false);

        // Resolve the tag by its C-TG·4 business key (lowercase + trimmed — the
        // TagService.DeriveSlug idiom).
        var derivedSlug = slug.Trim().ToLowerInvariant();
        await using var session = _store.QuerySession();
        var tag = await session.Query<Tag>()
            .Where(t => t.Slug == derivedSlug)
            .FirstOrDefaultAsync();
        if (tag is null)
            return new ProfileTagPage(Array.Empty<Profile>(), null, false);   // missing tag ⇒ empty, no row

        // Candidate set (the GetProfilesAsync shape, non-blocked) filtered by
        // the tag (C-M23·6) — the match is a feed organizer (D6), never a gate.
        var candidates = (await _userInfo.GetProfilesAsync(false))
            .Where(p => p.TagIds.Contains(tag.Id)).ToList();
        if (candidates.Count == 0)
            return new ProfileTagPage(Array.Empty<Profile>(), tag, false);   // 0 candidates ⇒ empty, no row

        // The gate (D6/C-M23·4): one frozen CanSeeAsync pass — it writes the one
        // aggregate audit row itself (the M3 ListFeedAsync shape) and resolves the
        // owner branch internally (the author always sees their own).
        var visible = await GateAsync(candidates, actorId);
        if (visible.Count == 0)
            return new ProfileTagPage(Array.Empty<Profile>(), tag, false);

        var pageSlice = Paged(visible, page);
        return new ProfileTagPage(pageSlice, tag, candidates.Count == PageSize);
    }

    public async Task<ProfileBioPage> FindPeopleByBioAsync(string q, string actorId, int page)
    {
        if (string.IsNullOrWhiteSpace(q))
            return new ProfileBioPage(Array.Empty<Profile>(), false);   // blank query ⇒ empty, no row

        var needle = q.Trim();
        var candidates = (await _userInfo.GetProfilesAsync(false))
            .Where(p => p.Bio is not null && p.Bio.Contains(needle, StringComparison.OrdinalIgnoreCase))
            .ToList();

        var visible = await GateAsync(candidates, actorId);
        if (visible.Count == 0)
            return new ProfileBioPage(Array.Empty<Profile>(), false);   // 0 visible ⇒ empty, no row (the M3 0-candidate shape)

        var pageSlice = Paged(visible, page);
        return new ProfileBioPage(pageSlice, candidates.Count == PageSize);
    }

    // ── The gate (D6/C-M23·4): one frozen CanSeeAsync pass over the whole
    //    candidate set (C6, the M3 ListFeedAsync shape) — it emits the one
    //    aggregate AccessAudit row itself (the M3 C-M3·3 lane) and resolves the
    //    owner branch internally (the author always sees their own). Returns the
    //    source docs whose id the VisibleSet surfaced (F1/F2 — never a hidden
    //    profile's fields).
    private async Task<List<Profile>> GateAsync(List<Profile> candidates, string actorId)
    {
        var visibleSet = await _authz.CanSeeAsync(
                actorId, AccessAction.Read,
                candidates.Select(p => new ProfileToAuditableResource(p)))
            .ConfigureAwait(false);
        var visibleIds = new HashSet<string>(visibleSet.Visible.Select(v => v.Id));
        return candidates.Where(p => visibleIds.Contains(p.Id)).ToList();
    }

    private static List<Profile> Paged(List<Profile> ordered, int page)
    {
        var zeroBased = Math.Max(0, page - 1);
        return ordered.Skip(zeroBased * PageSize).Take(PageSize).ToList();
    }
}
```

> **Match the real codebase exactly where it differs:** `CanSeeAsync` returns
> a `VisibleSet(IReadOnlyList<(string Id, AccessVia Via)> Visible, int
> HiddenCount)` (confirmed in `Decision.cs`) — mirror the M3
> `visibleSet.Visible.Select(v => v.Id)` projection verbatim. `CanSeeAsync`
> **commits its own aggregate audit row** (standalone form, the M3
> `ListFeedAsync` "plain read, no in-flight caller transaction" lane) — so
> **there is no hand-written aggregate row** in this service (the §drift-guard
> "one aggregate row" pin is met by the frozen method, not by a second row).
> The `HasMore` flag is `candidates.Count == PageSize` (the M3 `ListFeedAsync`
> idiom — pre-gate candidate count). The `Tag` lookup + `DeriveSlug` shape
> mirror `TagService` (confirmed). `AccessAction.Read` — confirm the enum
> name in `AccessAction.cs` (it is `Read` in `Decision.cs`'s usage).

  a tag: one whose `Visibility` includes the viewer, one whose `Visibility`

  whose `Bio` contains the query: one `Visibility`-visible, one
  `Visibility`-denied. `FindPeopleByBioAsync(q, viewer, 1)` returns only the

  `TargetId = null`. (C-M23·4.)
- **Blank query / missing tag ⇒ empty page, no row (GATE-2).**
  `FindPeopleByBioAsync("   ", actor, 1)` and

  page and emit **no** `AccessAudit` row (the M8 "no decision, no row" shape).
- **The owner sees their own (F3).** A profile the actor owns (a
  `Visibility` that excludes others) still surfaces in the actor's own

## What this unit must NOT do (the §drift-guard)

- **Must not** create a new bounded context, a new `*DocTypes` surface, or a
  new document for the find-people read — D4 / C-M23·2 forbids it (the read is
  a **composition service** over the existing `Profile` doc + the frozen
  `Tag` doc).
- **Must not** add a new `AccessAction` / `Decide()` branch / `AccessVia` value
  beyond the TG lane's `Owner` / `IAuthorizationService` method / `TargetKind`
  — C-M23·2 / D7 forbids it (`IProfileFindService` is a **caller** of the
  frozen seams via the **existing** `ProfileToAuditableResource`, not an
  extension of them).
- **Must not** surface a profile the viewer cannot see, or leak a denied
  profile's bio/tag — D6 / C-M23·4 forbids it (the match is a feed organizer,
  never a gate; the `Visibility` decision is the gate).
- **Must not** emit **no** aggregate audit row on a non-empty read, or emit a
  **second** row the `DirectoryService` doesn't write — C-M23·4 / the
  `DirectoryService` audit-emission posture (match the real
  `DirectoryService`; do not double-write).
- **Must not** do full-text / semantic bio search — the bio read is a
  **case-insensitive substring** (the M8 D4 engine, D4); a richer search is a
  deferred lane (D8·2).
- **Must not** create a people-discovery *surface* (facet browse, a
  `/people/skills/{tag}` taxonomy, shared-interests) — D8·3 forbids it in M23;
  the *find-people read* is M23, the *surface* is future.
- **Must not** touch `Profile`/`ProfileUpdate` (U01), `UpsertProfileAsync`
  (U02), or the Web project (U04/U05).
