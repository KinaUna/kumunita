## Goal

folder) —

- **`UsageEvent`** POCO — `sealed class` + `string.Empty` default house
  style. Fields: `Id` (string), `At` (DateTimeOffset), `ActorId` (string,
  empty when anonymous), `RouteTemplate` (string). **No** status code, no
  email, no body, no UA, no IP (C-M13·2).
- **`UsageDocTypes`** — the `*DocTypes.Configure(StoreOptions)`
  registration surface (the `M3DocTypes` shape verbatim — one
  `opts.Schema.For<UsageEvent>();` call).
- **`UsageCapturePolicy`** static class — pure `Decide(UsageCaptureInput)
  → UsageCaptureDecision`. `UsageCaptureInput { HasEndpoint (bool),
  IsStaticFile (bool), RouteTemplate (string?), ActorId (string) }`.
  `UsageCaptureDecision { Record (bool), RouteTemplate (string),
  ActorId (string) }`. Skip rules: `!HasEndpoint` ⇒ Skip; `IsStaticFile`
  ⇒ Skip; otherwise Record.
- **`SurfaceKey`** static class — pure `Map(string routeTemplate) →
  string`. The top-level-segment → surface-key map (the D2 closed list
  from the design doc, verbatim). `"other"` fallback.
- **Boot wiring** — `Program.cs`: one `UsageDocTypes.Configure(opts);`
  line next to the `M3DocTypes` call. `SchemaBootstrap.cs`: one line.
