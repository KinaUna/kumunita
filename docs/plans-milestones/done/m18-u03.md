# M18 · U03 — The author-only skip / undelete seams (`SkipOccurrenceAsync` / `UndeleteOccurrenceAsync`)

**U01 must be done first** (the two additive `Event` fields). U02 is **not** a prerequisite (skip / undelete operate on any concrete row, including non-recurring ones — but the series context is what makes them meaningful; if U02 is done, use its create lane to build a series in the tests, otherwise build a 3-row series directly via the store). This unit is **Core-only**; the exit gate is `dotnet build Kumunita.slnx -c Debug` + `dotnet exec tests\Kumunita.Core.Tests\bin\Debug\net10.0\Kumunita.Core.Tests.dll`, both green.

## Goal

Add the two **author-only** seams `IEventService.SkipOccurrenceAsync` / `UndeleteOccurrenceAsync` + their `EventService` bodies, and land GATE-3. Skip is a **soft-delete of one row** (`IsDeleted = true`) — never a hard-delete, never a cascade, never a touch of the head's rule (C-M18·8). Undelete is its inverse (`IsDeleted = false`). Both ride the **frozen** `EventToAuditableResource` + `IAuthorizationService.Decide()` seams with the existing author-∪-GlobalAdmin standing (C-M18·4 / C-M18·5 — **no** new `AccessAction`).

Locked decisions: **D5** (the seams + standing), **C-M18·4** (author ∪ GlobalAdmin only, non-author gets 404), **C-M18·5** (zero new authz surface), **C-M18·8** (soft-delete, reversible, one row).

## Deliverables (3 files)

1. **`src/Kumunita.Core/Events/IEventService.cs`** (edit) — add the two seams (place them near the other author-only write lanes; the doc-comments below are the contract):

   ```csharp
   /// <summary>
   /// M18 (ADR 0119, D5 / C-M18·8) — soft-delete **one** occurrence: set
   /// <c>IsDeleted = true</c> on the named row only. Never a hard-delete, never a
   /// cascade, never a touch of the head's <c>RecurrenceRule</c> or any sibling
   /// (C-M18·8). Author ∪ GlobalAdmin only (C-M18·4); a non-author, non-
   /// GlobalAdmin actor gets a 404 (the frozen seam's "absent" shape — no leak,
   /// no 403). Rides the frozen <c>EventToAuditableResource</c> +
   /// <c>IAuthorizationService.Decide()</c> seams — **no** new
   /// <c>AccessAction</c> / <c>AccessVia</c> / adapter (C-M18·5).
   /// </summary>
   Task SkipOccurrenceAsync(string eventId, string actorId, CancellationToken ct = default);

   /// <summary>
   /// M18 (ADR 0119, D5 / C-M18·8) — the inverse of <see cref="SkipOccurrenceAsync"/>:
   /// set <c>IsDeleted = false</c> on the named row only. Same standing, same
   /// frozen-seam shape, same one-row scope. A skip is always reversible by the
   /// author.
   /// </summary>
   Task UndeleteOccurrenceAsync(string eventId, string actorId, CancellationToken ct = default);
   ```

2. **`src/Kumunita.Core/Events/EventService.cs`** (edit) — implement both bodies. Each follows the **existing** author-only write-lane shape in this file (read one — the ADR 0014 / 0016 / 0017 edit lane — and copy its standing-guard structure exactly):
   - Load the row by `eventId`; if absent → **404** (the frozen seam's "absent" shape — this is also the non-author path's outcome, since the standing guard below denies before the write but the 404 is the observable shape).
   - Map the row via the **existing** `EventToAuditableResource` and call the **frozen** `IAuthorizationService.Decide()` with the existing author-∪-GlobalAdmin standing (the same `AccessAction` the ADR 0014 / 0016 / 0017 edit lane uses — **do not** introduce a new one, C-M18·5). On deny → **404** (not 403).
   - On allow: set `row.IsDeleted = true` (skip) / `row.IsDeleted = false` (undelete); **do not** touch `RecurrenceRule`, `RecurrenceHeadId`, `Start`, `End`, or any sibling; save in the existing session shape.
   - **No** `AccessAudit` row (this is a write side-effect, not an access decision — the same posture as the reminder job; the existing edit lanes' audit posture is the precedent — match it, do not add a new audit row).

3. **`tests/Kumunita.Core.Tests/EventServiceSkipUndeleteTests.cs`** (new file) — the GATE-3 pinned tests:
   - `Skip_Occurrence_Sets_IsDeleted_On_That_Row_Only` — build a 3-row weekly series (via U02's create lane if done, else directly via the store: one head `RecurrenceRule` set, two siblings `RecurrenceHeadId == head.Id`). Call `SkipOccurrenceAsync(middleRow.Id, authorId, ct)`. Assert: `middleRow.IsDeleted == true`, `head.IsDeleted == false`, `thirdRow.IsDeleted == false`, `head.RecurrenceRule` non-null (untouched). Then call `UndeleteOccurrenceAsync(middleRow.Id, authorId, ct)` and assert `middleRow.IsDeleted == false` (reversible, C-M18·8).
   - `Skip_By_NonAuthor_Returns_404` — build a 2-row series owned by author A; call `SkipOccurrenceAsync(sibling.Id, actorId: "user-B", ct)` where user-B is a signed-in non-author, non-GlobalAdmin. Assert the seam throws / returns the 404 shape (match the existing edit lane's 404 observable in this codebase — a `NotFoundException` / 404 result, **not** a 403), and `sibling.IsDeleted == false` (no write occurred).
