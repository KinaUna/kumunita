views (`list.cshtml` / `detail.cshtml` / `create.cshtml`), and the **`inv.*` `kw-l`
keys** registered in `KnownTranslationKeys` (× en/de/fr/da — the U00 §kw-l key list is

sections verbatim):**

  `IAuthorizationService` (the controller composes `IInventoryService`, which does the
  `CanSeeAsync(Read)` / `CanAsync(Read)`); the detail's 404-vs-403 split (C-M3·4).
- **D5 / C-M16·5** — the Web `[Authorize]` attribute is a **convenience pre-gate
  only**, never the source of truth (the standing probe is server-side — U03).
- **D6 / C-M16·6** — M16 is a **standing core surface** (no toggle); the views are
  always available to the community.
- **§kw-l** — the `inv.*` keys (the U00 list) are registered in `KnownTranslationKeys`
  × en/de/fr/da; the parity tests pin them.
