# M18 · U02 — Create-time series expansion (the `CreateAsync` lane materializes the series)

**U01 must be done first** (the `Recurrence` / `EventRecurrenceRule` types + the two additive `Event` fields + the pure `EventRecurrenceExpander`). This unit is **Core-only**; the exit gate is `dotnet build Kumunita.slnx -c Debug` + `dotnet exec tests\Kumunita.Core.Tests\bin\Debug\net10.0\Kumunita.Core.Tests.dll`, both green.

## Goal

Extend the **create** write-lane so that a `CreateAsync` call carrying a recurrence rule materializes the full series (head + siblings) in one transaction, and land GATE-2. A `CreateAsync` call with **no** rule (the existing behavior for every event created so far) is **byte-for-byte unchanged** — this is the zero-change branch GATE-2's second test pins.

Locked decisions this unit implements: **D1** (materialized occurrences — the create lane is where they come into being), **D3** (the head is occurrence #1, carrying the rule; siblings carry `RecurrenceHeadId`), **C-M18·1** (reads see concrete rows — create produces them), **C-M18·2** (the expansion is the pure U01 expander — this unit only *calls* it and *persists* the rows, it does not re-implement stepping).

Store **all** rows (head + siblings) in the **same session / transaction** as the head (the existing create path's session shape — one `session.SaveChangesAsync` / commit, not N).
   - **Standing is unchanged** — `CreateAsync` is the author's own lane; no `IAuthorizationService` change (C-M18·5).
