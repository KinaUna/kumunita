# M22 · U01 — the additive `Profile.OnboardingCompletedAt` field + the two owner-scope seams on `IUserInfoService`

**You are the U01 agent.** This is a **Core** unit. It adds M22's **only new
Core surface**: one **additive field** on the existing `Kumunita.Core.UserInfo.Profile`
doc (`OnboardingCompletedAt: DateTimeOffset?`, ADR 0004 §B.1 — the M23 `Bio`/
`TagIds` additive precedent) and **two owner-scope seams** on
`IUserInfoService` (`CompleteOnboardingAsync` write + `GetOnboardingCompletedAsync`
read), the `SetProfileTimezoneAsync` shape verbatim (owner-scope, one
`SaveChangesAsync`, **no `AccessAudit` row**, **never load-or-creates** →
`KeyNotFoundException`). It does **not** add a new bounded context, a new
`*DocTypes` surface, a new `Program.cs` boot line, an adapter, a controller, or
any views. **Exit: `dotnet build` clean + `Kumunita.Core.Tests` green.**

**Read the design doc + ADR first** — they lock the C# in this unit (D1/D2,
C-M22·1/C-M22·2/C-M22·3). The codebase wins for *mechanics* (the exact
`SetProfileTimezoneAsync` body, the `Profile` field placement); the design doc
wins for the *locked surface* (the `OnboardingCompletedAt` member, the two seam
signatures, the "no audit row / no load-or-create / writes only
`OnboardingCompletedAt`" pins).

## Goal

Make the onboarding completion state visible on the `Profile` doc and
writable/readable through two owner-scope seams, with **zero new
authorization surface** (C-M22·2 — no new `AccessAction`/`Decide()`/`AccessVia`/
`IAuthorizationService` method; the write emits **no** `AccessAudit` row,
C-M22·3) and **zero new Marten surface** (C-M22·1 — the field is additive on
an *existing* doc; no new `*DocTypes`, no new boot line).

```csharp
    /// <summary>
    /// M22 (ADR 0132, D1) — the onboarding completion stamp. <c>null</c> =

    /// </summary>
    public DateTimeOffset? OnboardingCompletedAt { get; set; }
```

### 2. `src/Kumunita.Core/UserInfo/IUserInfoService.cs` — two owner-scope seams

Add exactly **two** members to `IUserInfoService`, immediately after
`SetProfileEmailLanguageAsync` (the ADR 0006-E compatible-addition idiom, the
`SetProfileTimezoneAsync` shape verbatim):

```csharp
    // ── Onboarding addition (ADR 0132; the *single* completion-stamp write
    // lane + its owner-scope read — the ADR 0006-E compatible-addition idiom
    // this file uses, the exact shape of SetProfileTimezoneAsync) ──────────

    /// <summary>
    /// M22 (ADR 0132, D2) — stamp the onboarding-completed state. Owner-scope
    /// single write lane (the <see cref="SetProfileTimezoneAsync"/> shape
    /// verbatim): stamps <see cref="Profile.OnboardingCompletedAt"/> = now, one
    /// <c>SaveChangesAsync</c>, **no <see cref="Authorization.AccessAudit"/>
    /// row** (a profile-field write — the <see cref="UpsertProfileAsync"/>
    /// shape, "not an access decision"). Strong consistency (invariant C4): the
    /// stamp is live on the very next <see cref="GetProfileAsync"/> call. The
    /// self-scope check happens at the Web boundary (the owner is the actor);
    /// this lane writes <c>Profile.OnboardingCompletedAt</c> only.
    /// </summary>
    /// <exception cref="System.Collections.Generic.KeyNotFoundException">
    /// No profile with that <c>subjectId</c> exists (fail closed — the lane
    /// never load-or-creates, the <see cref="SetProfileTimezoneAsync"/> pin).</exception>
    Task CompleteOnboardingAsync(string subjectId, string actorBy);

    /// <summary>
    /// M22 (ADR 0132, D2) — owner-scope read of the completion stamp
    /// (<see cref="Profile.OnboardingCompletedAt"/>; <c>null</c> = not
    /// completed, the floor). The <see cref="GetProfileAsync"/> read re-
    /// projected: owner-scope, **no audit row**, **never load-or-creates**
    /// (returns <c>null</c> when no <see cref="Profile"/> exists — the read is
    /// the floor, not a write). Mirrors <see cref="GetProfileAsync"/>.
    /// </summary>
    Task<DateTimeOffset?> GetOnboardingCompletedAsync(string subjectId);
```

> **Match the frozen group exactly** — the two new members sit right after
> `SetProfileEmailLanguageAsync` (or `GetProfileAsync` for the read), with the
> same "owner-scope, no audit row, never load-or-creates" doc-comment idiom.
> `actorBy` is recorded for the write (the owner is the actor); the lane does
> **not** re-check roles or emit an `AccessAudit` row (C-M22·3).

### 3. `src/Kumunita.Core/UserInfo/UserInfoService.cs` — the two impls

Add the two implementations immediately after `SetProfileEmailLanguageAsync`
(mirror the `SetProfileTimezoneAsync` body **verbatim** — same session, same
load, same `KeyNotFoundException` fail-closed, same one `SaveChangesAsync`;
only the field + the `now` stamp differ):

```csharp
    /// <inheritdoc />
    public async Task CompleteOnboardingAsync(string subjectId, string actorBy)
    {
        // ADR 0132 (D2) — the onboarding-completion stamp write lane. Mirrors
        // SetProfileTimezoneAsync exactly (the C-MED·8 single write-lane shape):
        // the self-scope check happens at the Web boundary (the owner is the
        // actor); this lane writes Profile.OnboardingCompletedAt only. One
        // session, one SaveChangesAsync (C3); no audit row (a Profile field
        // write — the UpsertProfileAsync shape, "not an access decision").
        // Fail closed on a missing profile (never load-or-create, the
        // SetProfileTimezoneAsync pin). Strong consistency (C4): the stamp is
        // live on the very next GetProfileAsync call.
        await using var session = store.OpenSession(new SessionOptions());

        var profile = await session.LoadAsync<Profile>(subjectId).ConfigureAwait(false);
        if (profile is null)
            throw new KeyNotFoundException($"Profile not found: {subjectId}");

        profile.OnboardingCompletedAt = DateTimeOffset.UtcNow;
        session.Store(profile);
        await session.SaveChangesAsync().ConfigureAwait(false);
    }

    /// <inheritdoc />
    public async Task<DateTimeOffset?> GetOnboardingCompletedAsync(string subjectId)
    {
        // ADR 0132 (D2) — the onboarding-completion read seam. The
        // GetProfileAsync read re-projected (owner-scope, no audit row,
        // never load-or-creates — null is the floor, not a write).
        await using var session = store.OpenSession(new SessionOptions());

        var profile = await session.LoadAsync<Profile>(subjectId).ConfigureAwait(false);
        return profile?.OnboardingCompletedAt;
    }
```

> **`DI`:** no change — `IUserInfoService` is already registered; the two new
> members are on the **existing** sealed `UserInfoService`, so the existing
> `AddScoped<IUserInfoService, UserInfoService>` (or its equivalent in
> `Kumunita.Core/DependencyInjection.cs`) already covers them. **Do not add a
> new DI registration.**
