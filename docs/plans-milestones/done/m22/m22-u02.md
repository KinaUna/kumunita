# M22 · U02 — `OnboardingController` (`GET /onboarding` + `POST /onboarding/finish`) + the `OnboardingViewModel`

**You are the U02 agent.** This is a **Web** unit. It adds the **guided
walk-through surface**: the `OnboardingController` (one `GET /onboarding` that
renders the step sequence + completion state + the finish/skip action, and one
`POST /onboarding/finish` that stamps completion through **U01's**
`CompleteOnboardingAsync` lane) and the `OnboardingViewModel` (the
completion-state read + the per-step "set / not set" hints off the frozen read
seams + the banner-eligibility read). It **rides the frozen lanes** (D3) — it
calls U01's `CompleteOnboardingAsync` and reads through the existing
`IUserInfoService` read seams; it adds **no new field-write lane** and **no new
authorization surface** (C-M22·2/C-M22·4). It does **not** add the views (U03)
or author the `kw-l` keys (U03 authors; U02 *consumes* them). **Exit:
`dotnet build` clean + `Kumunita.Web.Tests` green.**

**Read the design doc + ADR first** — they lock the routes + the
`OnboardingViewModel` shape (D3/D4/D5). The codebase wins for *mechanics*
(the `FlashAsync` idiom, the `KumunitaPrincipal.SubjectId` helper, the
optional-ctor pattern, the `[Authorize]` + `Controller` base); the design doc
wins for the *locked surface* (the `/onboarding` + `/onboarding/finish`
routes, the "only write is `CompleteOnboardingAsync`" pin, the
banner-eligibility read).

## Goal

Ship the stateless `/onboarding` page's **controller + view model**: a `GET`
that composes the owner-scope read (completion state + per-step hints) and a
`POST /onboarding/finish` that stamps completion through U01's lane — with
**zero new field-write lanes** (D3), **zero new authorization surface**
(C-M22·2), and a **non-blocking** shape (D5).

### 1. `src/Kumunita.Web/Controllers/OnboardingController.cs`

The guided walk-through surface (D4/D5), mirroring the `LocaleController`
idioms (the `[Authorize]` + `Controller` base, the optional `ITranslationProvider?`
ctor param, the `FlashAsync` idiom, the `KumunitaPrincipal.SubjectId` read):

```csharp
using Kumunita.Core.Localization;
using Kumunita.Core.UserInfo;
using Kumunita.Web.Security;
using Microsoft.AspNetCore.Authorization;
using Microsoft.AspNetCore.Mvc;

namespace Kumunita.Web.Controllers;

/// <summary>
/// M22 (ADR 0132, D4) — the guided walk-through of a new resident's account
/// setup. Two actions, one controller (the <c>LocaleController</c>
/// settings-tabs shape):
/// <list type="bullet">
/// <item><c>GET /onboarding</c> — the step sequence (the closed
/// <c>onboarding.*</c> keys, D7) + the current completion state + the
/// finish/skip action. The model is the owner-scope read
/// (<see cref="IUserInfoService.GetProfileAsync"/> for
/// <c>OnboardingCompletedAt</c> + the per-step "set / not set" hints).
/// </item>
/// <item><c>POST /onboarding/finish</c> — the <b>one</b> write action: calls
/// U01's <see cref="IUserInfoService.CompleteOnboardingAsync"/> for the
/// signed-in subject and redirects home with the <c>onboarding.flash_done</c>
/// flash (the <c>LocaleController.FlashAsync</c> idiom). An optional
/// <c>POST /onboarding/skip</c> routes to the <b>same</b> lane (U00 may
/// collapse skip→finish in U00).
/// </item>
/// </list>
/// <para>
/// <b>Rides frozen lanes (D3):</b> the walk-through's <b>only</b> write is
/// <c>CompleteOnboardingAsync</c>; every field it surfaces links into the
/// existing editor/settings that owns it (display name/contact →
/// <c>/profile/edit</c>, avatar → <c>/profile</c>, UI language →
/// <c>/settings/language</c>, timezone → <c>/settings/timezone</c>, date
/// format → <c>/settings/dateformat</c>, email language →
/// <c>/settings/language</c>). The walk-through <b>never</b> re-implements a
/// write lane (C-M22·4).
/// </para>
/// <para>
/// <b>Non-blocking (D5):</b> sign-in is never gated; the "is a new user?"
/// check is the owner-scope read of <c>OnboardingCompletedAt</c> (never a
/// claim — the thin-token rule, ADR 0001-B). The <c>[Authorize]</c> here is
/// the standard signed-in gate (the surface is owner-scope, owner = the
/// signed-in actor), <b>not</b> an onboarding gate.
/// </para>
/// </summary>
[Authorize]
public sealed class OnboardingController(
    IUserInfoService userInfo,
    // The per-request translation read seam — the flash string in the resident's
    // language (the LocaleController.FlashAsync idiom). Optional (default null)
    // so test-construction sites that build this controller without the seam keep
    // compiling and render the KnownTranslationKeys.EnValues floor; DI always
    // supplies the live ITranslationProvider in the app.
    ITranslationProvider? translationProvider = null) : Controller
{
    private static string? SubjectId(System.Security.Claims.ClaimsPrincipal user) =>
        KumunitaPrincipal.SubjectId(user);

    /// <summary>
    /// Resolve an <c>onboarding.*</c> kw-l key to the resident's effective
    /// language (the house EffectiveLanguageCode.ResolveAsync +
    /// ITranslationProvider.GetAsync seam — the LocaleController.FlashAsync
    /// idiom). Falls back to the KnownTranslationKeys.EnValues floor (code is
    /// the floor, ADR 0015 D1) when the seam is absent, so a resident never
    /// sees a raw key.
    /// </summary>
    private async Task<string> FlashAsync(string key)
    {
        if (translationProvider is null)
            return KnownTranslationKeys.EnValues.GetValueOrDefault(key) ?? key;
        return await translationProvider.GetAsync(
            key,
            await EffectiveLanguageCode.ResolveAsync(HttpContext?.Request, null, translationProvider));
    }

    // ── GET /onboarding — the step sequence + completion state ────────────

    /// <summary>
    /// <c>GET /onboarding</c> — the guided walk-through. Seeds the model from
    /// the actor's saved <see cref="Kumunita.Core.UserInfo.Profile"/> (the
    /// <c>OnboardingCompletedAt</c> read + the per-step "set / not set" hints
    /// off the frozen read seams). Owner-scope only — the principal is the
    /// signed-in actor, never a form field.
    /// </summary>
    [HttpGet("/onboarding")]
    public async Task<IActionResult> Index()
    {
        var subjectId = SubjectId(User) ?? string.Empty;
        return View(new OnboardingViewModel(
            CompletedAt: await userInfo.GetOnboardingCompletedAsync(subjectId),
            profile: await userInfo.GetProfileAsync(subjectId)));
    }

    // ── POST /onboarding/finish — the ONE write (U01's lane) ──────────────

    /// <summary>
    /// <c>POST /onboarding/finish</c> — stamp completion through U01's
    /// <see cref="IUserInfoService.CompleteOnboardingAsync"/> (the owner-scope,
    /// no-audit-row, never-load-or-creates lane, D2/C-M22·3) and redirect home
    /// with the <c>onboarding.flash_done</c> flash. The walk-through's only
    /// write (D3/C-M22·4).
    /// </summary>
    [HttpPost("/onboarding/finish")]
    public async Task<IActionResult> Finish()
    {
        var subjectId = SubjectId(User) ?? string.Empty;
        try
        {
            await userInfo.CompleteOnboardingAsync(subjectId, subjectId);
        }
        catch (System.Collections.Generic.KeyNotFoundException)
        {
            // No profile to stamp (fail-closed, the SetProfileTimezoneAsync pin) —
            // treat as already-handled; redirect home (the banner is gated on the
            // read, so it will not persist for a profile-less actor).
            return RedirectToAction("Index", "Home");
        }
        TempData[ControllerBase.TempDataSuccessMessageKey] = await FlashAsync("onboarding.flash_done");
        return RedirectToAction("Index", "Home");
    }

    // ── POST /onboarding/skip — routes to the SAME lane (U00 may collapse) ─

    /// <summary>
    /// <c>POST /onboarding/skip</c> — "skip for now": the <b>same</b>
    /// <see cref="IUserInfoService.CompleteOnboardingAsync"/> lane as finish
    /// (D4 — skip→finish, the completion flag does not distinguish finish from
    /// skip). If U00 collapsed skip into finish, remove this action and keep
    /// only <see cref="Finish"/>.
    /// </summary>
    [HttpPost("/onboarding/skip")]
    public async Task<IActionResult> Skip() => await Finish();
}
```

> **Notes / drift-catch:**
> - **`FlashAsync`** mirrors `LocaleController.FlashAsync` /
>   `ProfileController.FlashAsync`. If the codebase resolves the effective
>   language through a different seam (e.g. it takes `ILocalizationService`),
>   **match the real `LocaleController.FlashAsync` body** — the codebase wins
>   for mechanics; the *shape* (resolve an `onboarding.*` key → the resident's
>   language, floor = `KnownTranslationKeys.EnValues`) is locked.
> - **The `TempData` success key**: if the codebase uses a different
>   flash/tempdata convention (e.g. the house `_SiteFlash` or an
>   `IHostedService`-free `TempData` key), **match the real
>   `LocaleController` flash convention** — do not invent a new one. The
>   *shape* (a `onboarding.flash_done` flash on the redirect) is locked.
> - **`RedirectToAction("Index", "Home")`**: match the real home action name
>   (grep `Controller` for the home `Index`) — the *shape* (redirect to home)
>   is locked.
> - **Do NOT** add a field-write lane, a per-step POST, a persisted step
>   cursor, a server-session, an `AccessAudit` write, or a claim read
>   (C-M22·2/3/4/5, D3/D4/D5).

### 2. `src/Kumunita.Web/Models/OnboardingViewModel.cs`

The read-only model the `GET` seeds (D4/D5) — the completion state + the
per-step "set / not set" hints (off the frozen read seams, D3). The view (U03)
renders it; this unit owns the shape.

```csharp
using Kumunita.Core.UserInfo;

namespace Kumunita.Web.Models;

/// <summary>
/// M22 (ADR 0132, D4/D5) — the read-only model for the <c>GET /onboarding</c>
/// guided walk-through. Owner-scope only (the signed-in resident reads their
/// own state). Exposes:
/// <list type="bullet">
/// <item><see cref="CompletedAt"/> — the <c>OnboardingCompletedAt</c> read
/// (<c>null</c> = not completed, the floor: the banner shows).</item>
/// <item><see cref="Completed"/> — the derived bool (<c>CompletedAt != null</c>)
/// for the view's conditional rendering + the banner-eligibility read (D5).</item>
/// <item>The per-step "set / not set" hints (<see cref="HasDisplayName"/> /
/// <see cref="HasAvatar"/> / <see cref="HasTimezoneOverride"/> /
/// <see cref="HasDateFormatOverride"/> / <see cref="HasEmailLanguage"/>) —
/// derived from the frozen read seams (D3), each step linking into its owning
/// surface (the register D3 table).</item>
/// </list>
/// The model holds a <see cref="Profile"/> reference read-only; it never
/// writes (the only write is the controller's <c>CompleteOnboardingAsync</c>,
/// D2/D3).
/// </summary>
public sealed class OnboardingViewModel
{
    public OnboardingViewModel(
        DateTimeOffset? completedAt,
        Profile? profile)
    {
        CompletedAt = completedAt;
        Completed = completedAt is not null;
        HasDisplayName = !string.IsNullOrWhiteSpace(profile?.DisplayName);
        HasAvatar = !string.IsNullOrWhiteSpace(profile?.AvatarId);
        HasTimezoneOverride = !string.IsNullOrWhiteSpace(profile?.TimeZone);
        HasDateFormatOverride = !string.IsNullOrWhiteSpace(profile?.DateFormat);
        HasEmailLanguage = !string.IsNullOrWhiteSpace(profile?.EmailLanguage);
    }

    /// <summary>The <c>OnboardingCompletedAt</c> read; <c>null</c> = not completed.</summary>
    public DateTimeOffset? CompletedAt { get; }

    /// <summary>Derived: <c>true</c> when the resident has finished/skipped.</summary>
    public bool Completed { get; }

    /// <summary>Step hint: a display name is set (links to <c>/profile/edit</c>).</summary>
    public bool HasDisplayName { get; }

    /// <summary>Step hint: an avatar is set (links to <c>/profile</c>).</summary>
    public bool HasAvatar { get; }

    /// <summary>Step hint: a time-zone override is set (links to <c>/settings/timezone</c>).</summary>
    public bool HasTimezoneOverride { get; }

    /// <summary>Step hint: a date-format override is set (links to <c>/settings/dateformat</c>).</summary>
    public bool HasDateFormatOverride { get; }

    /// <summary>Step hint: an email/notification language is set (links to <c>/settings/language</c>).</summary>
    public bool HasEmailLanguage { get; }
}
```

> **Note:** the per-step hints are the "set / not set" affordances (D8·2 defers
> the *recommendation engine* — M22 only shows a derived hint + a link into the
> owning surface). If U00's design doc pins different hint derivations (e.g. a
> "UI language is set" hint off the `LocaleCookie` read), **add that member**
> here to match the locked set — the *shape* (owner-scope derived reads, no
> write) is locked.
