# M18 · U07 — The 14 `kw-l` keys × en/de/fr/da + the closure test

**U05 and U06 must be done first** (they reference the key *names* this unit authors the *string values* for). This unit is **Core-only** (the `kw-l` key registry is `Kumunita.Core`); the exit gate is `dotnet build Kumunita.slnx -c Debug` + `dotnet exec tests\Kumunita.Core.Tests\bin\Debug\net10.0\Kumunita.Core.Tests.dll`, both green.

## Goal

Add the **14** `events.*` keys (the D9 closed set) to **all four** closed dictionaries in `src/Kumunita.Core/Localization/KnownTranslationKeys.cs` — `EnValues` (the `en` floor, the canonical source text), `DeValues`, `FrValues`, `DaValues`. Then author the **first** `kw-l` **closure test**: a pinned test asserting each of the 14 keys is present in all four dictionaries (no English-only key — a key present in `EnValues` but missing from `DeValues` / `FrValues` / `DaValues`), and that no user-visible string leaks a non-localized "RRULE" / "iCal" / "RFC 5545" term. This test doubles as the standing guard that a future M18-era unit cannot add an English-only key.

Locked decisions: **D9** (the 14-key closed set × en/de/fr/da, no new namespace, no English-only key, no leaked term). The keys live **under the existing `events.*` namespace** — the M4 events keys already sit there as `events.created` / `events.edited` (this unit appends alongside them; it does **not** invent a new `event.*` / `recurrence.*` / `series.*` namespace).

## §drift-guard (this unit only)

- **No new `kw-l` namespace.** The 14 keys sit under `events.*`, not `event.*`, `recurrence.*`, `series.*`, or any other invented namespace. The `KnownTranslationKeys.cs` file's existing section-divider comment style is the shape to match (the `// ── events (M4 — ...) ──` header above the existing `events.created` / `events.edited` pair).
- **No English-only key.** Every one of the 14 keys must appear in all four dictionaries. The closure test enforces this; a unit that adds a key to `EnValues` only and skips de/fr/da will fail the test.
- **No leaked term.** No `RRULE`, `iCal`, `RFC 5545`, `EXRULE` substring in any of the 14 keys' values in any of the four dictionaries. The closure test enforces this.
- **Do not touch** the `kw-l` TagHelper, the `kw-l` seed path, or the `en`-floor seeder — the M·9 / ADR 0005 / 0015 shape (the seeder materializes each key's `en` row on first boot; the non-`en` rows are the localized text) is **unchanged**. This unit only adds 14 × 4 = 56 entries to the four closed dictionaries.
- **Do not author the de / fr / da values by machine-translation** in a way that produces a non-idiomatic string (e.g. a German word in a French value). The values are the unit author's call — they should read as if a native speaker wrote them, matching the tone of the surrounding M4 entries.
