## Goal

Create the `Kumunita.Core.PersonalNotes` service seam (the **note CRUD**
part): **`IPersonalNoteService`** (the public surface — the note methods
only; the folder-tree methods are **U03**) + **`PersonalNoteService`**
(the composition service — a concrete class pairing the frozen seams with
the host-registered Marten `IDocumentStore`, the M17 `BookmarkService` /
M3 `PostService` shape), the result types (per design doc §2.2), and the
DI registration in `Kumunita.Core/DependencyInjection.cs`. Then the
**pinned Core tests** for the note methods (the 12 note-related tests of
the §2.5 list; the 6 folder-tree tests are **U03**).

**The locked decisions you implement (from the design doc — read §2.2,
§2.3, §2.4, §2.5 verbatim):**
- **D2** — a personal note is a **personal-by-id** record; the list lane
  makes **no** `CanSeeAsync` pass over the note rows themselves
  (C-M37·2).
- **D3** — the write lane (attach a note to a target) **re-runs the
  target's own frozen `Read` decision** before the note row is created;
  Deny ⇒ `NoteCreateStatus.Refused` (the Web layer maps to **404**, not
  403), **no row survives**.
- **D4** — a note is *content*, not a pointer: the body is **never**
  mutated in place — edit is a **new revision** (the `Modified`
  timestamp is the witness); the body is **visible to the author always**
  (the D7 degraded shape).
- **D5** — tags are author-set, free-form, per-note; the tag set is
  **normalized on write** (lowercase, trimmed, deduped, sorted — the M26
  `Tag` doc's `Name` normalization shape).
- **D7** — the list resolves each note row by `TargetKind` + `TargetId`
  against the owning surface's read seam; a dangling note renders the
  **degraded** label (no title, no link, no id) — **and the body
  remains visible** to the owner.
