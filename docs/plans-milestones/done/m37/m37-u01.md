## Goal

Create the `Kumunita.Core.PersonalNotes` bounded context: the **two
documents** (`PersonalNote` + `NoteFolder`), the **
`PersonalNotesDocTypes`** surface (with the **unique indexes** — the
D3/F1 witness on `(OwnerId, TargetKind, TargetId)` + the D6 witness on
`(OwnerId, ParentId, Name)`), and wire
`PersonalNotesDocTypes.Configure(opts)` into the boot path(s). **No
service, no Web surface, no adapter** (M37 adds no adapter at all — D2).

**The locked decisions you implement (from the design doc — read §2.1 +
§2.2 verbatim):**
- **D1** — two documents, one new surface (`PersonalNotesDocTypes`),
  additive, idempotent, zero migrations (the M17 `BookmarkDocTypes` /
  M9 `MessagingDocTypes` precedent).
- **D2** — a personal note is a **personal-by-id** record; **no**
  `PersonalNoteToAuditableResource`, **no** new `AccessAction`/
  `AccessVia`.
- **D4** — a note is *content*, not a pointer: it carries a **body**
  (the resident's own writing) + `Modified` (the body's revision
  witness); the body is **never** mutated in place.
- **D5** — tags are author-set, free-form, per-note; the tag set is
  normalized on write (lowercase, trimmed, deduped, sorted — the M26
  `Tag` doc's `Name` normalization shape).
- **D6** — the folder tree is a personal tree, bounded in depth (≤ 2),
  unique in name (the `(OwnerId, ParentId, Name)` unique index is the
  witness).

## Deliverables (4 files)

1. `src/Kumunita.Core/PersonalNotes/PersonalNote.cs` — the document (the
   **exact** §2.1 shape): `Id` (string), `OwnerId` (string),
   `TargetKind` (string — the closed set {`post`, `grouppost`, `event`,
   `page`, `project`, `todo`, `board`, `document`, `directory`}; a
   `/// <summary>` noting the closed set + the D1 string-not-enum shape),
   `TargetId` (string), `Body` (string — the resident's own writing,
   stored as raw text, Markdown-rendered on read via the **frozen**
   `MarkdownRenderer` — the M31 / ADR 0031 shape; a `/// <summary>`
   noting the D4 "content, not pointer" pin), `FolderId` (`string?` —
   the owner's folder id; a `/// <summary>` noting the D6 pin — a note
   cannot live in another resident's folder), `Tags`
   (`IReadOnlyList<string>` — or a JSON column — U01's call, the M26
   `Tag` doc's `Name` normalization shape on write — lowercase, trimmed,
   deduped, sorted; a `/// <summary>` noting the D5 pin — a tag is **not**
   a platform-wide `Tag` doc), `Created` (`DateTimeOffset`, never
   mutated — the D4 pin), `Modified` (`DateTimeOffset?` — the body's
   revision witness, null until the first edit — the D4 pin). **No**
   `Audience`, **no** `IsDeleted` (a note is *content*, not a pointer —
   D4; the body survives the target's death), **no** `ComponentId`, **no**
   `LanguageCode` (D1/D2/D4). A doc-comment on the class says "a note,
   not a pointer — the body survives the target's death (D4 / D7)".
2. `src/Kumunita.Core/PersonalNotes/NoteFolder.cs` — the document (the
   **exact** §2.1 shape): `Id` (string), `OwnerId` (string), `ParentId`
   (`string?` — the owner's parent folder id; depth ≤ 2: root → child →
   grandchild — the D6 pin), `Name` (string — unique within the owner's
   tree — the D6 pin), `Created` (`DateTimeOffset`). **No** `Audience`,
   **no** `IsDeleted`, **no** `ComponentId`, **no** `LanguageCode`
   (D1/D2). A doc-comment on the class says "a personal folder — the
   depth ≤ 2 pin (D6); a folder's deletion moves its notes to the root
   (`FolderId = null`) — the note body is never lost (D6)".
3. `src/Kumunita.Core/PersonalNotesDocTypes.cs` — the surface (D1):
   `public static class PersonalNotesDocTypes { public static void
   Configure(StoreOptions opts) { … } }` with:
   - `opts.Schema.For<PersonalNote>()` carrying:
     - the **unique** index on `(OwnerId, TargetKind, TargetId)` (the
       D3/F1 witness — the M17 `Bookmark` shape re-used),
     - the non-unique index on `(OwnerId, Created)` (the list-ordering
       index),
     - the non-unique index on `(OwnerId, FolderId)` (the folder-tree
       list index — the D6 shape).
   - `opts.Schema.For<NoteFolder>()` carrying:
     - the **unique** index on `(OwnerId, ParentId, Name)` (the D6
       witness),
     - the non-unique index on `(OwnerId, ParentId)` (the folder-tree
       list index — the D6 shape).
   (Use the exact Marten index idiom the `BookmarkDocTypes` /
   `MessagingDocTypes` files use — mirror them; if the codebase uses
   `.UniqueIndex((b) => …)` lambdas, use that form.)
4. `src/Kumunita.Web/Program.cs` — `PersonalNotesDocTypes.Configure(opts);`
   added to the `*DocTypes.Configure(opts)` block, **immediately after**
   the `BookmarkDocTypes.Configure(opts);` line (one line added). If
   `SchemaBootstrap.cs` also calls `BookmarkDocTypes.Configure`, add the
