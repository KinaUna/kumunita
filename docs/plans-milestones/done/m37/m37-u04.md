## Goal

Create the **Web surface part 1** of M37: the **`NotesController`**
(the `attach` action + the `has-note` query action — a *thin* HTTP layer
— routes + authz + shape, the M17 `BookmarksController` precedent), the
**`_NoteButton` partial** (the per-target "attach a note" / "noted"
toggle button, the M17 `_BookmarkButton` precedent), and **wiring** the
partial into the **nine** target detail surfaces (post, group post, event,
page, project, to-do, board, document, directory — the M37 `TargetKind`
closed set). The **`/notes` list view** is **U05** (the list surface +
the `pn.*` `kw-l` keys + the nav entry are U05's).

**The locked decisions you implement (from the design doc — read §2.2,
§2.3, §2.5 verbatim):**
- **C-M37·2** — the owner's note is a **personal read**: a **non-owner**
  (a `GlobalAdmin` included) gets a non-leaky **404** on the `has-note`
  query — and that 404 commits **no** `AccessAudit` row either (the ADR
  0105 "operator has no read standing" precedent). The controller's
  `[Authorize]` is a convenience pre-gate only; the owner-check
  (`SubjectId(user) == ownerId`) is the gate.
- **C-M37·3 / D3** — the write lane (attach a note to a target) **re-runs
  the target's own frozen `Read` decision** before the note row is
  created; Deny ⇒ **404** (not 403 — the Deny row **does not survive**,
  the M16 create-gate posture). The note row itself **never** appears in
  any `CanSeeAsync` pass, never widens an audience, and never confers
  standing.
- **C-M37·4 / D4** — a note is *content*, not a pointer: the button
  reflects "noted" on reload (the `HasNoteAsync` query — the F1 witness).

## Deliverables (3 files)

1. `src/Kumunita.Web/Controllers/NotesController.cs` — the **thin HTTP
   layer** (the `attach` action + the `has-note` query action — the
   M17 `BookmarksController` precedent):
   - `POST /notes/attach` (the D3 write-lane visibility check at the Web
     layer: the controller calls `IPersonalNoteService.CreateNoteAsync`
     with the target's `TargetKind` + `TargetId` + the body (a `string?`
     — null for an empty note, the M17 `Bookmark` shape re-used); the
     `NoteCreateStatus.Refused` maps to **404** (not 403 — the M16
     create-gate posture); the `NoteCreateStatus.AlreadyNoted` maps to
     **200** (the no-op — the M17 `Bookmark` shape re-used); the
     `NoteCreateStatus.Created` maps to **201** (the note is created)).
   - `GET /notes/has/{targetKind}/{targetId}` (the F1 witness — the
     "noted" state on reload: the controller calls
     `IPersonalNoteService.HasNoteAsync` with the actor's `SubjectId`
     as the `ownerId`; a non-owner (a `GlobalAdmin` included) gets a
     non-leaky **404** — the C-M37·2 pin; the owner's own query is a
     personal read, **zero** `AccessAudit` rows — the C-M37·2 pin).
   - **The `[Authorize]` attribute** on both actions (the M17
     `BookmarksController` precedent — the convenience pre-gate).
   - **The owner-check** (`SubjectId(user) == ownerId`) on both actions
     (the M17 `BookmarksController` precedent — the gate).
