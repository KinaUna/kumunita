## Deliverables (≤ 4 files)

1. `src/Kumunita.Web/client/lib/mention-renderer.ts` (new) — the plain-TS,
   no-dep, no-`any` IIFE (the ADR 0031 pin): (1) reads the **rendered** HTML
   body + the **resolved mention map** (the `data-mention-map` JSON attribute
   on the body element, the server-rendered map); (2) scans the rendered body
   for `@<DisplayName>` text nodes **not** inside an existing `<a>` / `<code>`
   / `<pre>` / `<img>` element and **not** already part of an `href`; (3)
   rewrites **only** those to
   `<a class="mention" href="/directory/{residentId}">@<DisplayName></a>`;
   (4) **idempotent** (running twice = same output); (5) a **no-op** for every
   unresolved / ambiguous / blocked / self token (the `resolved map` only
   contains the resolved names) — M36·6. **Zero** new npm package, **zero**
   build step.
2. `src/Kumunita.Web/wwwroot/css/site.css` (modified) — the `.mention { color:
   var(--kw-mention); text-decoration: none; }` + `:hover { text-decoration:
   underline; }` rules — M36·7.
3. `src/Kumunita.Web/Views/Shared/_MentionRenderer.cshtml` (new) — the shared
   partial that `@await`s the `MentionRenderer` pass over the body element —
   the in-scope surfaces' render-boundary wire-in (≤ ~5 files / ~500 LOC).
