## Goal

Create the **Web surface part 1** of M17: the **`BookmarksController`**
(a *thin* HTTP layer — routes + authz + shape, the M16
`InventoryController` precedent), the **`/bookmarks` list view** (the
owner's own bookmarks, grouped by `TargetKind`, the D5 degraded label,
the per-row unbookmark control), the **`bm.*` `kw-l` keys** (× en/de/fr/da
into `KnownTranslationKeys`), the **nav entry** (`bm.nav` — the shared
top-nav + the icon rail), and the **pinned Web tests**.

**The locked decisions you implement (from the design doc — read §kw-l,
§gate (a)/(b)/(c), §2.2 (the result-type shapes) verbatim):**
- **C-M17·2** — the owner's list is a **personal read**: a
  **non-owner** (a `GlobalAdmin` included) gets a non-leaky **404** —
  and that 404 commits **no** `AccessAudit` row either (the ADR 0105
  "operator has no read standing" precedent). The controller's
  `[Authorize]` is a convenience pre-gate only; the owner-check
  (`SubjectId(user) == ownerId`) is the gate.
- **C-M17·5 / D5** — a bookmark whose target is absent, soft-deleted,
  or no longer visible renders the **generic** `bm.list.degraded` label
  — **no title, no link, no id** — and the unbookmark control **still
  works** on it. The degraded row's entire leak surface is exactly one
  static `kw-l` string.
- **§kw-l** — the 12 `bm.*` keys are registered in
  `KnownTranslationKeys` (× en/de/fr/da), the closed set the parity
  tests pin.

## Deliverables (5 files)

1. `src/Kumunita.Web/Controllers/BookmarksController.cs` — the
   controller (the **exact** shape below; mirror the
   `InventoryController` doc-comment tone):
   - `[Authorize]` + `[ValidateAntiForgeryToken]` (on the `POST`
     action).
   - **`GET /bookmarks`** — the owner's list: the actor's
     `SubjectId` (via `KumunitaPrincipal.SubjectId(user)`) is the
     `ownerId`; a non-owner call (a `GlobalAdmin` who is not the
     owner) is a **non-leaky 404** (`NotFoundResult` — the C-M17·2
     pin, the ADR 0105 "operator has no read standing" precedent).
     The seam's `ListAsync(ownerId)` is the **sole reader** (the
     C-M17·1/C-M17·2 pin: the controller never re-derives access, the
     seam does the owner-check + the list-ordering). The view receives
     the `BookmarkListResult` verbatim (the grouped rows, the D5
     degraded flag).
   - **`POST /bookmarks/{targetKind}/{targetId}/remove`** — the
     per-row unbookmark control (the D5 pin: unbookmark on a
     **degraded** row **still works** — the row is keyed on the
     owner's own `Bookmark` id, not the target's id, so the
     unbookmark needs no target read at all). The seam's
     `RemoveAsync` is the sole writer; the controller redirects back
     to `/bookmarks` (the "redirect after write" precedent).

2. `src/Kumunita.Web/Views/Bookmarks/Index.cshtml` — the list view
   (the **exact** shape below; mirror the M16 `Inventory` list view
   layout):
   - **Header**: `<kw-l key="bm.list.title">` (the "Your bookmarks"
     heading).
   - **Empty state**: when `BookmarkListResult.Groups` is empty,
     render `<kw-l key="bm.list.empty">` (the "No bookmarks yet"
     empty state) — the same empty-state discipline as M16.
   - **Groups**: one `<section>` per `BookmarkGroup` (ordered by the
     closed `TargetKind` set, §2.1 — `post` / `event` / `todo` /
     `announcement` / `page`), with a `<h2>` carrying the group's
     `bm.list.kind.<kind>` label (one of the 5 `bm.list.kind.*`
     keys).
   - **Rows**: one `<li>` per `BookmarkRow`. When
     `row.Degraded == false`: the `row.Title` as an `<a href="…">`
     link (the `row.Link`), + a small `<span>` carrying the `Created`
     date (the `DateTimeTagHelper` shape, the ADR 0020 shape). When
     `row.Degraded == true`: a **closed** `<span>` carrying
     `<kw-l key="bm.list.degraded">` — **no** `<a>` tag, **no**
     title text, **no** `TargetId` text (the D5 / C-M17·5 pin; the
     row's entire leak surface is exactly that one static string).
   - **Per-row unbookmark**: a `<form method="post">` POSTing to
     `/bookmarks/{targetKind}/{targetId}/remove` with a hidden
     `_csrf` + a button carrying `<kw-l key="bm.list.unbookmark">`.
     The form is rendered **identically** for degraded and
     non-degraded rows (the D5 pin — the unbookmark control works
     on both).
