# U03 — Month view (true calendar month) + the Day/Week/Month toggle

**Goal:** reframe the shipped EV-CAL chip grid to a **true calendar month**
(driven by `WindowDays`, which the U02 engine now sizes to 5–6 weeks) and add
the **Day / Week / Month toggle** to the header. **Month is the default view**
(C-DWM·8). The existing `client/lib/events-calendar.ts` is **reused unchanged**
— its day-distribution + overlap are view-agnostic (they iterate whatever
day-columns exist, so they work on a 5–6 week × 7 day grid with no change).

**Entry reads:**
- `docs/design/events-calendar-dwm-design.md` §3.4 + §3.5 (Month reframe +
  toggle/nav shape).
- `src/Kumunita.Web/Views/Event/Calendar.cshtml` (the **shipped month
  grid** — the `days`/`NavHref`/header/filter/empty-state shape + the chip
  pool; rework the `days` loop to iterate `Model.WindowDays` and add the
  toggle).
- `src/Kumunita.Web/Models/EventEditorModel.cs` `EventCalendarViewModel`
  (U02's shape — `View`, `WindowDays`, `Label`, `PrevAnchor`/`NextAnchor`;
  the `@model` bindings to match).
- `src/Kumunita.Web/client/lib/events-calendar.ts` (read-only — confirm its
  distribution/overlap iterate `.events-calendar-day` columns generically;
  **do not modify** — C-DWM·7).
- `src/Kumunita.Web/wwwroot/css/site.css` the `events-calendar*` rules
  (~L1145; the grid/column/overlap-ring styles to extend for the toggle).

**Deliverables (2 files):**
- `src/Kumunita.Web/Views/Event/Calendar.cshtml`:
  - drive the day grid from **`Model.WindowDays`** (the ordered local grid
    days) instead of the hardcoded `Enumerable.Range(0, 30)` — this is what
    makes Month a *true calendar month* (the columns now span the anchor's
    calendar month, 5–6 weeks, starting on the Monday on/before the 1st);
  - add the **Day / Week / Month toggle** in the header (three buttons, each
    a plain GET link to `/events/calendar` with `?view=day|week|month` +
    `from=@Model.FromAnchor` + `componentId` riding along — C-DWM·6; mark the
    active view using `Model.View`);
  - use `@Model.Label` for the header lede (the view-appropriate display
    string) in place of `@Model.MonthLabel`;
  - **preserve** the chip pool + the `#events-calendar` root + `data-time-zone`
    / `data-overlap-hint` (so the unchanged `events-calendar.ts` keeps
    distributing + flagging overlap on the Month grid);
  - **preserve** the `componentId` filter form + the "List" cross-link
    (C-DWM·8).
- `src/Kumunita.Web/wwwroot/css/site.css` — add the **toggle** styles (the
  Day/Week/Month button group + active state) + a 5–6 week month-grid
  adjustment if the existing `col-*` row layout needs one for a taller grid
  (a CSS-only change; no markup structural break to the chip stack).
