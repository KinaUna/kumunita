# U08 — the **`ProjectsController` board routes** (list / detail / composer / lane update / delete) + the **board view models**

**Goal:** extend the **`ProjectsController`** U07 created with the **board**
routes (list, detail, composer, the lane-update + board-delete verbs, and the
**`F10`** copy-to / move-to endpoints) and `src/Kumunita.Web/Models/ProjectBoardViewModels.cs`
(the board view models), mirroring the **same M4 `EventController`**
thin-HTTP-layer pattern U07 established (ADR 0006-D: "route + authz + shape" —
the controller never re-derives access). The FACES this surface exercises are
the **behavioral acceptance scenarios** in the design doc **§5** —
specifically **F2** (a to-do can be placed on several boards / appears on
each, over `ListBoardsAsync` / `GetBoardAsync` + the placement rows), **F3**
(a board is gated by its own `Audience`; a to-do on the board is visible iff
**both** are visible — over `GetBoardAsync`'s **two-level decision**
(C-M5·3), the **§2.3** pin), **F4** (moving a to-do into a lane with a
`Status` sets the to-do's status — over `MoveTodoToAdjacentLaneAsync` /
`MoveTodoToBoardAsync`, the **§2.3** pin), **F5** (moving a to-do into a lane
with null `Status` leaves its status unchanged — over the same lanes),
**F6** (a lane at its `MaxItems` limit **refuses** a further move/copy into
it — over `MoveTodoToAdjacentLaneAsync` / `MoveTodoToBoardAsync` /
`CopyTodoToBoardAsync`, the **§2.3** pin), and **F10** (copy-to-board
duplicates / move-to-board relocates the placement — over
`CopyTodoToBoardAsync` / `MoveTodoToBoardAsync`, the **§2.3** pin). The
controller is **thin**: it mints the `actorId` + `actorRoles` set from the
signed-in principal (the `KumunitaPrincipal.SubjectId` / `.RoleSet` helpers —
the M4 pattern, the **U07** shape, reused), calls the `IProjectService` lanes
U04–U06 implemented, resolves the **board author** + **card assignee display
names** via the `IUserInfoService.GetProfileAsync` read surface (a read, never
an access decision — the service's `CanSeeAsync(Read)` / `CanAsync(Read)`
already ran), and returns the view model. The `KeyNotFoundException` →
`NotFound()` (404) and `UnauthorizedAccessException` → `ForbidResult()` (403)
split is the **C3** pin (the M4 `EventController` shape, verbatim — the **U07**
shape, reused). Build green.

### 1. `src/Kumunita.Web/Controllers/ProjectsController.cs` — the **board** routes (extension)

The **class** is **U07's** (the `[Authorize]` + `sealed` shape, the
**`IProjectService`** / **`IUserInfoService`** / **`ILocalizationService`**
injection, the **`SubjectId`** / **`RoleSet`** helpers, the
**`SeedGrantPickerOptionsAsync`** / **`SeedComponentPickerAsync`** /
**`SeedLanguagePickerAsync`** composer-seed trio — the **M4 shape, the U07
shape, reused**). U08 **adds** the following board routes to the **same**
class (the M4 `[HttpGet]` / `[HttpPost]` + the
`catch (UnauthorizedAccessException) { return new ForbidResult(); }` +
`catch (KeyNotFoundException) { return NotFound(); }` split — the **C3** pin,
verbatim from the M4 `EventController`, the **U07** shape, reused):

- **`GET /projects/boards`** (the board feed) — `[HttpGet("/projects/boards")]`,
  calls `IProjectService.ListBoardsAsync(componentId, actorId, page)`, projects
  the rows into **`BoardRow`** records (the **`title / description / created`**
  fields — the M4 `EventRow` shape), returns
  `View(new BoardIndexViewModel { … })`. The **F2** FACES (a to-do can be

  controller's `ForbidResult` / `NotFound` split is the **C3** pin only.
- **`GET /projects/boards/{id}`** (the board detail — the **two-level decision**)

  `IProjectService.GetBoardAsync(boardId, actorId)` → the
  **`BoardDetailResult { Board, Lanes }`** (the **§2.3** shape — the **F3**
  pin: a board is gated by its own `Audience`; a to-do on the board is
  visible iff **both** are visible — the **two-level decision** is the
  **service's**, the **§2.3** pin), projects the **`Board`** + its
  **`Lanes`** (each lane with its **`Cards`** — the **`TodoItem`** rows, each

  **F2** pin: a to-do can be placed on several boards / appears on each) into

  are the **service's**.
- **`GET /projects/boards/new`** (the board composer) —
  `[HttpGet("/projects/boards/new")]`, seeds the **`_GrantPickers`** options

  component picker (the M4 `SeedComponentPickerAsync` pattern, the **U07**
  shape), the language picker (the M4 `SeedLanguagePickerAsync` pattern, the
  **U07** shape), returns
  `View(new BoardEditorModel { … })` (the **empty** form — the

  **`AudienceEditorModel`** (the **M2 shared** grants editor, the sole access

  **service's** pins, the **§2.3** pin)).
- **`POST /projects/boards`** (the board create — with lanes) —
  `[HttpPost("/projects/boards")]`, binds **`BoardEditorModel`**, calls
  `IProjectService.CreateBoardAsync(actorId, RoleSet(User), new
  CreateBoardRequest { Title, Description, ComponentId, Audience,
  LanguageCode, Lanes })` (**§2.3** shape — the **F2** pin: a to-do can be
  placed on several boards / appears on each — the board is the **container**,

  M4 redirect-after-POST pattern, the **U07** shape), on
  `UnauthorizedAccessException` → `ForbidResult()` (the **F8** pin — the

  `KeyNotFoundException` → `NotFound()`.
- **`POST /projects/boards/{id}/lanes/{laneId}`** (the lane update) —

  **`LaneEditorModel`** (the **`Title / Status / MaxItems / Order`** fields —

- **`POST /projects/boards/{id}/delete`** (the board delete — cascades lanes
  + placements) — `[HttpPost("/projects/boards/{id}/delete")]`, calls
  `IProjectService.DeleteBoardAsync(boardId, actorId, RoleSet(User))` (the
