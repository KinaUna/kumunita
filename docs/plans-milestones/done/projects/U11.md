### 1. `src/Kumunita.Web/client/lib/projects-board.ts` — the **board
interaction module**

The **one** plain-TS module for `Views/Projects/BoardDetail.cshtml` (the
**ADR 0031** pin: tsc-only, zero dependencies, no bundler — the
`events-calendar.ts` shape, reused). The module is an **IIFE**
(Immediately Invoked Function Expression) — the **M3/M4** precedent; no
globals, no `any`, no HTML5 drag, no optimistic reordering (the **C-M5·9** /
**D10** pins). The data contract is the **kanban CSS classes** the U10 view
ships (`.kanban-board` / `.kanban-lane` / `.kanban-card` / `.kanban-cards`)
+ the **card action dropdown** `<form method="post">` elements (the **M4
redirect-after-POST** shape). The module is **keyboard + menu**: the
**menu** is the Bootstrap dropdown (server-rendered, the **U10** shape);
the **keyboard** is the module's `keydown` listener (the **C-M5·9** pin:
plain TS / zero deps / explicit server round trips).

```ts
/**
 * Board interaction (M5 — ADR 0067) — the one plain-TS module for
 * `Views/Projects/BoardDetail.cshtml` (tsc-only, zero dependencies — the
 * ADR 0031 pin; mirrors the `events-calendar.ts` shape). Two interaction
 * channels:
 *
 * (a) Menu (server-rendered, the U10 shape): the Bootstrap dropdown
 *     items are `<form method="post">` elements — the browser handles
 *     the POST + CSRF + redirect natively; no JS needed.
 *
 * (b) Keyboard (this module): arrow keys on a focused card trigger the
 *     corresponding reorder endpoint (up / down / left / right) via a
 *     CSRF-aware `fetch` + `window.location` redirect (the `api.ts`
 *     `getAntiForgeryToken` shape, the **C3** pin: the server is
 *     authoritative — no optimistic reordering, the **D10** pin).
 *
 * No HTML5 drag (C-M5·9 / D10), no `any`, no globals, no new
 * `api.ts` method — `getAntiForgeryToken` is the sole import.
 */
import { getAntiForgeryToken } from './api.js';

(() => {
  'use strict';

  const board = document.querySelector<HTMLElement>('.kanban-board');
  if (!board) return;

  // The CSRF token — the `api.ts` shape (the **C3** pin: the server is
  // authoritative; the token is a **write** channel, never a **read**
  // channel — the **§2.3** pin).
  function postAndRedirect(url: string): void {
    fetch(url, {
      method: 'POST',
      credentials: 'same-origin',
      headers: { 'RequestVerificationToken': getAntiForgeryToken() },
    })
      .then((res) => {
        if (res.redirected) {
          window.location.href = res.url;
        } else if (res.ok) {
          // Some endpoints return 204 (no content) + a `Location` header
          // instead of a 302 — follow the `Location` header.
          const loc = res.headers.get('Location');
          if (loc) {
            window.location.href = loc;
          } else {
            window.location.reload();
          }
        } else {
          // 403 (the **F8** pin: the non-stable actor is refused — the
          // **service's** pin, the **§2.3** pin) or 404 (the **C3** pin:
          // the placement / board / lane was not found — the
          // **service's** pin) — the server's response is authoritative;
          // navigate to the URL (the browser shows the 403 / 404 page).
          window.location.href = url;
        }
      })
      .catch(() => {
        // Network error — navigate to the URL (the browser shows the
        // error page).
        window.location.href = url;
      });
  }

  // Keyboard shortcuts (the **C-M5·9** pin: plain TS / zero deps /
  // explicit server round trips; the **D10** pin: **no** HTML5 drag,
  // **no** optimistic reordering — the server is authoritative):
  //   ArrowUp    → move-up    (within-lane)
  //   ArrowDown  → move-down  (within-lane)
  //   ArrowLeft  → move-left  (adjacent-lane)
  //   ArrowRight → move-right (adjacent-lane)
  //
  // The card's `<form>` element carries the `action` URL (the **U10**
  // shape — the `POST /projects/boards/{boardId}/lanes/{laneId}/cards/{placementId}/move-{direction}`
  // route, the **U08** shape, reused). The module finds the
  // corresponding form by the `action` URL suffix and submits it via
  // `postAndRedirect` (the **C3** pin: the server is authoritative).
  const KEY_TO_DIRECTION: Record<string, string> = {
    ArrowUp: 'move-up',
    ArrowDown: 'move-down',
    ArrowLeft: 'move-left',
    ArrowRight: 'move-right',
  };

  board.addEventListener('keydown', (e: KeyboardEvent) => {
    const card = (e.target as HTMLElement).closest<HTMLElement>('.kanban-card');
    if (!card) return;

    const direction = KEY_TO_DIRECTION[e.key];
    if (!direction) return;

    e.preventDefault();

    // Find the form for this direction (the **U10** shape — the
    // `<form method="post" action="...">` element in the card's
    // action dropdown, the **M4 redirect-after-POST** shape).
    const form = card.querySelector<HTMLFormElement>(
      `form[action$="/${direction}"]`,
    );
    if (form?.action) {
      postAndRedirect(form.action);
    }
  });
})();
```

**The module is loaded** as an ES module from the U10 `BoardDetail.cshtml`
view's `@section Scripts`:
`<script type="module" src="~/js/lib/projects-board.js"></script>` (the
**ADR 0031** pin — the `<script type="module" src="~/js/lib/...">` shape,
the **M3/M4** precedent, the **U09 / U10** shape, reused). The **`tsc`**
build (the **`npm --prefix src/Kumunita.Web run build`** command, the
**ADR 0031** pin) compiles the module to `wwwroot/js/lib/projects-board.js`
(the **`tsconfig.json`** output path, the **M3/M4** shape, reused).

**The module does NOT:**
- **Drag-and-drop** (the **C-M5·9** / **D10** pin: **no** HTML5 drag — the
  reorder is **keyboard + menu**, not drag).
- **Optimistically reorder** the DOM (the **D10** pin: the server is
  authoritative — the `postAndRedirect` function navigates to the server's
  response, which re-renders the board with the new order).
- **Re-derive standing or visibility** (the **C3** pin: the server's
  `ForbidResult` / `NotFound` split is the **service's** — the module
  navigates to the server's response, which shows the 403 / 404 page if the
  actor is refused).
- **Handle the menu items** (the **U10** shape: the Bootstrap dropdown
  items are `<form method="post">` elements — the browser handles the POST
  + CSRF + redirect natively; the module only handles the **keyboard**
  channel).
