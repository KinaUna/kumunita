  - `### 2.3 the full `IProjectService` surface (exact C#, verbatim)` —
    - **Read lanes (U04):**
      - `Task<IReadOnlyList<TodoItem>> ListTodosAsync(string? componentId, string? assigneeId, string actorId, int page, CancellationToken ct = default);`
        — the **standalone to-do list** (the feed): the candidates are
        `!IsDeleted`, filtered by optional `ComponentId` (a
        filter, never a gate — C-M3·2) and optional `AssigneeId` (a filter,
        never a gate — C-M5·6); the survivors are
        `CanSeeAsync(Read)`-filtered (C6 / C3) over the
        `TodoItemToAuditableResource`; ordered by `Created` descending
        (the newest first — the post feed shape); paged. The **aggregate**
        `AccessAudit` row (`TargetKind "todo"`, `visibleCount` /
        `hiddenCount`) is the C-M3·3 shape.
      - `Task<TodoDetailResult> GetTodoAsync(string todoItemId, string actorId, CancellationToken ct = default);`
        — one to-do + its **subtasks** (the `TodoItem` rows with
        `ParentId == todoItemId`, each with its own `Audience` decision —
        a subtask is a full to-do, C-M5·7). One `CanAsync(Read)` over the
        to-do; if `Allowed`, the subtasks are loaded **under the parent's
        decision** (each subtask's own `CanAsync(Read)` — the ADR 0013
        reply-inherits shape is **not** the M5 pin; a subtask is its own
        document with its own `Audience`). `KeyNotFoundException` (404) on
        absent, `UnauthorizedAccessException` (403) on denied (the C3
        404-vs-403 split).
      - `Task<IReadOnlyList<KanbanBoard>> ListBoardsAsync(string? componentId, string actorId, int page, CancellationToken ct = default);`
        — the **board list** (the feed): the candidates are
        `!IsDeleted`, filtered by optional `ComponentId` (a filter, never a
        gate — C-M3·2); the survivors are `CanSeeAsync(Read)`-filtered
        (C6 / C3) over the `KanbanBoardToAuditableResource`; ordered by
        `Created` descending; paged. The **aggregate** `AccessAudit` row
        (`TargetKind "board"`, `visibleCount` / `hiddenCount`) is the
        C-M3·3 shape.
      - `Task<BoardDetailResult> GetBoardAsync(string boardId, string actorId, CancellationToken ct = default);`
        — one board + its **lanes** (the `KanbanLane` rows with
        `BoardId == boardId`, ordered by `Order` ascending) + each lane's
        **cards** (the `BoardItemPlacement` rows with `BoardId == boardId
        && LaneId == laneId`, ordered by `Order` ascending, each resolved to
        its `TodoItem`). **The two-level decision** (C-M5·3): the board's
        `CanAsync(Read)` is the entry gate (a `Deny` ⇒ 404/403 split — the
        C3 shape); each card's `TodoItem` is **itself** `CanAsync(Read)`-gated
        (a to-do on the board is visible iff **both** the board and the
        to-do are visible — C-M5·3; a denied card is **not returned** in the
        result, not just hidden in the view). The **aggregate**
        `AccessAudit` row (`TargetKind "board"`, `visibleCount` = the visible
        card count, `hiddenCount` = the denied card count) is the C-M3·3
        shape.
    - **Write lanes (U05):**
      - `Task<TodoItem> CreateTodoAsync(string actorId, IReadOnlySet<string> actorRoles, CreateTodoRequest request, CancellationToken ct = default);`
        — the author's choice is written verbatim (ADR 0001-B); the to-do is
        **published on creation** (no `IsDraft` — the ADR 0037 draft lane is
        out of scope for M5). The author becomes the standing owner
        (the `AuthorId` branch). The `AccessAudit` row (`todo.create`,
        `TargetKind "todo"`) is stored in the caller's session (C3).
      - `Task<TodoItem> UpdateTodoAsync(string todoItemId, string actorId, IReadOnlySet<string> actorRoles, UpdateTodoRequest request, CancellationToken ct = default);`
        — **creator ∪ assignee ∪ GlobalAdmin** (the ADR 0014 / 0016 / 0017
        precedent, enforced server-side per C-M5·6). `AuthorId` / `Created`
        preserved untouched; `Modified` stamped on a real change. The
        `actorRoles` parameter carries the principal's real role set (the Web
        layer passes `RoleSet(User)` — the standing matrix, C-M5·6).
      - `Task<TodoItem> AssignTodoAsync(string todoItemId, string actorId, IReadOnlySet<string> actorRoles, string? assigneeId, CancellationToken ct = default);`
        — set `AssigneeId` to `assigneeId` (`null` = unassign). **Creator ∪
        assignee ∪ GlobalAdmin** (C-M5·6). The `AccessAudit` row
        (`todo.assign`, `TargetKind "todo"`) is stored in the caller's
        session (C3).
      - `Task<TodoItem> AddSubtaskAsync(string parentTodoItemId, string actorId, IReadOnlySet<string> actorRoles, CreateTodoRequest request, CancellationToken ct = default);`
        — a new `TodoItem` with `ParentId = parentTodoItemId` (the
        sole hierarchy mechanism — C-M5·7). **Creator ∪ assignee ∪
        GlobalAdmin** over the **parent** (C-M5·6). The parent's
        `ParentId` is unchanged. The `AccessAudit` row (`todo.add_subtask`,
        `TargetKind "todo"`) is stored in the caller's session (C3).
      - `Task DeleteTodoAsync(string todoItemId, string actorId, IReadOnlySet<string> actorRoles, CancellationToken ct = default);`
        — **soft-delete** the to-do (sets `IsDeleted = true` — the ADR 0024
        author-lane shape) + **cascade** to the descendant subtree (the
        `TodoItem` rows transitively reachable via `ParentId` — C-M5·7).
        **Creator ∪ assignee ∪ GlobalAdmin** (C-M5·6). The `AccessAudit`
        row (`todo.delete`, `TargetKind "todo"`) is stored in the caller's
        session (C3).
      - `Task<KanbanBoard> CreateBoardAsync(string actorId, IReadOnlySet<string> actorRoles, CreateBoardRequest request, CancellationToken ct = default);`
        — a new `KanbanBoard` + its initial `KanbanLane` rows (the lane
        `Title` / `Status` / `MaxItems` / `Order` values are in the
        `CreateBoardRequest.Lanes`). The author becomes the standing owner
        (the `AuthorId` branch). The `AccessAudit` row (`board.create`,
        `TargetKind "board"`) is stored in the caller's session (C3).
      - `Task<KanbanLane> UpdateLaneAsync(string laneId, string actorId, IReadOnlySet<string> actorRoles, UpdateLaneRequest request, CancellationToken ct = default);`
        — set the lane's `Title` / `Status` / `MaxItems` / `Order`.
        **Creator ∪ GlobalAdmin** over the **board** (the lane's standing
        is the board's — a lane is not its own standing surface; the
        assignee branch does not apply to a lane). The `AccessAudit` row
        (`board.update_lane`, `TargetKind "board"`) is stored in the caller's
        session (C3).
      - `Task DeleteBoardAsync(string boardId, string actorId, IReadOnlySet<string> actorRoles, CancellationToken ct = default);`
        — **soft-delete** the board (sets `IsDeleted = true` — the ADR 0024
        author-lane shape) + **delete** the board's `KanbanLane` rows +
        **delete** the board's `BoardItemPlacement` rows (the placements
        are **not** cascaded to the to-dos — a to-do on a deleted board is
        still standalone, C-M5·2). **Creator ∪ GlobalAdmin** over the board.
        The `AccessAudit` row (`board.delete`, `TargetKind "board"`) is
        stored in the caller's session (C3).
    - **Placement lanes (U06):**
      - `Task<BoardItemPlacement> MoveTodoWithinLaneAsync(string placementId, string direction, string actorId, IReadOnlySet<string> actorRoles, CancellationToken ct = default);`
        — **`direction` is `"up"` or `"down"`** (a string, not an enum —
        the ADR 0031 plain-GET/POST posture). **Reorder** within the lane:
        swap `Order` with the adjacent card (the `BoardItemPlacement` row
        with the next lower / higher `Order` in the same lane). **Creator ∪
        assignee ∪ GlobalAdmin** over the **to-do** (C-M5·6). The
        `AccessAudit` row (`todo.move_within_lane`, `TargetKind "todo"`) is
        stored in the caller's session (C3).
      - `Task<BoardItemPlacement> MoveTodoToAdjacentLaneAsync(string placementId, string direction, string actorId, IReadOnlySet<string> actorRoles, CancellationToken ct = default);`
        — **`direction` is `"left"` or `"right"`** (a string, not an enum).
        **Change lane** (same board): the placement's `LaneId` is set to the
        adjacent lane's id (the `KanbanLane` row with the next lower /
        higher `Order` in the same board); `Order` is reset to the **end** of
        the target lane (the max `Order` + 1). **The lane-status
        auto-update** (C-M5·4): if the target lane's `Status` is non-null,
        the to-do's `Status` is set to that lane's status (in the same
        transaction — C3); if the target lane's `Status` is null, the
        to-do's status is unchanged. **The lane-limit refusal** (C-M5·5):
        if the target lane's `MaxItems` is non-null and the target lane
        already has `MaxItems` placements, the move is **refused** (a
        `InvalidOperationException` with the lane's `Title` in the
        message; nothing is written). **Creator ∪ assignee ∪ GlobalAdmin**
        over the to-do. The `AccessAudit` row (`todo.move_to_lane`,
        `TargetKind "todo"`) is stored in the caller's session (C3).
      - `Task<BoardItemPlacement> MoveTodoToBoardAsync(string todoItemId, string targetBoardId, string actorId, IReadOnlySet<string> actorRoles, CancellationToken ct = default);`
        — **relocate** the placement (C-M5·8): the placement rows on the
        **source** board (all of them) are **deleted**; a new
        `BoardItemPlacement` row is created on the target board's **first
        lane** (the `KanbanLane` row with the lowest `Order` in the target
        board); `Order` is set to the end of that lane (the max `Order` +
        1). **The lane-status auto-update** (C-M5·4) applies to the
        target's first lane (the same C-M5·4 rule). **The lane-limit
        refusal** (C-M5·5) applies to the target's first lane (the same
        C-M5·5 rule). **Creator ∪ assignee ∪ GlobalAdmin** over the to-do.
        The `AccessAudit` row (`todo.move_to_board`, `TargetKind "todo"`)
        is stored in the caller's session (C3).
      - `Task<TodoItem> CopyTodoToBoardAsync(string todoItemId, string targetBoardId, string actorId, IReadOnlySet<string> actorRoles, CancellationToken ct = default);`
        — **duplicate** the to-do (C-M5·8): a new `TodoItem` row with the
        same `Title` / `Body` / `Status` / `AssigneeId` / `Audience` (the
        `AuthorId` is the **actor**, not the original's author — the copy
        is a new to-do, not a clone); **no** `ParentId` (a copy is always
        top-level — a subtask is not copied as a subtask; the copy is its
        own to-do); a new `BoardItemPlacement` row on the target board's
        **first lane** (the same shape as `MoveTodoToBoardAsync`). The
        original to-do is **untouched** (C-M5·8). **The lane-status
        auto-update** (C-M5·4) applies to the target's first lane (the same
        C-M5·4 rule). **The lane-limit refusal** (C-M5·5) applies to the
        target's first lane (the same C-M5·5 rule). **Creator ∪ assignee ∪
        GlobalAdmin** over the to-do. The `AccessAudit` row
        (`todo.copy_to_board`, `TargetKind "todo"`) is stored in the
        caller's session (C3).
    - **The DTOs** (ns `Kumunita.Core.Projects`):
      - `CreateTodoRequest { string Title, string? Body, string? ComponentId, string? AssigneeId, string? ParentId, Audience? Audience, string? LanguageCode, IReadOnlyList<string>? TagIds }`
      - `UpdateTodoRequest { string? Title, string? Body, string? ComponentId, string? Status, string? ParentId, bool ClearParent, string? LanguageCode, IReadOnlyList<string>? TagIds }`
        (the `ParentId?` is the new parent id — a non-null value **reparents** the to-do to that parent; `ClearParent` is the explicit flag that **unparents** the to-do back to top-level (sets `ParentId = null`). The **hierarchy cycle guard** (C-M5·7) is enforced server-side in `UpdateTodoAsync` — U05's pin; the `UpdateTodoRequest` carries the intent, the service enforces the guard.)
      - `CreateBoardRequest { string Title, string? Description, string? ComponentId, Audience? Audience, string? LanguageCode, IReadOnlyList<CreateLaneRequest> Lanes }`
