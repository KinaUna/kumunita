# U09 — the **to-do Razor views** (list / detail / compose / edit) + the **nav entry** + the **to-do action dropdown**

**Goal:** create the **four to-do Razor views** under
`src/Kumunita.Web/Views/Projects/` (`TodoIndex.cshtml`,
`TodoDetail.cshtml`, `TodoNew.cshtml`, `TodoEdit.cshtml`) rendering the
**`TodoIndexViewModel`** / **`TodoDetailViewModel`** / **`TodoEditorModel`**
view models U07 created; add the **nav entry** to
`src/Kumunita.Web/Views/Shared/_Layout.cshtml` (the signed-in nav block — the
`nav.events` M4 precedent, line 73); and wire the **to-do action dropdown**
(assign / add-subtask / delete) on the list + detail rows — the **Bootstrap
`dropdown`** shape (the `_AccountNav.cshtml` pattern, the **M2/M3/M4** shared
nav-dropdown idiom). The views are **server-rendered** (Razor Pages / MVC, the
**ADR 0001** stack pin); the **F1 / F7 / F8 / F9** FACES are the
**service's** (the views render what the service returns — the **C3** pin).
The to-do `Body` renders through the **one** `bindRichEditor` (the **ADR
0031** WYSIWYG editor pin — the `data-rich-editor` + `rich-editor.js` module
shape, the **M3/M4** precedent). The audience grants render through the
**`_GrantPickers`** partial (the **M2/M3/M4 shared** grants-picker shape). All
timestamps render through the **`kw-dt`** TagHelper (the **ADR 0019 / 0020**
pin). All labels use **`kw-l`** keys from the **`projects.todo.*`** +
**`nav.projects`** blocks. **Key story:** the design doc **§2.6** pins the
**floor** of `kw-l` keys (18: the `projects.todo.title / body / assignee /
status / delete / add_subtask / copy_to / move_to / move_up / move_down /
move_left / move_right` + the `projects.board.*` set); the views + board TS
(U09 / U10 / U11) reference a **larger** set (the `lede / new / edit / save /
assign / parent / clear_parent / subtasks / boards / nav.projects` labels).
**U11 ships the *complete* `kw-l` key set the views + board TS reference,
present in all four seeded languages (en / de / fr / da), English as the
fallback** (the **ADR 0015** key-registry shape, the **D11** pin) — the §2.6
list is the design *floor*, not the ceiling. U09's views may reference the
full set; U11 is the unit that adds them to `KnownTranslationKeys.cs`. Build
green.
