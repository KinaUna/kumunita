# U07 — the **`ProjectsController` to-do routes** (list / detail / compose) + the **to-do view models**

**Goal:** create `src/Kumunita.Web/Controllers/ProjectsController.cs` with the
**to-do** routes (list, detail, compose, and the five to-do action verbs) and
`src/Kumunita.Web/Models/ProjectTodoViewModels.cs` (the to-do view models),
mirroring the **M4 `EventController`** thin-HTTP-layer pattern (ADR 0006-D:
"route + authz + shape" — the controller never re-derives access). The FACES
this surface exercises are the **behavioral acceptance scenarios** in the
design doc **§5** — specifically **F1** (a standalone to-do is visible to its
audience member / hidden from a non-member, over `ListTodosAsync` /
`GetTodoAsync`), **F7** (the assignee has standing over an assigned to-do,
over `UpdateTodoAsync` / `AssignTodoAsync`), **F8** (a non-creator /
non-assignee / non-GlobalAdmin is refused, over every to-do write lane), and
**F9** (a subtask is a full to-do; delete cascades to the subtree, over
`AddSubtaskAsync` / `DeleteTodoAsync`). The controller is **thin**: it mints
the `actorId` + `actorRoles` set from the signed-in principal (the
`KumunitaPrincipal.SubjectId` / `.RoleSet` helpers — the M4 pattern), calls
the `IProjectService` lanes U04–U06 implemented, resolves the **author /
assignee display names** via the `IUserInfoService.GetProfileAsync` read
surface (a read, never an access decision — the service's `CanSeeAsync(Read)`
/ `CanAsync(Read)` already ran), and returns the view model. The
`KeyNotFoundException` → `NotFound()` (404) and `UnauthorizedAccessException`
→ `ForbidResult()` (403) split is the **C3** pin (the M4 `EventController`
shape, verbatim). Build green.

**Deliverables (2 new files):**

### 1. `src/Kumunita.Web/Controllers/ProjectsController.cs` — the **to-do** routes

The **class** (`[Authorize]` + `sealed` — the M4 `EventController` shape),
injected with **`IProjectService`** (the lanes U04–U06 implemented),
**`IUserInfoService`** (the **author / assignee display-name** resolution — a
read, never a decision), **`ILocalizationService`** (the composer's authored-in
language picker seed — the M4 pattern); the same helper methods **`SubjectId`**
/ **`RoleSet`** (the `KumunitaPrincipal` helpers — the M4 shape, reused) +
**`SeedGrantPickerOptionsAsync`** / **`SeedComponentPickerAsync`** /
**`SeedLanguagePickerAsync`** (the M4 composer-seed trio — the **M2/M3/M4**
shared composer pattern, reused not reinvented).

The routes (the M4 `[HttpGet]` / `[HttpPost]` + the
`catch (UnauthorizedAccessException) { return new ForbidResult(); }` +
`catch (KeyNotFoundException) { return NotFound(); }` split — the **C3** pin,
verbatim from the M4 `EventController`):

- **`GET /projects/todos`** (the to-do feed) — `[HttpGet("/projects/todos")]`,
  calls `IProjectService.ListTodosAsync(componentId, actorId, page)`, projects
  the rows into **`TodoRow`** records, returns
  `View(new TodoIndexViewModel { … })`. The **F1** FACES (visible to audience
  member / hidden from non-member) are the **service's** — the controller's
  `ForbidResult` / `NotFound` split is the **C3** pin only.
- **`GET /projects/todos/{id}`** (the to-do detail) —
  `[HttpGet("/projects/todos/{id}")]`, calls
  `IProjectService.GetTodoAsync(todoItemId, actorId)` → the
  **`TodoDetailResult { Todo, Subtasks }`** (the **§2.3** shape), projects the
  **`Todo`** + its **`Subtasks`** (each subtask is its own row — **F9**: a
  subtask is a full to-do, its own `Audience` decision) into
  **`TodoDetailViewModel`**, returns `View(vm)`.
- **`GET /projects/todos/new`** (the compose) —
  `[HttpGet("/projects/todos/new")]`, seeds the **`_GrantPickers`** options (the
  M4 `SeedGrantPickerOptionsAsync` pattern), the component picker (the M4
  `SeedComponentPickerAsync` pattern), the language picker (the M4
  `SeedLanguagePickerAsync` pattern), returns
  `View(new TodoEditorModel { … })` (the **empty** form — the
  **`Title / Body / Status (text) / AssigneeId / ParentId`** fields + the
  **`AudienceEditorModel`** (the **M2 shared** grants editor, the sole access
  boundary) + the **parent picker** (the actor's **own** top-level to-dos — a
  `ListTodosAsync` read; the **F9** pin — a subtask is a full to-do, the
  parent's own `ParentId` is unchanged)).
- **`POST /projects/todos`** (the create) —
  `[HttpPost("/projects/todos")]`, binds **`TodoEditorModel`**, calls
  `IProjectService.CreateTodoAsync(actorId, RoleSet(User), new
  CreateTodoRequest { Title, Body, ComponentId, AssigneeId, ParentId,
  Audience, LanguageCode, TagIds })` (**§2.3** shape), on success
  `Redirect("/projects/todos/{id}")` (the M4 redirect-after-POST pattern), on
  `UnauthorizedAccessException` → `ForbidResult()` (**F8** — refused
  server-side), on `KeyNotFoundException` → `NotFound()`.
- **`POST /projects/todos/{id}`** (the update) —
  `[HttpPost("/projects/todos/{id}")]`, binds **`TodoEditorModel`**, calls
  `IProjectService.UpdateTodoAsync(todoItemId, actorId, RoleSet(User), new
  UpdateTodoRequest { Title, Body, ComponentId, Status, ParentId, ClearParent,
  LanguageCode, TagIds })` (**§2.3** shape — the **`ParentId?`** is the new
  parent, a non-null value **reparents** the to-do; **`ClearParent = true`**
  unparents back to top-level; both `null` + `ClearParent = false` is a no-op
  on the hierarchy — the **C-M5·7** pin, the **§2.3** pin verbatim); the
  **hierarchy cycle guard** (C-M5·7) is enforced **server-side** in
  `UpdateTodoAsync` (U05's pin); the **F7** / **F8** FACES (the assignee has
  standing / the non-stable actor is refused) are the **service's**.
- **`POST /projects/todos/{id}/assign`** (the assign) —
  `[HttpPost("/projects/todos/{id}/assign")]`, binds the **`AssigneeId?`**
  form field (`null` = unassign), calls
  `IProjectService.AssignTodoAsync(todoItemId, actorId, RoleSet(User),
  assigneeId)`; the **F7** / **F8** FACES are the **service's**.
- **`POST /projects/todos/{id}/subtasks`** (the add-subtask) —
  `[HttpPost("/projects/todos/{id}/subtasks")]`, binds **`Title / Body /
  Status / AssigneeId`**, calls
  `IProjectService.AddSubtaskAsync(parentTodoItemId, actorId, RoleSet(User),
  new CreateTodoRequest { Title, Body, ComponentId, AssigneeId, ParentId =
  parentTodoItemId, Audience, LanguageCode, TagIds })` (the **§2.3**
  `AddSubtaskAsync` shape — the **F9** pin: a subtask is a full to-do, the
  parent's own `ParentId` is unchanged); the **F7** / **F8** FACES over the
  **parent** are the **service's**.
- **`POST /projects/todos/{id}/delete`** (the soft-delete) —
  `[HttpPost("/projects/todos/{id}/delete")]`, calls
  `IProjectService.DeleteTodoAsync(todoItemId, actorId, RoleSet(User))`; the
  **cascade** to the descendant subtree is the **service's** (U05's pin — the
  **F9** `DeleteCascadesToSubtree` pin); the **F7** / **F8** FACES are the
  **service's**.

**The controller is thin (ADR 0006-D):** every access decision is the
`IProjectService`'s; the controller's `ForbidResult` / `NotFound` split is the
**C3** pin (the M4 shape); the **F1 / F7 / F8 / F9** FACES are the
**service's** (the controller never re-derives standing or visibility).

### 2. `src/Kumunita.Web/Models/ProjectTodoViewModels.cs` — the **to-do** view models

Mirroring the M4 `EventViewModels.cs` shape:

- **`TodoRow`** (a record — the **`title / body / status (text) / assignee
  display name / parent (if any) / created`** fields — the M4 `EventRow`
  shape, the **F1** list-row shape).
- **`TodoIndexViewModel`** (the **`GET /projects/todos`** return — the
  **`IReadOnlyList<TodoRow>`** rows + the **component picker options** + the
  **current page** — the M4 `EventIndexViewModel` shape).
- **`TodoDetailViewModel`** (the **`GET /projects/todos/{id}`** return — the
  **`TodoRow`** (the to-do) + the **`IReadOnlyList<TodoRow>` subtasks** (each
  a full to-do — the **F9** pin) + the **board placements** (which boards +
  lanes the to-do is on — the **F2** FACES the board view (U08)
  cross-references) — the M4 `EventDetailViewModel` shape).
- **`TodoEditorModel`** (the **compose / edit** form — the **`Title / Body /
  Status (text) / AssigneeId / ParentId`** fields + the
  **`AudienceEditorModel`** (the **M2 shared** grants editor, the sole access
  boundary on the form — the M3/M4 precedent) + the **`LanguageCode`** + the
  **`TagIds`** — the M4 `EventEditorModel` shape).
