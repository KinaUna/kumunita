# M27 U05 — Import: the per-entity resolve model (add-elsewhere / discard)

## Context (self-contained)

M27 = **user-scoped portability**: a resident imports **their own authored
data** and resolves per-entity conflicts. U04 shipped the `ClassifyAsync`
clean/duplicate/conflict classification (the pre-write report). U05 pins the
**resolve model** (the closed shapes U01's shell declared): the
`UserPortabilityEntityResolution` POCO set — the resident's per-entity
decision: **`AddElsewhere`** (the re-point: the absent reference target kind
+ the **target id the resident picked** — a group/component/page/tag they *are*
a member of / own) or **`Discard`** (no write). The closed `ResolutionKind`
set + the `UserPortabilityImportResult` closed-failure shape. **Pure model +
the `ResolveAsync` input contract** (U06 fills the apply). **No apply logic
yet** (U06). **No auto-merge** (C-M27·4 — the author's choice is absolute).

## Goal

Pin the `UserPortabilityEntityResolution` POCO closed shape (the
`ResolutionKind` enum `AddElsewhere`/`Discard` + the `AddElsewhere` re-point
fields (the absent-reference kind + the **picked target id**) + the `EntityKey`
the decision is keyed on) + the `UserPortabilityImportResult` closed-failure
shape (the D4 no-auto-merge + the apply-failure set) + author the **resolve-
model shape pins** in
`tests/Kumunita.Core.Tests/UserPortabilityResolveModelTests.cs`. The
`ResolveAsync` body stays `NotImplementedException` until U06.
