## Goal

D4 rendered in the UI: **two `[Authorize]` routes on `ProjectsController`**
(the M12 iCal route shapes, the `IcsWriter` serve idiom):

- **`GET /projects/todos.ics`** — the **subscription feed**: the frozen
  `IProjectService.ListTodosAsync` caller's **visible** set (the
  candidate filter + the `CanSeeAsync(Read)` gate all inside the seam) →
  filter to **dated** to-dos (`DueAt != null || StartAt != null`) →
  `TodoIcsWriter.BuildTodos` → the serve idiom. **Always `200`** (the feed
  is a valid `VCALENDAR` — an empty visible set is a valid empty calendar;
  the seam filters rather than throws). **No subscription token** — the
  feed rides the cookie, re-authorized every fetch (the M6 link-lane
  posture).
- **`GET /projects/todos/{id}.ics`** — the **per-to-do** file: the frozen
  `IProjectService.GetTodoAsync`'s **404-not-403** split → one `VTODO`
  (if dated) → the serve idiom.
- **Serve shape (the ADR 0034/0108 idiom):** `Content-Type:
  text/calendar; charset=utf-8` + `Content-Disposition: attachment;
  filename="kumunita-todo-{id}.ics"` / `"kumunita-todos.ics"` +
  `Cache-Control: no-store` + `X-Content-Type-Options: nosniff`.
- **Two quiet `kw-l` affordances** × **en/de/fr/da**:
  `projects.todos.ics.download` "Add to calendar" (a plain `<a>` on the
  to-do detail) + `projects.todos.ics.feed` "Calendar feed (iCal)" (a plain
  `<a>` on the to-do index). **No new JS** (tsc-only ADR 0031 — these are
  plain anchors).
