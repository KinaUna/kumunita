## Goal

D3 rendered as code: `SetTodoEventAsync` on `IProjectService` —

- **Standing (server-side, C-M5·6 / C-M14·3):** creator ∪ assignee ∪
  GlobalAdmin over the to-do; the Web `[Authorize]` is a convenience
  pre-gate only.
- **Preconditions:** the to-do exists and is `!IsDeleted` (else
  `KeyNotFoundException` — 404, non-leaky).
- **The `eventId` visibility rule:** a non-existent / soft-deleted /
  unreadable `eventId` is **refused** (`KeyNotFoundException`) — you can
  only link to an event you can *see* (reused via the frozen
  `IEventService.GetAsync`); a `null` / blank `eventId` **clears** the
  link (sets `EventId = null`).
- **One `AccessAudit` row** (`todo.set_event`, `TargetKind = "todo"`)
  commits atomically with the write (C3); `Modified` stamped on a real
  change.
- **No new authorization surface** (C-M14·4).
- **3 pinned tests** (names verbatim): creator / assignee / GlobalAdmin
  each allowed, an outsider refused 403; a non-visible `eventId` refused
  404, a `null` clears the link; the `AccessAudit` row `todo.set_event`
  committed with the write.
