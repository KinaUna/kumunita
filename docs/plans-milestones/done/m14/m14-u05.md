## Goal

D4 rendered as code: `TodoIcsWriter` — **BCL-only, pure** (the `IcsWriter`
discipline, C-M14·5 / C-M14·6):

- **`BuildTodos(IReadOnlyList<TodoItem> todos, DateTimeOffset nowUtc)`** —
  one public method. Renders the **entire** ICS file — the one
  `VCALENDAR` envelope + one `VTODO` per **dated** to-do, in list order —
  on the **closed pinned subset** only.
- **Dated filter:** a to-do is emitted iff `DueAt != null || StartAt !=
  null`; a to-do with neither is **skipped** (a `VTODO` with neither `DUE`
  nor `DTSTART` is pointless — the "only include what's meaningful"
  `IcsWriter` idiom).
- **The closed `VTODO` property set (C-M14·4 / C-M14·5 ceiling):**
  `VCALENDAR` = `VERSION:2.0` / `PRODID:-//Kumunita//community calendar//EN`
  / `CALSCALE:GREGORIAN` / `METHOD:PUBLISH`; `VTODO` = `UID`
  (`kw-todo-{TodoItem.Id}@kumunita`, stable) / `DTSTAMP` (the caller-passed
  `nowUtc`) / `DUE` (`DueAt`, only when set) / `DTSTART` (`StartAt`, only
  when set) / `SUMMARY` (`Title`) / `DESCRIPTION` (`Body`, only when
  non-empty — the Markdown source, not rendered HTML) / `STATUS` (only when
  `IsDeleted` — the RFC update path, an emitter *capability* never reached
  through the frozen read seams).
- **Formatting (C-M14·4):** CRLF on every line (including the final
  `END:VCALENDAR`); a content line whose UTF-8 octet length exceeds 75 is
  folded at a ≤ 75-octet boundary that does not break a multi-byte UTF-8
  sequence, a single leading space on each continuation; escaping — `\` →
  `\\` (first), `;` → `\;`, `,` → `\,`, CR/LF → `\n` (a CRLF or a lone LF
  becomes the two-char backslash-`n`).
- **Never emitted (the D4 "never" list, C-M14·5 / C-M14·6):** `ORGANIZER` /
  `CREATED-BY` / `ATTENDEE` (no author or assignee identity in a file that
  travels — the ADR 0028 posture), `RRULE` / `RECURRENCE-ID` (C-M14·6 — M18),
  `Audience` / grant / membership internals (the decision is already
  applied to the set — C-M14·2), `AssigneeId`, `Status`, and **any**
  vendor-specific `X-…` property.
- **4 pinned tests** (BCL-only, no Testcontainers): the `VTODO` field-map
  for a dated to-do; the `DUE`-only / `DTSTART`-only / neither (skipped)
  conditional shape; the fold + escape on a long / special-char
  title+body; a valid **empty** `VCALENDAR` when no dated to-dos.
