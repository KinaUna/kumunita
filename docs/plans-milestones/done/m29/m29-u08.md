# M29 U08 — Web: the `/admin/labels` GlobalAdmin surface + the `/admin/platform` link + the admin-surface `kw-l` keys

## Context (self-contained)

M29 = **Admin surface labels**. U06/U07 wired the 13 nav items + 13 surface
headers to the label resolver.

**What this unit does:** ship the `/admin/labels` surface (the GlobalAdmin's
edit page — the 13-row form, one text input per surface key, blank = use the
default label; the `AdminSurfaceLabelsController` + the view + the
`/admin/platform` link + the admin-surface `kw-l` keys). **No test (U09).**

**The one thing this unit must respect:** the `/admin/labels` surface is the
**ADR 0150 shape** — a **dedicated** `AdminSurfaceLabelsController`
(`[Route("admin/labels")]` + `[Authorize(Roles = GlobalAdmin)]`) wrapping the
`ISurfaceLabelsService` seams, one `AccessAudit` row per save (`Via = Admin`,
action `surface_labels.save`, `TargetKind` "surface-labels" — the
`site.save` shape). The `AdminController`'s constructor is pinned by two
Web-layer test harnesses (`AdminControllerBlockTests` /
`AdminControllerMandatoryTests`), so a new dependency there would break them —
a separate `/admin/labels` surface mirrors `/admin/site` / `/admin/signup` /
`/admin/timezone` (M29·7). A **blank** field **clears** that surface's label
(falls back to the `kw-l` key).

   `AdminSurfaceLabelsViewModel` exactly.
