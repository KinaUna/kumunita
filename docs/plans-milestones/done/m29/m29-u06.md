# M29 U06 — Web: wire the 4 flat-row surface headers (Home, Announcements, Community, Groups)

## Context (self-contained)

M29 = **Admin surface labels**. U05 wired the 13 nav items in
`_Layout.cshtml` to the label resolver.

**What this unit does:** wire the 4 flat-row surface page headers (`<h1>`) —
Home, Announcements, Community, Groups — to the **same** label resolver (the
`GetLabelAsync` helper — override → `kw-l` fallback). **Home's hero stays under
the SITE lane** (M29·10 — M29 drives only the Home nav label, not the SITE
hero). **No More-dropdown surface header (U07), no admin surface (U08).**

**The one thing this unit must respect:** the resolved label is the **same** in
the nav (U05) and the surface's `<h1>` (M29·1) — a rename is never "nav says X,
header says Y." The Home surface's `<h1>` (if it is a distinct element from the
SITE hero) may be driven by the M29 label; the SITE hero text (the
`HomeHeroEyebrow` / `HomeHeroLead` fields) is **never** re-shaped (M29·10).

## Goal

Wire the 4 flat-row surface page headers (`<h1>`) — Home, Announcements,
Community, Groups — to the same label resolver. **Home's hero stays under the
SITE lane.** **No More-dropdown surface header (U07), no admin surface (U08).**
