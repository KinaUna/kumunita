**Deliverables (closed set):**
- **`src/Kumunita.Core/Notifications/NotificationService.cs`**
  (new) — the **exact** service surface from design doc §6.2:
  - **Ctor:** `NotificationService(IDocumentStore store,
    IUserInfoService userInfo, ITranslationProvider translator,
    IMailerStage mailer)` — the frozen seams, no ADD (the
    C-M6·11 pin).
  - **`EmitAsync`** (the writer): stores the `Notification`
    row **first** (always — the C-M6·7 pin: the inbox is the
    record), then **conditionally** calls
    `mailer.StageAsync(...)` (only if the recipient's
    `NotificationPreference.KindsEnabled` includes the kind, or
    is `null` / empty = all enabled — the C-M6·7 pin), using
    the caller-supplied idempotency key (the C-M6·4 pin — the
    `notification:{kind}:{stable-source-id}` shape, the
    *emitter's* responsibility) and the recipient's
    `Profile.EmailLanguage` (the frozen
    `IUserInfoService.GetProfileAsync` read seam — the
    C-M6·6 pin). **The inbox row store + the
    `StageAsync` call are in the caller's session** (the C3
    same-transaction pin — the caller owns the transaction,
    the M3b `FileReportAsync` / the M5 `AssignTodoAsync`
    `IDocumentSession`-overload convention). **No
    `IAuthorizationService` call** (the C-M6·3 pin — a
    personal read, not an `AccessAction` decision). **No
    `AccessAudit` row** (the C-M6·3 pin).
  - **`ListInboxAsync`** (the read lane): returns the
    **most recent 50** `Notification` rows for the recipient
    (newest-first, `Created` descending — the C-M6·8 pin).
    **No pagination** (the 50 cap is the shape). **No
    `IAuthorizationService` call** (the C-M6·3 pin).
  - **`CountUnreadAsync`** (the read lane): returns the count
    of the recipient's `ReadAt == null` rows (the C-M6·8
    pin). **No `IAuthorizationService` call** (the C-M6·3
    pin).
  - **`MarkAllReadAsync`** (the state lane): sets
    `ReadAt = now` on **all** the recipient's unread rows (one
    `Update` — no per-row loop — the C-M6·8 pin). **No
    `IAuthorizationService` call** (the C-M6·3 pin).
  - **`GetPreferencesAsync`** (the preference read lane):
    returns the recipient's `NotificationPreference` row (or
    a fresh `KindsEnabled = null` shape if none exists — the
    lean-default, the C-M6·9 pin). **No
    `IAuthorizationService` call** (the C-M6·3 pin).
  - **`SetPreferencesAsync`** (the preference write lane):
    upserts the recipient's `NotificationPreference` row with
    the new `KindsEnabled` list + `Updated = now` (the
    C-M6·9 pin). **No `IAuthorizationService` call** (the
    C-M6·3 pin).
  - **The method signatures** (parameter order, types,
    nullability, return types) are **verbatim** from design
    doc §6.2 — a later unit can copy them verbatim into the
    controller's call sites.
- **`src/Kumunita.Core/DependencyInjection.cs`** (modified) —
  register `NotificationService` as a **scoped** service (the
  M5 `ProjectService` / the M4 `EventService` registration
  precedent — `AddScoped<NotificationService>()`, the
  constructor-injected frozen seams already registered).
- **Nothing else.** No emitters (U04), no controller (U05),
  no views (U06–U08), no tests (U09), no ADR.
