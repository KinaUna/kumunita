**Goal:** create
**`src/Kumunita.Web/Views/Notifications/Preferences.cshtml`**
(the preferences editor — the toggles for the nine
`NotificationKinds` constants) and ship the **complete
`kw-l` key set** (the floor: the inbox labels, the bell
label, the settings toggles, the empty state, the "mark all

to `src/Kumunita.Core/Localization/KnownTranslationKeys.cs`
