# M25 U6 — Admin surface: `POST /admin/storage/limits` set-lane + admin Web tests

> **Sealed unit.** One fresh agent, ~32K context window. Self-contained. The
> register (`docs/plans-milestones/plan-m25-upload-limits.md`) is the
> cross-reference; when the two disagree, **this file wins for what to do**.
> **Exit: build green + the 2 admin Web tests pass.** **Precondition:** U5's
> `GET /admin/storage` + the build are green.

## Understanding

This unit adds the **GlobalAdmin-gated write lane** — `POST
/admin/storage/limits` — where the admin sets the per-file size limit + the
per-user quota. It calls `IStorageSettingsService.SetAsync` **in the caller's
session** (one in-caller-session write, C-UP·1), then redirects back to the
`GET` view. It adds the form to `Storage.cshtml` and the **2 pinned admin Web
tests** (design doc §2.4, items 20–21).

## Deliverables (≤ 4 files)

1. **`src/Kumunita.Web/Controllers/AdminStorageController.cs`** — add
   `POST /admin/storage/limits` (`[ValidateAntiForgeryToken]`): read the two
   values — per-file limit (blank ⇒ `null`, i.e. env fallback) + per-user quota
   (`0` ⇒ unlimited) — call `SetAsync(maxFileBytes, perUserQuotaBytes, subject,
   session)` in the caller's session (C-UP·1), redirect back to `GET
   /admin/storage`. Subject is the signed-in principal (server-side).
2. **`src/Kumunita.Web/Views/Admin/Storage.cshtml`** — add the **form** (two
   inputs: per-file limit [optional] + per-user quota) that posts to `POST
   /admin/storage/limits` (the U5 display stays).
3. **`src/Kumunita.Web/Models/AdminStorageViewModel.cs`** — extend with the form
   field values (`MaxFileBytesInput`, `PerUserQuotaBytesInput`) if not already
   present.
4. **`tests/Kumunita.Web.Tests/AdminStorageControllerTests.cs`** — the 2 pinned
   admin Web tests (§2.4, items 20–21):
   - `AdminStorage_SetLimits_Persists` — a GlobalAdmin `POST` sets both values;
     the `SetAsync` seam is called with the right values; the stored doc
     reflects them.
   - `AdminStorage_NonGlobalAdmin_Forbidden` — a non-GlobalAdmin `POST` (or
     `GET`) is rejected (403 / the role gate) — C-UP·1.

## Rules

- **GlobalAdmin-gated** (C-UP·1). The write is **one in-caller-session** write
  (C-UP·1); the subject is minted server-side (never a path param).
- **Blank per-file limit ⇒ `null`** (env fallback, C-UP·5); **`0` quota ⇒
  unlimited** (C-UP·5). Do not coerce blank → `0`.
- Do **not** change the `Decide` / the four-lane wiring in this unit.
