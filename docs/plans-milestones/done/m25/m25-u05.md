# M25 U5 — Admin surface: `GET /admin/storage` (settings + totals view) + nav link

> **Sealed unit.** One fresh agent, ~32K context window. Self-contained. The
> register (`docs/plans-milestones/plan-m25-upload-limits.md`) is the
> cross-reference; when the two disagree, **this file wins for what to do**.
> **Exit: build green.** **Precondition:** U4's `IStorageSettingsService` +
> the build are green.

## Understanding

This unit adds the **GlobalAdmin-gated** `GET /admin/storage` surface — a
**read-only** view of the community's current upload limits (the effective
per-file limit, the per-user quota or "unlimited") plus the community total
usage. It mirrors the existing "admin sets a community setting" precedent
(M9 `AdminMessagingController`, M20 `AdminQuietController`). **The write lane
(set the limits) is U6** — this unit is display + nav only.

- `src/Kumunita.Web/Controllers/AdminMessagingController.cs` or

  mirror (the `[Authorize(Roles = Roles.GlobalAdmin)]` + the `GET` action + the

  section-link list U5 adds a "Storage" row to.

- `src/Kumunita.Core/Usage/IStorageSettingsService.cs` (U4's seam).
- `src/Kumunita.Web/Views/Admin/` — the existing admin view + layout style.

## Deliverables (≤ 4 files)

1. **`src/Kumunita.Web/Controllers/AdminStorageController.cs`** —
   `[Authorize(Roles = Kumunita.Core.Identity.Roles.GlobalAdmin)]`;
   `GET /admin/storage` → loads the settings (`GetOrCreateAsync()`) + the
   community total usage (Σ over all `MediaObject.SizeBytes`, **or reuses
   M24's metrics seam if present** — see the drift-guard note), + renders the
   view. **Read-only in U5** (the set lane is U6).
2. **`src/Kumunita.Web/Models/AdminStorageViewModel.cs`** — the view model:
   `MaxFileBytes?` (the admin override), `PerUserQuotaBytes`, `TotalUsedBytes`,
   the **effective** per-file value (override ?? env default), the
   quota-unlimited flag.
3. **`src/Kumunita.Web/Views/Admin/Storage.cshtml`** — the settings display
   (the effective per-file limit, the per-user quota or "unlimited", the
   community total used). The **form** is U6 — the display is what U5 ships.
4. **`src/Kumunita.Web/Views/Admin/Index.cshtml`** (or the `/admin` hub) — add
   the "Storage" nav link row (mirror the existing section links).

## Rules

- **GlobalAdmin-gated** (C-UP·1). Non-GlobalAdmins must not reach
  `/admin/storage` (U6's `AdminStorage_NonGlobalAdmin_Forbidden` test pins this
  at the Web level; U5 just applies the attribute).
- The community total read is **read-only** (a `QuerySession`) and emits **no**
  `AccessAudit` row (C-UP·7 — the admin surface is not an audience-restricted
  read).
- **No write lane, no test, no form** in this unit.
