# M25 U4 — `IStorageSettingsService` + pure `StorageLimits` + the Core tests

> **Sealed unit.** One fresh agent, ~32K context window. Self-contained. The
> register (`docs/plans-milestones/plan-m25-upload-limits.md`) is the
> cross-reference; when the two disagree, **this file wins for what to do**.
> **Exit: build green + the 10 Core tests pass.** **Precondition:** U3's doc +
> `StorageSettingsDocTypes` exist and the build is green.

## Understanding

This unit implements the **Core** of M25 — the service seam
(`IStorageSettingsService`: get-or-create / set / per-user-usage) + the **pure**
decision module (`StorageLimits.Decide`) — and the **10 pinned Core tests**
(design doc §2.3). It registers the service in `AddKumunitaCore`. The decision
is **pure** (C-UP·3): no HTTP types, no `IFormFile`, no `ActionResult` — the
Web gate (U8) is the only place a `413` is produced.

## Deliverables (≤ 4 files)

1. **`src/Kumunita.Core/Usage/IStorageSettingsService.cs`** — the 4-method seam
   per §2.1:
   - `Task<CommunityStorageSettings> GetOrCreateAsync(CancellationToken ct)` —
     read; **create-if-missing** with sentinel defaults (`MaxFileBytes = null`,
     `PerUserQuotaBytes = 0`).
   - `Task SetAsync(long? maxFileBytes, long perUserQuotaBytes, string actorId,
     IDocumentSession session)` — one in-caller-session write (C-UP·1).
   - `Task<long> GetPerUserUsageBytesAsync(string subjectId, CancellationToken
     ct)` — the C-UP·4 read: `store.QuerySession()` (a **read**) —
     `Query<MediaObject>().Where(o => o.CreatedById == subjectId).Sum(o => o.SizeBytes)`.
   - `StorageDecision Decide(long incomingBytes, long currentUsageBytes,
     CommunityStorageSettings settings, long envMaxBytes)` — **pure**, delegates
     to `StorageLimits`.
2. **`src/Kumunita.Core/Usage/StorageSettingsService.cs`** — the impl (the
   four methods above; `GetOrCreateAsync` is create-if-missing; `SetAsync` is a
   single `session.Store(...)` + `session.SaveChanges()`).
3. **`src/Kumunita.Core/Usage/StorageLimits.cs`** — the **pure** static
   `Decide(long incoming, long currentUsage, CommunityStorageSettings s,
   long envMaxBytes)`:
   - `effectiveMax = s.MaxFileBytes ?? envMaxBytes` (a `0` effective max =
     unlimited file size, C-UP·5).
   - `if (effectiveMax > 0 && incoming > effectiveMax) return Oversize;`
   - `if (s.PerUserQuotaBytes > 0 && currentUsage + incoming >
     s.PerUserQuotaBytes) return OverQuota;`
   - `return Allowed;`
   **Size is checked before quota** (C-UP·2 ordering). **No HTTP types, no
   `IFormFile`** (C-UP·3).
4. **`tests/Kumunita.Core.Tests/Usage/StorageLimitsTests.cs`** — the 10 pinned
   Core tests (§2.3, items 1–10): `Decide_Oversize_Rejects`,
   `Decide_OverQuota_Rejects`, `Decide_WithinBoth_Allows`,
   `Decide_QuotaZero_Unlimited`, `EffectiveMaxFileBytes_AdminOverrideBeatsEnv`,
   `EffectiveMaxFileBytes_UnsetFallsBackToEnv`, `GetPerUserUsage_SumsCreatedByIdOnly`,
   `GetPerUserUsage_OtherUsersExcluded`, `SetAsync_PersistsInCallerSession`,
   `Decide_SizeCheckedBeforeQuota`. (The two `Decide`-only tests can be
   pure/no-DB; the `GetPerUserUsage`/`SetAsync` tests use the PostgresFixture.)
5. **`src/Kumunita.Core/DependencyInjection.cs`** — add
   `services.AddTransient<IStorageSettingsService, StorageSettingsService>();`
   (or the factory form if it needs the store — mirror `UsageAnalyticsService`'s
   registration).

## Rules

- **`Core` stays HTTP-free** (C-UP·3; ADR 0006-D): no `IFormFile`/`Stream`/
  `ActionResult` in any new file.
- The `Decide` module is **pure** and **size-first** (C-UP·2 ordering).
- Do **not** touch `IMediaStore` / `MediaObject` / `MediaOptions` (C-UP·1/4).
- Do **not** add a Web gate or a Web test in this unit.
