## Understanding

This unit is the **enforcement** of M25. It adds the **Web-only** `IUploadGate`
(the single place a `413` `ActionResult` is produced, mapping the pure Core
decision to a distinct oversize/over-quota message) and **adopts it in all
four upload lanes** (avatar / content-image / attachment / document), replacing
each lane's inline `MaxBytes` 413 check with the §2.2 adoption sequence
(get-or-create → per-user-usage → gate → return-if-reject), **before**
`PutAsync`. The allowlist + empty-file checks are **untouched** and keep their
positions; M25 changes *what* the size gate reads (the admin doc + quota) and
*how* it reports (a distinct over-quota 413), not *where* it runs.

## Deliverables (5 files: 1 new gate + 4 controller edits)

1. **`src/Kumunita.Web/Security/IUploadGate.cs`** (or
   `Kumunita.Web/UploadGate.cs`) — the Web-only gate per §2.1:
   `ActionResult? CheckUpload(long incoming, string subject,
   CommunityStorageSettings settings, long envMaxBytes)`. It calls
   `storageSettings.GetPerUserUsageBytesAsync(subject)`, then
   `StorageLimits.Decide(incoming, usage, settings, envMaxBytes)`, and maps
   `Oversize` → `StatusCode(413)` ("file exceeds the per-file size limit"),
   `OverQuota` → `StatusCode(413)` ("upload exceeds your storage quota"),
   `Allowed` → `null`. **The only place a `413` is produced** (C-UP·3).
   Register it in the Web host DI.
2. **`src/Kumunita.Web/Controllers/ProfileController.cs`** — in `AvatarUpload`,
   replace the inline `if (mediaOpts.Value.MaxBytes > 0 && file.Length >
   mediaOpts.Value.MaxBytes) return 413;` with:
   `var reject = gate.CheckUpload(file.Length, subject, settings,
   mediaOpts.Value.MaxBytes); if (reject is not null) return reject;`
   **before** `PutAsync`. Keep the empty-file → 400 + the allowlist check
   **untouched** and in their original positions.
3. **`src/Kumunita.Web/Controllers/ContentImageController.cs`** — the same
   replacement in the content-image upload action (same guard order preserved).
4. **`src/Kumunita.Web/Controllers/AttachmentController.cs`** — the same
   replacement in the attachment upload action (same guard order preserved).
5. **`src/Kumunita.Web/Controllers/DocumentController.cs`** — the same
   replacement in the document upload action (same guard order preserved).

## Rules

- The gate is **Web-only** (C-UP·3) — the `413` + the message live here; the
  decision stays the pure Core `StorageLimits.Decide` (U4).
- **Guards before write** (C-UP·2): the gate runs **before** `PutAsync`; on a
  reject, **no byte is written** (F9 — U10 pins this with a "no `PutAsync`
  called" assertion).
- The **allowlist** + **empty-file** checks are **untouched** and keep their
  original positions; M25 only swaps the size/over-quota check.
- **No new test** in this unit (U9 adds the per-lane tests).
