# M28 U01 — `GuardianTimeLimitSchedule` doc + `TimeLimitMode` enum + `M1DocTypes` registration

## Context (self-contained)

M28 = **Guardian time limits**: a **guardian** sets a per-child schedule
(hours × days-of-week, Blocked/Allowed polarity) that **gates the child's
whole-platform access** (a sign-out, the `BlockedAccountMiddleware` analog).
This is the **inverse of the M20 quiet lane** (ADR 0121) but on the **GU
guardian surface** (ADR 0028), using the **same pure-evaluator discipline**
(wall-clock-first, ADR 0019). U00 locked the design doc + ADR 0151.

**U01 creates the data model** — the `GuardianTimeLimitSchedule` POCO (per-
child, id = `ChildId`, the exact `NotificationQuietSchedule` "one row per
subject" shape) + the `TimeLimitMode` enum (`Blocked`/`Allowed`, the
`QuietScheduleMode` shape) — and registers the doc on the **existing
`M1DocTypes` GU surface** (next to `GuardianLink`). No service, no evaluator,
no middleware, no Web, no test yet.

**Why `M1DocTypes` (not a new `M28DocTypes`):** the doc is **part of the GU
guardian-lane surface** (the "lane on the M1 surface, not a new bounded
context" shape, the M27 D7 precedent). The ADR 0004 §B.1 additive-doc-type
precedent: delta-detected, idempotent, no new `*DocTypes`, no new boot-path
wiring, no EF migration.

## Goal

Create the `GuardianTimeLimitSchedule` POCO + the `TimeLimitMode` enum
(namespace `Kumunita.Core.UserInfo`) + register the doc on `M1DocTypes`
(next to `GuardianLink`). Mirrors the `NotificationQuietSchedule` doc shape
(per-subject, the `Enabled` master / `Mode` enum / `Hours` int[] / `DaysOfWeek`
int[] / `Updated?`), with `ChildId` in place of `RecipientId`. **No service,
no evaluator, no middleware, no Web, no test.**

## Deliverables (≤ 3 files)

1. **`src/Kumunita.Core/UserInfo/GuardianTimeLimitSchedule.cs`** (new) — the
   POCO + the enum (one file, the `NotificationQuietSchedule` +
   `QuietScheduleMode` same-file shape):
   - `public sealed class GuardianTimeLimitSchedule`:
     - `ChildId` (string, identity — the `RecipientId` analog; the
       supervised child's subject id).
     - `Enabled` (bool, default `false` = **never restricted** = the floor,
       C-M28·3).
     - `Mode` (`TimeLimitMode`, default `Blocked` — the lean default).
     - `Hours` (int[], 0–23, empty = **all hours**).
     - `DaysOfWeek` (int[], 0=Sunday…6=Saturday, empty = **all days**).
     - `Updated?` (DateTimeOffset? — the last save instant, for display).
   - `public enum TimeLimitMode`:
     - `Blocked = 0` — the child is **restricted DURING** the listed window
       (the lean default, the "no platform at night" reading).
     - `Allowed = 1` — the child is **restricted EXCEPT** the listed window
       (the allow-list, the "only allowed during these hours" reading).
   - A doc-comment on the class pinning: C-M28·3 (the floor), C-M28·6 (the
     child's effective zone — the evaluator handles it, not the doc), the
     "one row per child" identity (id = `ChildId`), and the M20 inverse
     framing (the `Enabled` / `Mode` / `Hours` / `DaysOfWeek` fields mirror
     `NotificationQuietSchedule`; the polarity is the **permission** —
     `IsAllowedNow` returns true = the child MAY use the platform now).
2. **`src/Kumunita.Core/M1DocTypes.cs`** (modify) — add
   `opts.Schema.For<GuardianTimeLimitSchedule>()` **next to** the
   `GuardianLink` line (the M6DocTypes `NotificationQuietSchedule`
   registration shape — identity pinned to `ChildId`, no unique index
   needed — the child id is already the identity).

## Rules

- **No service, no evaluator, no middleware, no Web, no test** (U02's
  evaluator tests are the first M28 tests).
- The doc + enum are in `Kumunita.Core.UserInfo` (the GU surface, not
  `Notifications`).
- The `M1DocTypes` line is **additive** (one `Schema.For` call — no new
  surface, no new boot path, no EF migration — ADR 0004 §B.1).
- The `Enabled` default is `false` (the floor — a fresh child account has
  no schedule, C-M28·3).
- The `Mode` default is `Blocked` (the lean default — the
  `QuietScheduleMode.Blocked` precedent).
