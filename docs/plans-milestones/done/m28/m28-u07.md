# M28 U07 — The acceptance gate tests (author the full seam list + run both suites)

## Context (self-contained)

M28 = **Guardian time limits**: a **guardian** sets a per-child schedule
(hours × days-of-week, Blocked/Allowed polarity) that **gates the child's
whole-platform access** (a sign-out, the `BlockedAccountMiddleware` analog).
This is the **inverse of the M20 quiet lane** (ADR 0121) but on the **GU
guardian surface** (ADR 0028). U00 locked the design doc + ADR 0151 (the
23-test seam list is pinned in the design doc §2.6, the acceptance gate in
§2.8). U01–U06 shipped the doc + enum, the pure evaluator, the three seams
+ impl, the `TimeLimitMiddleware`, the `kw-l` keys, and the guardian's
Detail section.

**U07 authors the full M28 seam list** (U02's 7 pure + U03's 7 standing/
audit + U04's 3 middleware + U06's 3 surface = **20 seam tests**, the exact
names from the design doc §2.6) as the **part-vs-whole** evidence + runs
both suites. **The gate is NOT recorded yet** (U08 records it) — U07
authors the 3 gate tests + runs + records the pass/red status for U08.

**The three acceptance tests (the M20 / M27 / M3 three-test shape, pinned in
the design doc §2.8):**
- **closed-loop** — a guardian sets a `Blocked`-mode schedule covering
  "now" for their child → `IsAllowedNow` returns `false` → the
  `GetActiveTimeLimitAsync` read sees the schedule (the F1 + C-M28·4
  composition).
- **handoff** — a guardian sets an `Allowed`-mode schedule that allows "now"
  → the child is allowed; then clears it → the child is again always-allowed
  (the F2-in-window + F3 floor + C-M28·4 strong-consistency).
- **part-vs-whole** — the full 20-test seam list passes together (the U02 7
  pure + U03 7 standing + U04 3 middleware + U06 3 surface, all green).

then run each assembly in-process: `dotnet build Kumunita.slnx -c Debug`,
then `dotnet exec tests\Kumunita.Web.Tests\bin\Debug\net10.0\Kumunita.Web-
Tests.dll` + `dotnet exec tests\Kumunita.Core.Tests\bin\Debug\net10.0\
Kumunita.Core.Tests.dll`. The in-process runner uses **single-dash** flags
