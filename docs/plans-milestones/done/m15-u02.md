## Goal

D5 rendered as code (the **import** half):

- **`TranslationBulkImporter`** — a **pure function** (no session, no
  audit, no store — the `IcsWriter` posture) that parses the bundle
  `string` and returns **either** the validated upsert matrix **or** a
  refusal naming the **first** offending row. **Validation is complete
  before any row is returned** (C-M15·3): the exact marker; a non-empty
  body; every body key ∈ `KnownTranslationKeys.AllKeys`; every language
  column ∈ the catalog's codes (the column set is the catalog's set — an
  extra column = unknown language); the `source` column is **ignored**
  (reference only); a **blank cell = no-op** (dropped from the upsert
  set, C-M15·4 — never a delete).
- **`UpsertManyTranslationsAsync(string languageCode,
  IReadOnlyDictionary<string, string> rows, string actorId,
  CancellationToken ct = default) → int`** on `ILocalizationService` —
  an **additive write seam**: upserts the present rows **through the same
  row store the frozen `UpsertTranslationAsync` uses** (C-M15·7 — one
  session, the same `TranslationResource` upsert), commits with
  **exactly one** `AccessAudit` row (`Action = "translation.import"`,
  `TargetKind = "translation"`, `TargetId` = the count as a string,
  `Via = Admin`, `Outcome = Allow`, C3 / C-M15·6), and returns the count
  of rows written. A blank value never reaches here (C-M15·4).
- **5 pinned tests** (names verbatim from the design doc).
