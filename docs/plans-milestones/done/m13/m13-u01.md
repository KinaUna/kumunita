## Goal

D6 rendered as code: the `Kumunita.Core.Logging` context (a new folder) —

- **`FileSinkOptions`** POCO (`Directory` + `RetentionDays` fields, the
  `CommunityOptions` bind shape — a `SectionName` constant for the
  `Logging__File` section).
- **`LogLine`** static class — pure `Write(TextWriter, LogLevel level,
  string category, string message, Exception? exception)` method. JSON
  escaping: `\` → `\\`, `"` → `\"`, newline → `\n`, tab → `\t`. Fields:
  `timestamp` (ISO-8601 `"o"` format), `level` (the `LogLevel` enum name
  in lowercase), `category` (verbatim), `message` (escaped), `exception`
  (the `exception?.ToString()` escaped string, omitted when null).
- **`RollingFileSink`** static class — `BuildFileName(DateTimeOffset now,
  string dir)` → `app-yyyyMMdd.log` under `dir`; `Retain(string dir,
  int retentionDays, DateTimeOffset now)` → `Directory.EnumerateFiles(dir,
  "app-*.log")` + `File.GetLastWriteTimeUtc(f) < now − retentionDays`
  filter + `File.Delete(f)`.
- **`FileLoggerProvider`** — `ILoggerProvider` impl. `CreateLogger(category)`
  returns a `FileLogger`. `Dispose` closes the writer.
- **`FileLogger`** — `ILogger` impl. `BeginScope` / `Log` / `IsEnabled`.
  `Log` writes one JSON line via `LogLine.Write`. Per-category `TextWriter`
  lock.
- **`AddFileSink`** extension — `LoggingBuilder AddFileSink(this
  LoggingBuilder b, string dir, int retentionDays)`. Registers the
  `FileLoggerProvider` as a singleton + calls `RollingFileSink.Retain`
  once at registration (the "delete at boot" pass).
- **`Program.cs` wiring** — the `builder.Services.Logging.AddFileSink(dir,
  days)` call (next to the `AddLogging()` line), the
  `Logging__File__Directory` / `Logging__File__RetentionDays` config read,
  the `appsettings.json` `Logging:File` section added.
- **3 pinned tests** (BCL-only, no Testcontainers):
  - `RollingFileSink_LogLine_Is_ValidJsonLines`
  - `RollingFileSink_FileNaming_Is_Daily`
  - `RollingFileSink_Retention_Deletes_Older_Files`
