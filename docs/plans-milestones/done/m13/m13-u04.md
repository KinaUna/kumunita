## Goal

D3 rendered as code:

- **`IUsageAnalyticsService`** interface in `Kumunita.Core.Usage`:
  - `Task<UsageAnalyticsResult> GetWindowAsync(int windowDays)`
  - `Task<IReadOnlyList<UsageCsvRow>> GetCsvRowsAsync(int windowDays)`
  - `windowDays` pin: 7/30/90; unknown → `ArgumentOutOfRangeException`.
- **`UsageAnalyticsResult`** POCO: `WindowDays`, `Total`,
  `AuthenticatedTotal`, `AnonymousTotal`, `DistinctActors`,
  `SurfaceRanking` (`IReadOnlyList<SurfaceRow>`). **`NewSignups` is
  dropped** — `User : IdentityUser` has no created-at column.
- **`SurfaceRow`** POCO: `Surface` (string), `Total` (int).
- **`UsageCsvRow`** POCO: `At` (DateTimeOffset), `Surface` (string),
  `Total` (int).
- **`UsageAnalyticsService`** impl — ctor: `(IDocumentStore store)`.
  `GetWindowAsync`: `switch (windowDays) { 7, 30, 90 }` pin;
  `cutoff = DateTimeOffset.UtcNow.AddDays(-windowDays)`;
  `session.Query<UsageEvent>().Where(e => e.At >= cutoff)`;
  `Total` count; `AuthenticatedTotal` = count where `!IsNullOrEmpty(ActorId)`;
  `AnonymousTotal` = count where `IsNullOrEmpty(ActorId)`;
  `DistinctActors` = `Select(e => e.ActorId).Distinct().Count()` (non-empty
  only); `SurfaceRanking` = `GroupBy(e => SurfaceKey.Map(e.RouteTemplate))`
  → `OrderByDescending(r => r.Total).ThenBy(r => r.Surface)`.
  `GetCsvRowsAsync`: same window, `GroupBy(e => new { Date = e.At.Date,
  Surface = SurfaceKey.Map(e.RouteTemplate) })`, sorted by `Date` ascending
  then `Surface` ascending.
- **DI registration** — `services.AddTransient<IUsageAnalyticsService,
  UsageAnalyticsService>();` in `DependencyInjection.cs`.
- **4 pinned Core tests** (Testcontainers `postgres:18`):

  - `Aggregation_SurfaceRanking_Descending_Then_Alphabetical`
  - `Aggregation_AuthenticatedVsAnonymous_Counts`
  - `Aggregation_DistinctActors_Counts_Unique_NonEmpty`
