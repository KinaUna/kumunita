## U03 — BookmarksController + /bookmarks list view + 12 `bm.*` keys (×4) + nav entry + 5 pinned Web tests

- **Controller surface confirmed** (`src/Kumunita.Web/Controllers/BookmarksController.cs`, the design doc §2.2 shape verbatim): `GET /bookmarks` → `Index()` — `SubjectId(User)` null/empty ⇒ non-leaky `NotFound()` **before** any seam call (the C-M17·2 "operator has no read standing" gate, ADR 0105), else `await bookmarks.ListAsync(actorId)` → `View(result)`; `POST /bookmarks/{targetKind}/{targetId}/remove` → `Remove()` with `[ValidateAntiForgeryToken]` — same `SubjectId` gate ⇒ 404, else `await using var session = store.LightweightSession(); await bookmarks.RemoveAsync(actorId, targetKind, targetId, session); await session.SaveChangesAsync();` → `Redirect("/bookmarks")`. - **Toggle action confirmed** (`src/Kumunita.Web/Controllers/BookmarksController.cs` `Toggle`): `[HttpPost("/bookmarks/toggle")]` + `[ValidateAntiForgeryToken]`; `SubjectId(User)` null/empty ⇒ non-leaky `NotFound()` **before** any seam call; else `await using var session = store.LightweightSession(); var result = await bookmarks.ToggleAsync(actorId, kind, id, session);` — `BookmarkToggleStatus.Refused` ⇒ `NotFoundResult` (the C-M17·2 "operator has no write standing" gate, ADR 0105, same owner-gate as the U03 remove lane); `Bookmarked` / `AlreadyBookmarked` (both idempotent success) ⇒ `await session.SaveChangesAsync(); Redirect("/bookmarks")`. `Removed` / `NotBookmarked` are not reachable from the toggle endpoint (they're read-lane statuses, not toggle outcomes) — the controller maps on the two toggle-success statuses explicitly.
