> **Abstract:** the lane-code glossary (D6, part 1, ADR 0307) — one row
> per lane-code prefix that appears in the codebase, resolved to its
> archived lane under `docs/archive/lanes/` and that lane's plan file,
> so a code comment's `F14.U2` / `C3-06` / `IS21` lands in its lane in one
> hop. Generated from the tree; the devx `lane-codes` rule fails the moment it goes stale.
