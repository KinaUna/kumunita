> **Abstract:** the code map (D4, ADR 0307) — one row per bounded context,
> linking the concern to the Core folder, its `*DocTypes.cs`, its DI-registered
> service seam, the Web controllers and view folders that serve it, the test
> folders that cover it, and the top 3 ADRs the folder cites. Generated from the
> code; the devx `code-map` rule fails the moment it goes stale.

# Code map

> generated by `tools/devx/code-map.ps1` — do not hand-edit.

One row per bounded context: a `Kumunita.Core` folder with its own `DependencyInjection.cs`.
The composition-root aggregator (`src/Kumunita.Core`) and the `Announcements` feature
module are excluded (by rule). Every cell is derived from the code; the ADR column is
a list of the most-cited numbers in the folder, not links. The `Key surfaces` column
lists the context's translation-key surfaces (one JSON file per surface under
`Localization/Keys/<lang>/`): a surface equal to the lower-case context stem is clean;
a `*` marks a D10 abbreviation — a proper prefix of the stem, e.g. `inv` on Inventory.
